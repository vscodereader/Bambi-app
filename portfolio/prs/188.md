## 변경 목적
운영 및 로컬 QA에서 확인된 프로필 업로드, 최초 사업자 인증, 운영자 신고 처리, 팝업 편집기, 탈퇴 회원 채팅 문제를 해결합니다.

## 작업 내용
- 활성 회원은 구인자·구직자 및 성별과 관계없이 구직자 계정 설정에서 프로필 사진을 등록할 수 있도록 변경했습니다.
- 최초 사업자 인증 서류는 브라우저에서 임시 선택하고, `업체 정보 제출` 시 이미지·PDF 업로드와 인증 요청을 함께 진행하도록 수정했습니다.
- 팝업 글 편집 중 입력 내용에 따라 편집 영역 크기가 늘어나지 않도록 고정했습니다.
- 신고 기각 다이얼로그를 `document.body` 포털로 렌더링해 채팅 참여자 프로필 이미지가 다이얼로그 위로 노출되는 문제를 해결했습니다.
- 조치 완료·기각 신고의 선택 UI를 비활성화하고 서버에서도 종결 신고의 일괄 상태 변경을 차단했습니다.
- 채팅방 신고 상세의 별도 `조치 완료` 버튼을 제거하고, 사유 입력 후 방 차단이 성공하면 신고가 자동 완료되도록 변경했습니다.
- 채팅방·채팅 메시지 신고 여부를 API 응답 객체 구조가 아닌 `targetType` 기준으로 판별하도록 수정했습니다.
- 탈퇴 회원과의 기존 대화는 열람할 수 있지만 `대화 불가능` 상태를 표시하고 신규 메시지 전송을 차단했습니다.
