## 주요 변경

### 1. 전체공고 48개 단위 조회

- 밤비 승인 공고와 크롤링 공고를 합쳐 최초 48개만 표시합니다.
- 공고 더보기마다 다음 48개가 추가되도록 조회 범위를 정리했습니다.
- 데스크톱 4열 배치와 모바일 반응형 열 수를 유지하며 필터 적용 시에도 동일한 단위를 사용합니다.
- 스페셜·추천 광고의 전체공고 중복 노출 정책은 유지합니다.

### 2. 공고 등록 동시 구매와 단독 구매 분리

- `job_boost_purchase_source` enum과 `purchase_source` 컬럼을 Drizzle migration으로 추가했습니다.
- 유료 노출상품 등록과 함께 산 옵션은 `job_registration`, 무료 공고 또는 광고관리에서 산 옵션은 `standalone`으로 분류합니다.
- 기존 데이터는 기본값 `standalone`을 유지합니다.
- 공고 등록 동시 구매 옵션은 별도 끌어올리기 결제 목록에서 제외합니다.

### 3. Admin 결제관리 개선

- 공고 결제 총액과 정렬 기준에 이용기간, 디자인, 묶음 끌어올리기 옵션 금액을 모두 반영했습니다.
- 선택한 항목만 `디자인`, `끌어올리기`, `횟수권`, `자동 끌어올리기` 상세 행으로 표시합니다.
- 공고 결제 목록과 단독 옵션 결제 목록 모두 모바일 카드 UI를 추가하고 기존 데스크톱 표를 유지했습니다.
- 모바일에서도 체크박스, 일괄 처리 및 개별 관리 작업을 제공합니다.

### 4. 묶음 옵션 결제 상태 연동

- 공고 결제완료 처리 시 함께 구매한 옵션을 동일 트랜잭션에서 활성화합니다.
- 미사용 묶음 옵션은 공고와 함께 미결제로 전환합니다.
- 묶음 옵션에 사용 이력이 하나라도 있으면 공고의 미결제 전환 전체를 거절합니다.
- 단독 구매 옵션의 개별 결제완료·미결제·취소 동작은 유지합니다.

### 5. 급여 및 구인자 화면 보완

- 자체 공고 급여 상한을 `123,456,789원`으로 통일하고 화면과 API 양쪽에서 검증합니다.
- 초과 시 `급여 금액은 최대 123,456,789원까지 입력할 수 있어요.` 문구를 반환합니다.
- 구인자 상단 메뉴에서 출석체크만 제거하고 내 정보 메뉴 및 직접 URL은 유지합니다.
- 광고관리 목록의 제목을 15자 초과 시 말줄임하고 잘린 제목에 원문 브라우저 툴팁을 제공합니다.

### 6. 검수 상세 화면 정리

- `/moderator/queue/[id]` 하단 결제 관리 패널만 제거했습니다.
- 공고 정보, 승인·반려 기능과 별도 결제관리 페이지 및 관련 API는 유지합니다.
