## 개요

구직자 전체공고를 48건 단위로 통일하고, 순차 끌어올리기 정렬을 회귀 테스트로 보강했습니다. 광고 관리의 수동·자동 끌어올리기 현황은 데스크톱과 모바일에서 공통 뱃지로 표시합니다.

## 주요 변경

### 1. 전체공고 48건 배치

- 최초 조회와 공고 더보기 모두 48건으로 통일
- 데스크톱 4열 기준 12줄 단위 노출
- 기존 반응형 1열·3열·4열 구조와 커서 페이지네이션 유지

### 2. 끌어올리기 정렬 검증

- 인증업체 우선 정렬 정책 유지
- 최근 끌어올림이 기존 끌어올림보다 앞에 오는 순차 정렬 테스트 추가
- 전체공고의 유료 공고 중복 노출 정책에 맞춰 테스트 헬퍼 교정

### 3. 광고 관리 뱃지 개선

- 오늘 끌어올리기와 자동 끌어올리기를 공통 뱃지로 표시
- 일일 횟수와 횟수권을 세로 두 줄 뱃지로 분리
- 미포함·미설정·대상 아님 상태를 회색 뱃지로 표시
- 모바일과 데스크톱에 동일한 표시 컴포넌트 적용
