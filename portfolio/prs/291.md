## 배경

운영자 사용자 관리에는 계정 상태·역할·신고·경고 정보는 있지만 회원이 현재 서비스를 이용 중인지 판단할 접속 상태가 없었다. 세션 존재나 장수명 연결만 기준으로 쓰면 화면을 방치해도 계속 온라인으로 남고, 채팅 연결만 보면 다른 화면 활동을 놓친다.

사용자 행동이 유발한 인증 API 요청을 마지막 인정 활동으로 기록하고, 운영자가 설정한 시간 동안 온라인으로 판정한다. 자동 polling·prefetch·SSE heartbeat·Socket 재연결은 활동에서 제외하며 마지막 유효 연결의 정상 종료는 가능한 경우 즉시 오프라인으로 반영한다.

설계·구현 계획: `docs/superpowers/plans/2026-09-04-user-online-presence.md`

## 확정 정책

- 대상: Web·Native의 구직자·구인자·법률자문·운영자. 계정이 없는 guest 제외
- 온라인: 최초 진입 또는 조회·검색·페이지 이동·등록·수정·삭제 등 사용자 행동이 유발한 인증 API 요청
- 오프라인: 마지막 인정 활동으로부터 운영자 설정 시간이 지난 시점. 기본 20분
- 자동 polling·prefetch·캐시 갱신, SSE heartbeat·재연결, Socket.IO 연결·타이핑은 활동에서 제외
- 여러 탭·기기 중 하나라도 유효하면 한 연결 종료만으로 계정 전체를 오프라인 처리하지 않음
- 마지막 유효 연결의 정상 종료·명시적 로그아웃·Native background는 즉시 오프라인. 종료 신호가 유실되면 설정 시간 만료로 최종 판정
- 탈퇴 계정은 항상 오프라인, 정지 계정은 실제 인증 활동이 있으면 온라인
- 전체 접속 이력은 보관하지 않고 최신 마지막 활동과 transient 연결만 저장

## 작업 내용

### DB·공용 정책

- `user.last_activity_at`, `user.presence_disconnected_at` 추가
- `bambi_site_settings.user_offline_after_minutes` 추가, 1 이상의 정수 DB check
- Web/Native 탭·기기별 `bambi_user_presence_connection` 추가: session FK, platform, 연결·lease 시각과 조회 index
- **Drizzle migration `0115_user-presence`** — 이 기능이 0115 번호 선점
- 공용 기본값 20분, 활동 기록 병합 10초, 연결 lease와 온라인 판정을 단일 서비스로 구성

### 활동 기록·연결 수명

- 공용 oRPC 활동 헤더를 통해 인증된 요청만 기록하고, 로그인 사용자도 호출하는 `publicProcedure` 공고·커뮤니티 API까지 포함
- Web은 최초 진입·클릭·제출·키보드 실행 뒤 1회 신호만 보내 자동 요청이 과거 행동을 주워가지 않게 처리
- Native는 active 상태 API를 기록하고 AppState 기반 연결 등록·해제·lease 갱신. lifecycle 요청은 활동에서 제외
- Web 알림 SSE를 connection lifecycle로 재사용하고 pagehide·SSE close·로그아웃에서 연결 해제
- 다중 연결 종료 판정은 사용자 단위 advisory lock으로 직렬화

### 서버 간 실시간 전파

- DB trigger가 사용자 활동·종료·설정 변경을 `pg_notify`로 발행
- 각 API 서버 인스턴스가 PostgreSQL `LISTEN`으로 받아 운영자 전용 `/sse/presence`에 fan-out
- 운영자 브라우저는 전체 사용자 목록을 polling하지 않고 대상 사용자만 즉시 갱신
- 시간 만료는 공용 클라이언트 시계로 최대 10초 오차 안에서 오프라인 전환
- SSE 재연결 시 사용자·설정 정본을 다시 읽어 유실 구간 복구

### 운영자 화면

- 사용자 관리: 체크박스와 이름 사이 `접속` 열, 체크박스와 같은 `size-4` 원, 온라인 우선·최근 활동순 정렬
- 상태 탭·이름/이메일/로그인 아이디 검색과 같은 첫 번째 행 오른쪽에 오프라인 기준 설정 배치
- 사용자 상세: 기존 계정 상태 옆 온라인/오프라인 배지, 계정 정보에 마지막 활동
- 출석 관리: 체크박스와 회원 사이 접속 열, 이름·아이디·오늘 출석을 한 줄로 표시
- 이름·소속 업소·이메일·아이디의 문자 수 기반 자르기를 제거하고 실제 열 폭 CSS 말줄임과 원문 설명 적용
