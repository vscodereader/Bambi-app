## 요약

웹의 공개·구직자·구인자·운영자·로그인·고객센터·편집기 화면에 **수동 다크모드**를 추가한다. 일반 흰 표면과 어두운 글자만 밤비 ink 계층·밝은 문자로 전환하고, 브랜드·상태 버튼·밝은 테두리·이미지/GIF/광고 소재는 기존 색을 유지한다.

최초 방문은 라이트모드이며 시스템 테마를 자동 추종하지 않는다. 헤더의 해/달 버튼으로 고른 테마는 새로고침·직접 URL 이동·재방문 뒤에도 유지된다.

## 주요 변경

### 전역 테마 기반
- `next-themes`를 Providers에 연결(`attribute="class"`, `defaultTheme="light"`, `enableSystem={false}`)하고 전용 저장 키·허용 테마 타입 추가
- 페이지 `ink-950`, 카드 `ink-900`, 팝오버 `ink-800`, 일반 본문 밝은 중립색으로 shadcn·밤비 시맨틱 토큰 동시 매핑
- 활성 테마에 Toaster·`color-scheme`·브라우저 `theme-color` 동기화, hydration 경고·초기 레이아웃 이동 방지
- 공통 `ThemeToggle`을 역할별 데스크톱·모바일 헤더, 공개 jobs/board/법적 문서, 로그인 게이트, 독립 광고 배너 편집 창, 모바일 채팅 자체 헤더에 연결

### 기존 색상·미디어 보존
- primary·상태 버튼과 기존 밝은 border/input 색은 유지하고, 공통 outline은 라이트 흰 배경·어두운 글자 / 다크 카드 배경·밝은 글자로 전환
- 공통 outline variant에 다크 카드 표면·밝은 전경과 `bg-clip-border`를 일원화해 188개 사용처의 화면별 중복·누락을 제거
- 로그아웃 세 곳은 공유 라이트 outline 예외를 사용하고, 실제 메인 팝업은 light scope로 다크 variant를 차단
- 업로드 이미지·GIF·광고 소재·배너/수집 이미지 편집 결과에는 필터·반전 미적용
- 성별 표식은 라이트모드의 남성 하늘색·여성 코럴 합성색과 어두운 아이콘을 불투명 토큰으로 고정해 다크에서도 동일 렌더

### 화면별 대비·구조 보완
- 모든 수다방 게시판 미리보기 카드의 제목/더보기 헤더 아래 구분선 1개 추가(글 사이 선 없음), 공지 카드 밝은 회색 표면 제거·제목/본문 대비 강화
- 운영자 모드 배지에 다크 전용 밝은 외곽선 추가
- 채팅 면접 완료·연락처 공개·날짜 칩의 누락된 코럴 텍스트 utility를 기존 `coral-700`으로 교정
- 헤더 해/달 버튼 크기·아이콘·테두리를 기존 아이콘 버튼과 통일
