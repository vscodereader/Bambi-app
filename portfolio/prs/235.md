## 주요 변경

### 등급 아이콘
- 공용 `GradeIcon`의 원본 크기·종횡비·`object-contain` 유지
- Badge 고정 높이·overflow로 위아래가 잘리던 문제 해소
- 출석·게시글·댓글·운영자 등급 소비처 공통 반영

### 뽑기권 획득·출석 복구
- 구직자는 배포 후 실제 출석일이 7일 연속될 때마다 뽑기권 1장 지급
- 하루 결석 시 새 연속 구간으로 시작, 배포 전 출석은 보상 계산 제외
- 복구권 1개당 과거 미출석일 한 날짜만 선택, 일반 출석 포인트 미지급
- 복구권 여러 장으로 과거 빈 7일을 채우는 흐름 허용
- 완료 면접을 가진 구직자 후기가 공개 상태로 72시간 유지되면 공고 최초 작성자에게 1장 지급
- 72시간 전 숨김·삭제는 영구 제외, 단순 신고만으로는 제외하지 않음, 지급 후 회수 없음

### 포인트 랜덤 뽑기
- 운영자 당첨 포인트·정수 가중치 CRUD와 예상 확률 표시
- 활성 설정이 없거나 뽑기권이 없으면 사용자·서버 모두 차단
- 서버 안전 난수로 결과 선확정, request ID 멱등, 뽑기권 1장 원자 차감
- 포인트 상한 범위의 실제 적립액을 결과·원장·알림에 기록
- 참고 이미지 기준 상단 캡·투명 유리통·캡슐볼 14개·사다리꼴 본체·크랭크·검은 출구·받침 구성
- 0.68~0.92초 3개 경로로 가챠볼이 유리통 전체를 빠르게 횡단
- 기계 흔들림 → 볼 배출 → 개봉 → 결과 상태 머신
- 모바일·데스크톱 반응형, reduced-motion·aria-live 지원

### 포인트몰 동적 진열·상품 관리
- 인기상품 1행 고정, 상품권·기타 아이템 초기 분류
- 빈 행 DB 보존, 분류 생성·공개·삭제, 드래그·키보드 재정렬, 삽입 이후 행 밀기
- 인기상품 복수 선택과 수동 순서
- 일반 분류 상품은 가격 오름차순, 같은 가격은 생성 순서·ID 안정 정렬
- 상품 사진·이름·분류·가격·대상·혜택·재고·공개 토글 CRUD
- 공개된 0P 상품 반복 구매, 뽑기권·복구권 구매 즉시 충전
- 기존 수동·횟수·기간제 자동 끌어올리기와 광고 연장 혜택 재사용
- 사용자·운영자 공용 반응형 `object-contain` 상품 이미지
