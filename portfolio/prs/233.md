## 주요 변경

### 공지사항 다중 게시판 노출
- 공지 한 건과 선택 게시판을 연결하는 `community_notice_board_placement` 추가 — 게시물 복제 없이 수정·삭제·댓글·좋아요·조회수 통합
- 공지 작성·수정 화면에 DB 기반 복수 게시판 선택 Accordion 추가 — 이후 생성되는 활성 게시판 자동 반영
- 공지사항은 이벤트 우선·그룹별 최신순, 선택 게시판은 공지 최신순 후 일반 글 최신순
- 수집 글이 섞이는 밤문화 이야기 목록·홈 미리보기에도 공지 우선 정렬 적용
- 댓글 작성 불가·비밀글·이벤트 옵션 유지, 이벤트와 비밀글 동시 사용 금지

### 유형별 포인트 광고 선정·지급
- 프리미엄·스페셜·추천의 지급 포인트와 로테이션 시간을 각각 운영자 설정으로 분리
- 유형별 현재 광고 한 건을 전역 무작위 선정하고 설정 시간마다 교체
- 내부 광고와 노출 설정이 켜진 외부 수집 광고 후보 재사용
- 좌·중·우 프리미엄 배너와 스페셜·추천 카드에 `circle-dollar-sign + POINT` 스티커 표시
- 광고 등록 문의 placeholder, 운영자, 구인자 자기 조직 공고는 선정/스티커/보상에서 제외
- 계정·유형별 advisory lock과 포인트 원장 external key로 동시 클릭·재시도 중복 지급 차단
- 실제 적립액을 포인트 내역·알림·공고 상세 딥링크·토스트에 반영

### 로테이션 변경과 개인 쿨타임
- 각 유형의 로테이션 시간이 해당 유형의 개인 재지급 쿨타임으로 동작
- 시간 값이 실제 변경된 유형만 기존 활성 쿨타임 조정
  - 남은 시간 R ≤ 새 N: 즉시 초기화
  - R > N: 기존 종료 시각에서 N시간 차감
- 시간 변경 즉시 해당 유형의 기존 선정 광고를 폐기하고 다음 조회에서 재선정
- 같은 시간 재저장·포인트 금액만 변경 시 기존 쿨타임 유지
- 포인트가 null/0인 유형만 독립 비활성화

### 운영자 개인 UI·포인트 화면
- 운영자 내 정보의 개인 포인트 요약·출석·내역·포인트몰 잔액 호출 제거
- 공용 등급 배치 조회에서 admin을 제외해 게시글·댓글·프로필 등 모든 소비처에서 등급 숨김
- 운영자 콘솔의 회원 포인트·출석·기타 설정·포인트몰 관리 기능은 유지
- 구직자·구인자 포인트 내역에 기존 내 정보와 같은 좌우 광고 레일 재사용

### 기타 포인트 설정 UI
- 회원가입과 출석 → 공고 포인트 → 게시판별 작성 포인트 순으로 독립 Accordion 구성
- 프리미엄·스페셜·추천을 구분선으로 분리하고 각 유형의 포인트·로테이션 시간을 한 묶음으로 표시
- 모바일 단위 줄바꿈 방지, 기본 카드 배경·얇은 시맨틱 테두리·그림자 적용
