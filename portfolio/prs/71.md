## 변경 사항

- 수다방 목록 뒤로가기와 게시판 표시 명칭을 정리했습니다.
  - 상세 진입 전 목록 URL을 히스토리에 남겨 페이지·스크롤 문맥으로 복귀
  - 화면의 ‘일 이야기’를 ‘밤문화 이야기’로 변경
- 운영자 관리형 닉네임 금칙어 정책을 추가했습니다.
  - 기존 `banned_word`에 `content | display_name` 범위를 추가
  - 운영자 콘솔 금칙어 관리 아래 동일 UI를 재사용한 ‘닉네임 금칙어’ 영역 추가
  - 두 금칙어 목록의 CRUD·CSV·검색·활성화·삭제를 범위별로 분리
  - 가입·프로필 변경·게시글 작성/수정에서 활성 닉네임 금칙어를 서버 기준으로 검증
  - 대소문자·공백·기호 우회를 정규화하여 차단하고 운영자 역할은 예외 처리
  - 클라이언트의 하드코딩된 예약어 목록 제거
  - 닉네임 중복은 계속 허용
  - 자유수다 비밀글 UI·API 우회 차단 및 기존 데이터 정리
- 채팅방별 안 읽은 메시지를 누적 개수로 집계하도록 수정했습니다.

## 마이그레이션

- `0060_community-author-secret-cleanup.sql`
  - 기존 비운영자 회원·게시글 작성인의 예약어 포함 값을 정리
  - 기존 자유수다 비밀글을 소프트 삭제
- `0061_nickname-banned-word-scope.sql`
  - 금칙어 범위 컬럼과 범위별 인덱스 추가
  - 초기 닉네임 금칙어 `Admin`, `관리자` 등록

실제 로컬 DB에는 아직 마이그레이션을 적용하지 않았습니다. 승인 후 `pnpm db:migrate`를 실행하고 DB 연동 테스트 및 운영자 화면 수동 확인을 진행해야 합니다.
