## PR 본문 원문

## 요약

구직자 메인과 수다방 홈이 하나의 게시판 행 배치를 공유하던 구조를 `main`·`community` 두 surface로 분리한다. 운영자는 메인에 필요한 게시판만 남기고 수다방에는 별도 전체 구성을 유지할 수 있으며, 공지사항·베스트글도 다른 게시판과 동일하게 이동·제거할 수 있다.

게시글 상세 하단에는 현재 게시판 목록·수다방 홈 버튼과 등록시간 기준 이전글·다음글 탐색을 추가한다. 비로그인 방문자도 수다방 버튼으로 `/seeker/community` 홈과 게시판 미리보기를 볼 수 있게 하되, 하위 목록·상세·글쓰기의 기존 권한은 유지한다.

Closes #245

## 변경 내용

### DB · 배치 API

- `community_board_layout_surface` enum(`main`|`community`)과 `community_board_home_layout.surface` 추가
- **0109 Drizzle migration**: 기존 배치를 `community`로 유지한 뒤 같은 행·위치를 `main`으로 복제 — 배포 직후 두 화면의 기존 구성 보존
- PK를 `(surface, board_key)`, 슬롯 유니크를 `(surface, row_index, position)`으로 변경해 같은 게시판을 두 화면에 독립 배치
- `getHomeLayout`·`updateHomeLayout`이 surface를 필수 입력으로 받고 해당 surface 행만 조회·교체
- 공지 1행·베스트 2행 첫 칸 고정 검증 제거, 한 surface 안의 중복·존재하지 않는 게시판만 거부
- 게시판 삭제 시 두 surface의 해당 배치 행을 함께 정리
- `community.overview`에 surface 입력을 추가해 공용 미리보기 조립 로직은 유지하면서 화면별 배치만 분리

### 운영자 게시판 관리

- `수다방 홈 행 배치`를 공용 `BoardLayoutEditor`로 일반화
- 기본 접힘 Accordion 2개 추가: **메인페이지 행 배치 → 수다방 행 배치** 순서
- 두 편집기 모두 행 추가, Select 추가, 제거, 행/행 내부 드래그, 저장 기능 재사용
- 공지사항·베스트글의 `고정` 라벨·drag 차단·제거 차단을 모두 제거
- 메인 저장은 main, 수다방 저장은 community cache·DB 행만 갱신

### 비로그인 수다방 홈

- proxy에서 `/seeker/community` 루트만 공개하고 하위 게시판·상세·쓰기 경로는 기존 게이트 유지
- seeker layout/page의 anon 분기를 조정해 `/seeker` 인증 게이트와 공개 수다방 홈을 각 페이지가 렌더
- 비로그인·게스트 수다방 홈에도 `SeekerShell`·광고 rail·community surface 미리보기 노출
- 메인 섹션의 수다방 더보기는 인증 팝업으로 가로채지 않고 `/seeker/community`로 이동

### 글 상세 이전글·다음글

- `getPostNavigation` publicProcedure 신설: 현재 화면 게시판·source(native/crawled)·글 ID를 받아 이전/다음 반환
- 정렬 총순서 `(createdAt ASC, id ASC)` — 이전글은 더 오래된 후보 중 가장 가까운 글, 다음글은 더 새로운 후보 중 가장 가까운 글
- 일반 게시판은 실제 board가 같은 글만 후보로 삼아 교차 노출 공지 제외, 공지 게시판에서는 공지끼리 탐색
- 베스트 최근 30일·추천 자격, work_talk 수집 피드 스위치·30일 컷오프, 비밀글 제목 마스킹·역할별 접근 규칙 재사용
- native/crawled 양쪽 쿼리에서 현재 글 ID를 명시적으로 제외하고 Web에서도 동일 ID를 한 번 더 제거해 자기 글 순환 방지
- 공개 `/board` 상세는 공개 게시판·비잠금 글 후보만 반환

### 상세 하단 UI

- `CommunityPostNavigation` 공용 컴포넌트를 일반 회원·인증 게스트·수집 글·공개 상세에 연결
- 이전글·다음글 박스 아래 오른쪽에 작은 `목록`·`수다방` primary 버튼 배치
- 첫 글은 이전글 행, 마지막 글은 다음글 행을 숨기고 이웃이 전혀 없으면 박스 전체 숨김
- native·crawled·공개 링크는 기존 `communityPostPath`·`communityCrawledPath`·`publicPostPath` 재사용
