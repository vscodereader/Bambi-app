## 개요

회원 프로필이 커뮤니티·채팅·고객센터에 일관되게 표시되도록 정리하고, 커뮤니티 익명·비회원 작성 정책과 운영자 신고 처리 흐름을 함께 개선했습니다. 페이지별 팝업 노출 설정과 운영자 채팅 신고 검토의 첨부파일 UI도 통합했습니다.

## 주요 변경

### 1. 회원 표시 이름과 프로필 사진

- 계정 설정에서 표시 이름과 JPG·PNG·WebP 프로필 사진을 등록하거나 기본 이미지로 초기화할 수 있습니다.
- 내 정보 프로필 카드 전체를 누르면 계정 설정으로 이동합니다.
- 커뮤니티 글·댓글, 채팅 참여자, 고객센터 문의·답변에 실제 계정 프로필을 표시합니다.
- 프로필 사진이 없거나 익명·비회원인 경우 글자 이니셜 대신 사람 아이콘 기본 프로필을 표시합니다.
- 채팅방 목록의 대표 이미지는 신규·기존 방 모두 말풍선 아이콘으로 유지하고 실제 대화 참여자 프로필과 분리했습니다.

### 2. 커뮤니티 익명·비회원 작성

- 자유수다·밤문화 이야기·중고거래·무료 법률 자문 작성 화면에 익명 선택을 추가했습니다.
- 일반 작성은 계정 표시 이름과 프로필 사진을 사용하고 작성자 입력을 수정할 수 없습니다.
- 익명 작성은 사용자 지정 별칭과 기본 프로필을 사용하며 계정 프로필 사진을 노출하지 않습니다.
- 본인인증이 완료된 비회원은 커뮤니티 글을 작성할 수 있고 작성자 이름은 `비회원`으로 고정됩니다.
- 최신 develop의 공용 비밀번호 수정 게이트를 유지하면서 익명 글 수정 시 `isAnonymous` 초기값도 복원합니다.
- 게시글 DB 저장 실패 시 1분 작성 제한을 소비하지 않도록 레이트리밋 적용 시점을 조정했습니다.

### 3. 운영자 콘텐츠와 신고 처리

- 운영자 게시글의 운영자 배지는 제거하고 운영자 댓글 배지는 유지합니다.
- 운영자가 작성한 글과 댓글에는 신고 버튼을 표시하지 않으며 직접 API 호출도 서버에서 거부합니다.
- 공고·채팅방·게시글·댓글 신고 기각 시 운영자가 처리 사유를 입력할 수 있습니다.
- 사용자의 내 신고 내역을 대상별 아코디언으로 구성하고 처리 대상 정보와 기각 사유를 함께 표시합니다.

### 4. 운영자 채팅 신고 검토와 첨부파일

- 신고된 채팅을 구인자 왼쪽·구직자 오른쪽으로 정렬하고 고정 높이 안에서 세로 스크롤하도록 변경했습니다.
- 첨부 이미지·PDF 줄은 대화 스크롤과 분리해 하단에 항상 표시합니다.
- 첨부 영역에서 가로 스크롤, 마우스 드래그, 모바일 스와이프를 지원합니다.
- 이미지는 작은 원본 비율 썸네일, PDF는 파일 아이콘 카드로 표시하고 클릭하면 원본을 새 탭에서 확인할 수 있습니다.

### 5. 고객센터 문의

- 1:1 문의 에디터에 복사한 내용을 붙여넣을 때 블록 HTML을 유지하지 않고 평문으로 현재 커서 위치에 삽입합니다.
- 문의 원문과 추가 메시지에 문의자·운영자의 표시 이름과 프로필 사진을 함께 표시합니다.

### 6. 페이지별 팝업 관리

- 팝업 위치를 버튼 묶음에서 중복 선택이 불가능한 콤보박스 행으로 변경했습니다.
- `위치 추가`로 여러 노출 위치를 추가하고 개별 위치를 삭제할 수 있습니다.
- 공통·개인회원·업소회원별로 실제 접근 가능한 페이지 이름만 표시합니다.
- 일반 커뮤니티·목록·게시판·게시글 상세 위치는 제거하고 자유수다·밤문화 이야기·중고거래·무료 법률 자문 목록에서만 팝업을 노출합니다.
- 이용 가이드·이용약관·개인정보 처리방침·알림 위치를 선택지에서 제거했습니다.
