## 주요 변경

### 모바일 본인인증 복귀·운영자 메뉴

- PortOne 모바일 리디렉션 이후 추가 클릭 없이 회원가입 폼으로 연결합니다.
- 데스크톱과 모바일 운영자 메뉴 목적지 정의를 통합했습니다.
- 채팅·면접 일정·팝업·사이트 정보 등 누락된 운영자 메뉴를 추가했습니다.
- 모바일 더보기 메뉴 스크롤과 하단 안전 영역을 보완했습니다.

### 신고 채팅 양측 차단

- 신고된 채팅방을 구직자와 구인자 양쪽에서 차단합니다.
- 신고 상태가 `open`·`reviewing`·`resolved`일 때 열람·발신·읽음 처리를 제한합니다.
- `dismissed` 기각 시 접근을 복구하고 `resolved` 처리 시 차단을 유지합니다.
- 신고 상태 변경 시 양쪽 참여자에게 실시간 갱신 신호를 보냅니다.
- 신고된 방을 채팅 목록·안 읽음 합계·하단 채팅 핀에서 제외합니다.

### 방 진입 즉시 읽음 처리

- 메시지 조회 완료 직후 서버 `markRead`를 호출합니다.
- 메시지를 보내지 않고 읽기만 해도 방별·계정 전체 안 읽음 수를 갱신합니다.
- 읽음 처리 성공 시 채팅 목록과 하단 채팅 핀 캐시를 함께 갱신합니다.
- 활성 채팅방에서 새 메시지를 받으면 즉시 읽음 처리합니다.

### 모바일 채팅 키보드 레이아웃

- 채팅 제목을 한 줄 말줄임 형태로 유지합니다.
- 공고 보기·상태·실시간 연결 정보를 제목 아래 별도 행에 배치했습니다.
- Visual Viewport를 기준으로 입력창을 소프트 키보드 위에 유지합니다.
- 메시지 목록만 남은 화면 높이 안에서 스크롤되도록 수정했습니다.

### 사업자 인증 서류 제출·검수

- 업소 회원이 사업자 인증 이미지 또는 PDF 서류를 여러 개 제출할 수 있습니다.
- 배포 후 신규 제출 및 반려 후 재제출 건에는 서류를 필수로 적용합니다.
- 반려 후 재제출하면 기존 서류를 삭제하고 새 서류로 교체합니다.
- 운영자 업소 관리에서 제출된 이미지와 PDF를 미리 보거나 다운로드할 수 있습니다.
- 파일 확장자·MIME·크기 정책을 API에서도 검증합니다.

### SEO 키워드 확장

- 여성알바·유흥알바·룸알바·밤알바 등 요청된 검색 키워드를 추가했습니다.
- 기존 키워드와 중복되는 값은 제거해 하나의 메타 keywords 값으로 제공합니다.
- 페이지 metadata에 확장된 키워드가 실제 반영되도록 연결했습니다.

### 테스트·문서
