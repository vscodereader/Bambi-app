## 목적

test.bambialba.com에서 구직자·구인자·운영자 화면을 함께 점검하며 발견한 운영자 내 정보, 신고 채팅, 팝업 링크, 공개 댓글 프로필과 게시글 댓글 제한 문제를 수정한다. 기존 프로필·신고 채팅·페이지별 팝업 기능은 유지하고 화면별 데이터와 권한을 일치시킨다.

설계·계획: `docs/superpowers/plans/2026-08-13-test-site-admin-community-chat-issues.md`

## 작업 내용

- 운영자 내 정보 프로필 카드에서만 운영자 뱃지 제거
- 운영자 신고 채팅에 사용자 채팅방과 동일한 동일 발신자·동일 분 메시지 그룹화 적용
- 운영자 신고 채팅 참여자에게 실제 계정 프로필 사진 표시
- 첨부 메시지 클릭 시 연결된 이미지·PDF를 하단 첨부 줄에서 자동 이동하고 2초간 테두리 강조
- 신고 대상이 채팅방이면 사용자 아이콘 대신 말풍선 아이콘 표시
- 팝업 링크에 localhost, bambialba.com과 모든 하위 도메인을 허용하고 유사 외부 도메인은 차단
- 비회원 공개 상세에서도 회원 댓글 작성자의 프로필 사진 표시
- 운영자 게시글 작성·수정에 댓글 작성 불가 설정 추가
- 댓글 제한 글의 기존 댓글은 유지하고 모든 계정의 신규 댓글·답글 작성 차단
- Drizzle migration으로 `community_post.comments_disabled` 추가 및 기존 글 기본값 유지
