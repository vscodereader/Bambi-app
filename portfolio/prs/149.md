## 개요

채팅의 이미지·PDF 첨부 UI를 콘텐츠 성격에 맞게 정리하고, 첨부와 문자를 함께 보낼 때 둘 다 하나의 요청에서 안전하게 저장되면서 첨부 → 문자 순서로 표시되도록 개선했습니다.

Closes #148

설계서: `docs/superpowers/plans/2026-08-12-chat-attachment-message-ui.md`

## 주요 변경

### 1. 이미지 첨부 UI

- 이미지의 색상 말풍선과 파일명·형식·용량 영역을 제거하고 이미지만 표시합니다.
- 발신자는 오른쪽, 수신자는 왼쪽의 기존 채팅 방향을 유지합니다.
- 원본 비율을 유지하며 데스크톱 최대 320px, 모바일 최대 `60vw`·240px·`50vh` 범위로 제한합니다.
- 작은 이미지는 원본보다 강제로 확대하지 않으며 클릭하면 원본을 새 탭에서 확인할 수 있습니다.

### 2. PDF 첨부 UI

- PDF를 밝은 테마의 파일 카드로 변경했습니다.
- 왼쪽 파일 아이콘, 파일명, `PDF · 용량`, 오른쪽 다운로드 버튼을 표시합니다.
- 긴 파일명은 한 줄 말줄임 처리하고 `title`로 전체 이름을 확인할 수 있습니다.
- 카드 전체 클릭과 다운로드 버튼 모두 파일 다운로드를 지원하며 기존 말풍선 배경과 그림자를 제거했습니다.

### 3. 첨부·문자 동시 전송

- 이미지 또는 PDF와 문자를 별도 메시지 종류로 유지하면서 하나의 `sendMediaMessage` 요청으로 전송합니다.
- 하나의 DB 트랜잭션에서 첨부 메시지·첨부 정보·문자 메시지를 함께 저장해 전체 성공 또는 전체 실패를 보장합니다.
- 첨부 메시지를 먼저, 문자 메시지를 1ms 뒤의 생성 시각으로 저장해 조회와 실시간 갱신에서 첨부 → 문자 순서를 보장합니다.
- 첨부·문자 각각의 클라이언트 메시지 ID를 사용해 동일 요청 재시도 시 중복 생성을 방지합니다.
- 기존 메시지 종류를 재사용하며 DB 스키마와 Drizzle migration 변경은 없습니다.

### 4. 시간·날짜 표시

- 같은 발신자가 같은 분에 연속해서 보낸 구간의 마지막 메시지에만 시간을 표시합니다.
- 다른 발신자가 끼어들면 같은 분이어도 새로운 구간으로 처리합니다.
- 시간은 말풍선 내부나 옆 공간이 아닌 콘텐츠 바로 아래에 `오후 12:29` 형식으로 표시합니다.
- 날짜가 바뀌면 모바일에는 날짜 칩, 데스크톱에는 연한 primary 구분선과 날짜 칩을 표시합니다.
- 이미지·PDF·문자와 구직자·구인자 채팅 모두 동일한 규칙을 사용합니다.
