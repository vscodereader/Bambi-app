## 요약
모바일 채팅에서 긴 한글·영문과 이미지·PDF 첨부가 말풍선 폭을 과도하게 늘리거나 카드 내부에서 잘리던 문제를 해결한다. 구인 관리 화면은 모바일에서 가로 스크롤이 필요한 표를 카드 목록으로 전환하고, 공고 카드의 바깥 여백과 점 3개 액션 위치를 작은 화면에 맞게 정리했다. 데스크톱(md+)의 기존 표·채팅 레이아웃과 상태·액션 로직은 유지한다.

## 모바일 채팅 말풍선·첨부
- 일반 텍스트 말풍선은 `<md`에서 채팅 본문 너비의 최대 60%, 첨부 말풍선은 최대 58%로 분리해 후속 메시지나 긴 문자열 때문에 기존 말풍선 폭이 다시 늘어나지 않게 했다
- 공백 없는 긴 한글·영문은 `overflow-wrap:anywhere`로 사용 가능한 말풍선 너비 안에서 줄바꿈하고, 사용자가 입력한 개행은 유지한다
- 이미지·PDF 첨부 카드의 모바일 강제 최소 너비를 제거하고 부모 말풍선 안에서 축소되도록 `min-w-0`·`max-w-full`·overflow 제약을 보강했다
- 긴 파일명은 한 줄 말줄임 처리하고, 본문·첨부 카드·전송 시간을 하나의 말풍선 안에 순서대로 배치했다
- 모바일 PDF 아이콘과 원형 전송 버튼 아이콘의 크기·정렬을 중앙에 맞췄으며 데스크톱 크기는 유지했다

## 모바일 구인 관리 카드
- `/employer` 내 공고, `/employer/promotions` 광고 관리, `/employer/analytics` 성과 분석, 멤버 관리를 `<md`에서 카드 목록으로 전환하고 `md+`에서는 기존 `DataTable`을 유지했다
- 내 공고 카드에 최근 수정순·제목순·급여순·상태순 정렬과 페이지당 10개 이전/다음 이동을 추가했다
- 공고 카드 영역 내부에 좌우 8px 여백을 적용해 모바일 화면 테두리에 카드가 붙지 않게 했다
- 내 공고·광고 관리의 점 3개 메뉴를 `CardAction`으로 제목 행 우측 상단에 배치해 메뉴가 아래 행으로 밀리며 생기던 빈 공간을 제거했다
- 기존 공개 여부·상태·끌어올리기 계산과 수정·삭제·관리 액션 컴포넌트를 카드와 데스크톱 표가 공유한다
