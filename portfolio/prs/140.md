## 목적
구인자 성과 분석의 공고별 `게재 구분`이 긴 문자열로 이어져 모바일과 데스크톱에서 상품별 노출 성과를 빠르게 구분하기 어려웠습니다. 각 구분의 명칭과 횟수를 색상별 뱃지로 표시해 가독성을 개선합니다.

## 작업 내용
- 일반·스페셜·급구·추천·프리미엄 배너 상단/좌측/우측에 서로 구분되는 고정 색상 적용
- `일반 81`, `프리미엄 배너·우측 0`처럼 명칭과 횟수를 하나의 뱃지 안에 표시
- 일반은 항상 표시하고 현재 구매 상품의 구분은 0회여도 유지하며, 과거 다른 상품의 실제 집계가 있으면 함께 표시하는 기존 정책 보존
- 모바일 공고 성과 카드와 데스크톱 성과 표에서 공통 `PlacementMetricBadges` 렌더러 사용
- 최신 develop의 `자동 재노출(7일)` 지표를 유지하면서 충돌 해소
- 설계서 `docs/superpowers/plans/2026-08-11-employer-analytics-placement-badges.md` 추가
