## 목적

test.bambialba.com 점검 중 댓글 작성 불가 공지에 의미 없는 `댓글 0`·빈 댓글 안내가 노출되고, 로그인 모달보다 공통 메인 팝업이 먼저 표시되는 문제를 수정합니다. 댓글 제한 글의 기존 댓글 열람 정책은 유지하면서 빈 댓글 영역만 숨기고, 팝업은 로그인과 회원 유형 확인이 끝난 뒤에만 노출되도록 정리했습니다.

설계·계획: `docs/superpowers/plans/2026-08-14-comment-lock-popup-auth.md`

## 작업 내용

- 댓글 작성 불가이면서 댓글이 0개인 회원·공개 게시글 상세에서 댓글 수, 빈 상태, 제한 안내와 작성 영역 전체를 숨겼습니다.
- 기존 댓글이 있는 제한 글은 댓글 열람을 유지하고 신규 댓글·답글만 기존 정책대로 차단합니다.
- 댓글 제한을 해제하면 댓글 영역과 작성 기능이 다시 표시됩니다.
- 비로그인 공개 팝업 API는 빈 목록을 반환하도록 변경했습니다.
- 클라이언트에서도 로그인 및 회원 유형 확인 전에는 팝업을 조회하거나 렌더링하지 않습니다.
- 로그인 후에는 공통 팝업과 현재 회원 유형 대상 팝업만 기존 정책대로 표시됩니다.
