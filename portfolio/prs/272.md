## 요약

게시판 목록·상세·댓글 등에 표시되는 회원 등급 뱃지에서 24px 아이콘의 위아래가 잘리던 문제를 해소한다.

## 원인

공용 `Badge`는 `h-5`(20px)와 `overflow-hidden`을 사용하지만 회원 등급 아이콘은 `size-6`(24px)이다. `GradeBadge`가 공용 높이를 그대로 사용해 아이콘이 뱃지보다 총 4px 커지고 위아래가 잘렸다.

## 작업 내용

- `GradeBadge`에서 공용 `Badge`의 고정 높이를 `h-auto`로 해당 사용처에서만 해제
- `min-h-5`로 아이콘이 없거나 로딩되지 않은 상태에서도 기존 최소 높이 유지
- 기존 `py-0.5`와 24px 아이콘이 실제 뱃지 높이를 콘텐츠 기반으로 결정하도록 구성
- `GradeIcon`의 `size-6`·`object-contain`, 뱃지 색상·간격·타이포 유지
- 공용 `Badge`와 다른 뱃지는 변경하지 않아 전역 레이아웃 영향 차단
- 콘텐츠 기반 높이와 기존 아이콘 크기를 보호하는 회귀 테스트 추가
