## 개요

회원가입·출석·게시판 활동의 포인트 정책을 운영자 설정으로 통합하고, 신규 공고 등록 시 작성자 본인의 포인트를 선택적으로 사용해 결제 예정 금액을 차감할 수 있도록 개선했습니다. 구직자·구인자는 내 정보와 포인트 내역에서 잔액·등급·출석·거래 내역을 확인하고, 운영자는 회원별 지급·차감·사용 내역과 처리자를 관리할 수 있습니다. 남성 구직자와 남성 법률자문가의 커뮤니티 접근 범위도 서버 정책과 화면에서 동일하게 제한했습니다.

Closes #209

설계·계획: `docs/superpowers/plans/2026-08-18-point-management-job-payment.md`

## 주요 변경

### 포인트 정책과 회원가입·활동 적립

- 운영자 포인트 관리에 출석 관리·등급 관리·회원 포인트 관리·기타 포인트 설정을 구성했습니다.
- 회원가입·출석·게시판별 글·댓글 포인트와 공고 결제 최소·최대 사용 포인트를 저장 후 적용하도록 했습니다.
- 구직자·구인자 본인인증 가입 완료 시 설정된 가입 포인트를 한 번만 지급하고, 로그인 화면의 가입 혜택 문구도 설정값에 맞춰 표시합니다.
- 최대 보유 포인트를 넘는 적립·환급은 상한까지만 반영하고 포인트 원장의 멱등키로 중복 지급·차감·환급을 방지합니다.

### 구직자·구인자 포인트 내역

- 내 정보의 `출석체크` 메뉴를 동전 아이콘의 `포인트 내역`으로 변경하고 기존 주소는 유지했습니다.
- 내 정보 상단에 보유 포인트·현재 등급·다음 등급까지 남은 포인트와 즉시 출석 버튼을 제공했습니다.
- 포인트 내역 페이지를 오늘 출석 → 기본 접힘 출석 달력 → 기본 접힘 보유 포인트 거래 내역 순으로 구성했습니다.
- 계정 설정의 포인트 내역을 새 화면으로 이동하고 운영자 지급 알림도 해당 아코디언으로 연결했습니다.

### 신규 공고 포인트 결제

- 신규 공고 등록 과정에서 공고 작성자 본인의 잔액·최소 사용 포인트·최대 사용 포인트·결제 예정 금액을 서버에서 재검증합니다.
- 직접 입력과 전액 사용을 지원하며, 공고·옵션 생성과 포인트 차감을 하나의 트랜잭션으로 확정합니다.
- 결제·공개 전 구인자 삭제는 최대 보유 상한 범위에서 환급하고, 한 번이라도 결제 완료 또는 공개된 공고는 환급을 잠급니다.
- 공고 수정 후 결제금액이 기존 사용 포인트보다 작아지면 저장을 차단하고, 운영자 결제 관리에도 포인트 차감 후 입금 예정 금액을 동일하게 표시합니다.

### 운영자 회원 포인트 관리

- 회원 목록에 닉네임·로그인 아이디 검색, 역할 필터, 등급·잔액, 10명 단위 숫자 페이지네이션을 제공합니다.
- 회원 상세에서 포인트 사용 내역, 전체 원장, 거래 후 잔액, 처리 운영자와 시스템 거래를 구분해 표시합니다.
- 필수 사유와 함께 포인트를 지급·차감하고, 지급 성공 시 회원에게 알림을 보냅니다.
- 사용자 관리와 포인트 관리의 역할을 분리하고 회원·업소·이메일·아이디 등 표 열과 모바일 채팅 내역 여백을 정리했습니다.

### 남성 회원 커뮤니티 접근 정책

- 일반 남성 구직자는 공지사항만 열람할 수 있습니다.
- 남성 법률자문가는 공지사항과 무료 법률 자문을 열람하고 기존 법률 게시판 글·댓글 작성 권한을 유지합니다.
- 목록·상세·글·댓글·추천 등 직접 API 접근도 동일한 공용 권한 정책으로 차단합니다.
