## 개요

운영자 크롤러의 커뮤니티 수집 결과를 밤문화 이야기에만 합치던 구조를 게시판별 독립 저장으로 확장한다. 운영자가 베스트를 제외한 DB 게시판 한 곳을 선택해 즉시·예약 수집하고, 수집 글과 원본 댓글을 기존 글·댓글 편집 UI로 수정할 수 있다.

Closes #293

## 작업 내용

### 게시판별 즉시·예약 수집
- 크롤러에 `수집할 게시판` 단일 Select 추가. `communityBoards.list`를 재사용해 신규·비활성·읽기전용 게시판을 재배포 없이 표시하고 가상 베스트는 제외
- 즉시수집은 화면의 현재 게시판, 예약 수집은 저장한 게시판을 회차 시작 시 고정해 실행 중 설정 변경의 영향 차단
- 수집 topic 중복 키를 `(source_site, source_external_id, board_key)`로 확장해 같은 원본도 게시판별 UUID·본문·수집 댓글·밤비 댓글·삭제 상태 독립
- 기존 topic은 ID와 댓글 FK를 유지한 채 `work_talk`로 backfill. 삭제·복구 및 게시판 삭제 가드도 topic ID·board FK 기준으로 연결

### 관리자 글·원본 댓글 편집
- 운영자 수집 목록과 수다방 수집 상세에서 관리자 편집 route 연결
- 기존 `CommunityPostForm`, Tiptap 편집기·이미지 업로드·읽기 전용 뷰어 재사용. 수집 평문은 HTML로 해석하지 않고 Tiptap paragraph 문서로 변환
- 관리자 편집 제목·본문·검색용 평문·작업자·수정일을 원본과 분리. 원본 수집 댓글에는 안정 ID를 붙이고 댓글별 편집 행을 별도 저장
- `editRevision` 조건부 UPDATE로 글·댓글 동시 편집의 늦은 저장을 거부하고 모더레이션 감사 기록 추가
- 재수집은 누락된 원본 필드만 보충해 관리자 편집값·댓글 ID·댓글 편집값 보존

### 표시·권한·목록 동기화
- 일반 게시판의 수정 글과 수정된 수집 댓글은 작성자 `ㅇㅇ` 및 크롤러 설정에서 선택한 기존 등급으로 표시. 댓글만 수정하면 글 작성자는 유지
- 전역 등급 FK를 사용해 이름·아이콘 변경과 등급 A→B 선택이 기존 편집 글·댓글에도 반영되며 등급 설정 변경만으로 수정일은 갱신하지 않음
- 글·수집 댓글 수정 시 `activityAt`을 갱신해 자체 글과 수정일 기준 최신순으로 정렬하고 30일 노출 기간 재시작
- 비밀게시판은 수정 전부터 기존 reader/actor·잠금 정책과 `밤비·여성` 표시를 적용. 포인트 열람 기능은 추가하지 않음
- 목록·검색·totalCount·홈 미리보기·이전/다음글·상세·밤비 댓글 API를 topic의 실제 게시판과 동일한 날짜·권한 조건으로 통일

### DB migration
- 최신 develop의 `0115_user-presence` 다음 `0116_crawled_community_board_editing`
- 목적 게시판·관리자 편집 메타·revision·활동시각, 수집 댓글 편집 테이블, 예약 목적지·편집 등급 설정, 회차 목적 게시판 추가
