fix: 신고 처리 사유와 팝업 노출 흐름 개선

- 신고 기각·처리 사유 입력에 500자 제한과 글자 수 표시를 적용하고, 서버 검증 실패가 무음으로 끝나지 않도록 오류 안내를 추가
- 신고 처리 mutation이 성공한 경우에만 목록으로 이동하도록 정리해 실패한 요청의 화면과 대기 상태를 유지
- 운영자 신고 상세에 신고자가 작성한 신고 내용을 원문과 조치 입력 영역 사이에 표시
- 커뮤니티 신고는 조치 사유 입력 후 숨기기 또는 삭제를 직접 선택하고, 실제 대상 조치가 성공한 뒤에만 신고를 처리 완료로 전환
- 커뮤니티 신고의 기각 기능은 별도로 유지하고, 조치 사유가 2자 미만이면 숨기기·삭제를 실행할 수 없도록 제한
- 사용자 신고 내역을 원글 → 신고 내용 → 기각 사유 또는 조치 순서로 표시하고 처리 완료 명칭을 조치로 통일
- 같은 사용자가 같은 대상을 접수됨·검토 중 상태에서 다시 신고하면 글·댓글·채팅방·공고별 안내 문구로 차단
- 처리 완료·기각된 신고의 재신고와 다른 사용자의 동일 대상 신고는 기존 정책대로 허용
- 로그인 화면과 인증 전환 중에는 팝업 조회·렌더링을 막고 목적지 페이지 로딩 완료 후 한 번만 표시
- 운영자 계정과 /moderator 경로에서는 팝업 목록을 반환하거나 렌더링하지 않도록 서버·웹 양쪽에서 차단
- 관련 회귀 테스트와 구현 계획 문서를 변경된 신고·팝업 정책에 맞게 갱신
