## 주요 변경

### 운영자 가계정 생성

- `회원 관리 → 계정 생성` 화면과 admin 전용 API 추가
- `user`·credential `account`·`bambi_profile`·감사 로그를 단일 트랜잭션으로 생성
- 실패하면 전부 롤백하고 운영자 세션은 유지
- PW·내부 이메일·CI/DI는 응답에 노출하지 않음

### 역할·인증 정책 연결

- 여성 구직자는 일반 수다방과 구직 기능 이용
- 남성 구직자는 공지사항·비밀게시판 범위만 이용
- 구인자는 업체 승인 전 공고 기능 차단, 승인 후 허용
- 회원 인증 정본을 `isPhoneVerified + gender + phoneNumber`로 통일
- 비회원은 기존 인증 로그·보존기간 판정 유지

### 로컬 미디어 정합성

- 운영 환경만 GCS 서명 URL 사용
- 개발 환경의 공고·본문·채팅 이미지/PDF·사업자 서류는 실제 원본을 로컬 PUT/GET
- 기존 GCS·신규 local·중간 형식 local 공고 key 모두 호환
- 로컬 원본 우선 조회 후 없으면 기존 GCS 공개 URL로 연결
- MIME·용량·파일 시그니처·경로 탈출 검사를 공용 정책으로 통합

### 신고 후처리 오류

채팅 신고 행이 저장된 뒤 실시간 갱신 쿼리가 JOIN하지 않은 `community_post` 컬럼을 SELECT해 500을 반환하던 문제를 수정했다. 신고 저장·실시간 갱신·알림까지 성공 응답으로 완료한다.

### 하드코딩 정리

- 비밀번호 최소 길이
- 커뮤니티 제목·작성인·잠금 비밀번호
- 사업자 서류 최대 개수
- 미디어 MIME·10MB
- storage key root·로컬 URL
- 역할·성별·감사 액션
- 성인 나이·안내 문구

위 정책을 각각 공용 정본으로 통합했다.
