## 요약

구인자가 필수 상세설명과 구조화 블록을 함께 입력했을 때 기본 상세설명이 저장 전에 사라지던 문제를 수정한다. 운영자 검수 화면에는 실제 공개 공고와 같은 본문 렌더링을 기본 접힘 아코디언으로 제공하고, 기존 이미지 썸네일 배치는 유지한 채 확대 화면에서 상세 이미지를 읽을 수 있는 크기와 비율로 스크롤 확인할 수 있게 한다.

## 주요 변경

### 상세설명 저장·구버전 호환
- Web 폼과 API 저장 경계에서 `description`(기본 상세설명)과 `descriptionBlocks`(문단·제목·목록·강조)를 각각 보존 — 블록 존재 시 기본 설명을 블록 평문으로 덮어쓰던 로직 제거
- 금칙어 검사는 제목·기본 상세설명·블록 합성본·면접 안내·배너 문구 전체에 적용
- 기존 공고에서 `description`이 블록 평문 합성본과 같으면 구버전 행으로 판정해 같은 본문을 두 번 표시하지 않음
- 검수용 평문은 기본 상세설명과 블록 전체를 조합해 실제 감지 문구가 블록에 있어도 강조 가능

### 공개·운영자 공용 본문
- `JobDescriptionContent` 공용 컴포넌트 추출 — 공개 공고와 운영자 검수가 같은 문단·제목·목록·강조 마크업과 순서를 사용
- 운영자 검수 상세에 기본 접힘 `공고 내용` shadcn Accordion 추가
- 서버 `detectedTerms`가 실제로 있을 때만 `공고 본문 · 감지 표현 강조`를 표시해 정상 공고에서 아코디언 본문과 평문이 중복되지 않음
- 관리자 단건 조회의 로딩·오류 상태를 본문 미리보기와 미디어에 함께 배선

### 상세 이미지 검수
- 기존 `공고 이미지 N장` 통합 썸네일 그리드 유지: 대표 이미지 첫 번째, 상세 이미지가 뒤를 잇는 기존 순서와 `grid-cols-2 lg:grid-cols-3`·`aspect-video`·`object-cover` 불변
- 공개·운영자 공용 `JobDetailImage` 추출 — 저장된 원본 width/height 우선, 치수가 없는 구버전 행만 기존 1200×1600 규격 fallback
- 확대 모달의 고정 `70vh`·`fill`·`object-contain` 제거, 본문 폭 `max-w-3xl`에서 원본 비율 `h-auto w-full`로 표시
- 공용 Dialog의 `overflow-y-auto`·`overscroll-contain`을 사용해 데스크톱 우측 스크롤바와 모바일 터치 스크롤 제공

### 테스트 정리
- 본문 저장·구버전 호환·공용 렌더링·관리자 데이터 배선·기본 접힘·기존 이미지 배치·확대 모달 회귀 테스트 추가
- 공고 생성 알림의 actor FK를 먼저 정리하도록 미디어 통합 테스트 cleanup 보완
