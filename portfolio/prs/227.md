## 변경 내용

### 비밀글 읽기·쓰기 권한 분리
- 성별·생년월일이 없는 활성 회원도 비밀글 목록·상세·댓글 읽기 허용
- 비밀글 글·댓글 작성은 기존 성인 본인인증·성별 확인 요건 유지
- 일반 게시판과 비회원의 기존 접근 정책 유지

### 구인자 공고 포인트·결제 UI
- 포인트 사용을 끌어올리기 옵션 바로 아래로 이동
- 결제 예정 금액과 무통장 입금 안내에 `광고 + 옵션 - 포인트` 차감 반영
- 하단의 중복 결제 예정 금액·최종 입금액 요약 제거
- 내 공고의 관리 열과 액션 버튼을 열 중앙으로 이동

### 수다방 홈·운영자 배치
- 수다방 첫·마지막 카드의 좌우 border가 잘리지 않도록 공용 최소 여백 적용
- 운영자 홈 배치에서 1행은 공지사항 전용, 2행 1열은 베스트글로 고정
- 고정 슬롯 제거·이동·덮어쓰기를 UI와 API 양쪽에서 차단
- 나머지 행·열의 추가·제거·drag-and-drop 유지

### 구직자·구인자 글 관리
- 좋아요 글·작성 글을 각각 기본 닫힌 독립 Accordion으로 변경
- 각 목록의 10건 페이지네이션 유지
- `게시판 / 제목 / 날짜` 3열과 포인트 내역 반응형 글자 크기 재사용
- 헤더·게시판·날짜는 중앙, 실제 글 제목은 좌측 정렬
- 행별 primary 배경 제거 및 삭제·이동 snapshot 안내 유지
- 좋아요 글과 작성 글 모두 원글 작성일 표시

## DB 변경
