## 요약

메인 팝업의 대상별 노출과 내부 링크 이동을 확장하고, 운영자 공지사항에 이벤트 게시물 유형을 추가했습니다. 광고 상품은 가격 옵션별 예약 할인을 독립적으로 설정할 수 있으며, 서버가 최종 결제 요청 시각을 기준으로 적용 가격을 확정합니다.

## 주요 변경

### 메인 팝업 대상 노출·링크

- 공통·개인회원·업소회원 중 하나를 게시 대상으로 지정할 수 있습니다.
- 비회원에게는 공통 팝업만, 로그인 사용자에게는 회원 유형과 승인 상태에 맞는 팝업만 노출합니다.
- 이미지형 팝업에 밤비 내부 주소를 연결하고, 비로그인 상태라면 로그인 후 원래 목적지로 복귀합니다.
- 운영자 설정 카드를 여러 개 동시에 접고 펼칠 수 있으며 브라우저가 펼침 상태를 기억합니다.
- 접은 상태에서도 저장 전 입력값을 유지합니다.
- 업소회원 가입 6개월 광고비 50% 할인 홍보 이미지를 운영 문서 자산으로 추가했습니다.

### 이벤트 공지사항

- 운영자 공지 작성·수정 화면에 이벤트 설정을 추가했습니다.
- 이벤트와 비밀글은 동시에 설정할 수 없습니다.
- 이벤트 게시물은 공지사항 상단에서 이벤트 최신순으로 노출합니다.
- 공지사항 목록에서 이벤트 태그와 옅은 primary 배경으로 일반 공지와 구분합니다.

### 광고 상품 기간 할인

- 각 이용기간 가격 옵션마다 기간 할인 시작·종료·할인율을 독립적으로 설정합니다.
- 시작 시각은 필수이고 종료 시각은 선택 사항이며, 종료 미설정 시 무기한으로 적용합니다.
- 예정·진행 중·종료 상태와 설정 이력을 DB에 보존합니다.
- 종료 후에는 기존 기본 할인율이 자동으로 다시 적용됩니다.
- 구매 화면에 현재 적용 가격과 할인 기간을 함께 표시합니다.
- 결제 요청 시 서버 도착 시각을 기준으로 가격을 다시 계산하여 화면과 결제 가격 불일치를 방지합니다.
- 운영자 광고 상품 목록을 옵션별 1열 배치로 정리하고 상품 접기·펼치기를 추가했습니다.

### 권한·회귀 방지

- 팝업 운영과 광고 기간 할인 API의 운영자 권한을 서버에서 검증합니다.
- 팝업 대상 판별, 기간 할인 가격 계산, 화면 표시 관련 테스트를 보강했습니다.
- 최신 develop을 반영하고 커뮤니티 정책 및 서버 업로드 제한 변경과의 충돌을 함께 해소했습니다.
