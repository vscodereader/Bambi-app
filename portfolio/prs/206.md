## 수정 내용

### 이용정지 회원의 운영자 문의 예외

- 이용정지된 구직자와 구인자 모두 운영자 1:1 문의의 조회, 새 대화 생성, 메시지 발신을 허용했습니다.
- 수다방 등 기존 제한 기능은 계속 차단하고, 이용정지 구직자가 커뮤니티에 접근하면 `차단된 유저는 확인이 불가합니다` 안내를 표시합니다.
- 이용정지 구인자의 신규 공고 등록 버튼을 비활성화하고 `/employer/new` 직접 접근에도 한국어 이용정지 안내 화면을 표시합니다.

### 탈퇴 회원 신고 채팅 열람

- 신고 채팅 참가자가 탈퇴했어도 운영자가 기존 이름과 탈퇴 상태를 확인할 수 있게 했습니다.
- 탈퇴 여부와 관계없이 전체 대화와 첨부파일을 운영자 화면에서 열람할 수 있게 했습니다.

### 운영자 페이지네이션과 확인창

- 공용 페이지네이션을 `< {현재 페이지 입력} / {총 페이지 수} >` 구조로 보강해 각 목록의 총 페이지 수를 표시합니다.
- 사용자 제재 이력을 최신순, 페이지당 10건으로 서버 페이지네이션했습니다.
- 제재 적용 및 최근 경고 되돌리기 확인창을 데스크톱과 모바일 모두 현재 viewport 중앙에 표시합니다.

### 문서와 회귀 테스트

- 구직자·구인자·운영자 매뉴얼과 테스트 플로우를 최신 동작에 맞게 수정했습니다.
- 운영자 문의 권한, 탈퇴 회원 채팅, 제재 이력 페이지네이션 및 Web UI 계약 회귀 테스트를 추가했습니다.
