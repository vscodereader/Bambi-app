## 요약
native 운영자 기능을 기능별 PR로 분리하기 위한 공통 셸·다이얼로그·정책과 Android 파일 저장 기반을 추가합니다. 후속 기능 PR은 이 PR이 `mobile`에 반영된 뒤 병합합니다.

## 변경
- **운영자 셸**: admin 역할 가드 아래 검수·신고·사용자 3탭과 업무별 더보기 메뉴를 구성하고 상세 화면은 Stack push·기본 뒤로가기로 목록 문맥을 유지
- **공통 UI**: 확인·사유·제재·필터·선택·조회 상태 컴포넌트와 내비게이션·쿼리·포그라운드·작성 이탈 유틸리티 공용화
- **공유 정책**: web 검수·신고·사용자 라벨과 사유 프리셋을 `packages/api/services`로 승격하고 web 재수출 경로 유지
- **Android 저장**: `moneyroad-app`과 같은 SDK 56 SAF 폴더 선택 방식 적용. 최초 권한 승인 뒤 SecureStore URI 재사용, 같은 파일명 교체, 취소·불완전 기록 성공 표시 차단
- **저장 결함 수정**: `ACTION_CREATE_DOCUMENT` 결과가 URI 대신 `Intent {...}` 문자열로 돌아와 0바이트 파일을 만들던 경로 제거, data URL 바이트 복원 추가

## 검증
- pre-commit ultracite/biome 통과
- native 저장 정책 테스트 10건 통과
- Android 에뮬레이터에서 `Download/Bambi`에 45,383바이트 이미지 저장·동일 파일 재저장·취소 확인

## 후속 PR 병합 조건
검수·신고·사용자·공고·채팅·포인트·콘텐츠·고객센터·팝업·크롤링 등 기능 PR은 이 PR이 `mobile`에 머지된 뒤 병합해야 합니다.

## 배포 메모
DB 마이그레이션 없음. Expo SDK 56 기본 `expo-file-system`과 기존 `expo-secure-store`를 사용합니다.
