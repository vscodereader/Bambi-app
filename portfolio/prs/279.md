## 요약
신규 가입 직후 역할별 온보딩을 제공하고, 실제 화면 구조를 재사용한 읽기 전용 미리보기·애니메이션·코치마크를 추가합니다. 구직자·구인자·공통 온보딩은 포인트몰 안내를 포함해 각각 5페이지입니다.

## 주요 변경
- 구직자: 공고 탐색, 채팅·첨부, 면접·연락처, 후기, 포인트몰
- 구인자: 업체 정보, 공고 등록, 지원자 채팅, 면접·지원자 관리, 포인트몰
- 공통: 채팅·첨부, 면접·연락처, 알림·쪽지, 신고·차단, 포인트몰
- 상품 선택 → 구매 창 → 구매 완료 → 마이페이지 포인트 내역을 API 호출 없는 로컬 시뮬레이션으로 재현
- 배민 5만원 상품권 예시 이미지와 주문완료·50,000P 차감·휴대폰 발송 안내 표시
- 모바일 전용 제목 `포인트로 실제\n상품권 구매까지!`와 설명 줄바꿈 적용, 데스크톱은 한 줄 유지
- 설정 다시 보기, 신규 가입 1회 노출, 역할별 코치마크 및 관련 문서·회귀 테스트 동기화
