# Queenalba 채용정보 노출 벤치마킹 정리

작성일: 2026-06-29

사용자가 제공한 Queenalba PC 웹 캡처 PDF를 기준으로 채용정보 노출 방식을 확인했다.

PDF는 2026-06-26 16:00 KST에 생성된 3페이지짜리 웹 캡처다. 실제 서비스 계정 로그인이나 추가 탐색은 진행하지 않았다.

## 2. 핵심 인상

Queenalba의 강점은 목록을 정돈된 채용 카드로만 보여주는 것이 아니라, 메인 화면 전체를 채용 광고판처럼 구성한다는 점이다.

Foxalba가 `공고가 많이 보이는 밀도`와 `광고 상품 운영`을 보여줬다면, Queenalba 캡처는 `시각적으로 강한 광고형 채용 노출`에 더 가깝다. 구직자가 상세 페이지에 들어가기 전에도 업체 로고, 배너형 이미지, 급여, 지역, 업종, 남은 기간을 빠르게 훑을 수 있도록 설계되어 있다.

다만 캡처 원본은 네온색, 굵은 테두리, 사이드 고정 배너, 반복 광고, 매우 높은 정보 밀도를 사용한다. 이 방식을 그대로 복제하면 Bambi의 안전 중심·신뢰 중심 톤이 약해질 수 있으므로, 밤비에는 `광고판형 노출 구조`만 가져오고 시각 표현은 더 절제해야 한다.

## 3. 화면 구조

캡처에서 확인한 주요 구조는 다음과 같다.

- 상단 로고, 검색, 고객센터, 구인 등록 버튼
- 넓은 보라색 내비게이션 바
- 상단 대형 배너 광고
- 로그인 박스와 복수의 그래픽 배너
- 커뮤니티성 게시판 영역
- `우대채용정보`
- `프리미엄채용정보`
- `스페셜채용정보`
- `급구채용`
- `추천채용`
- `최신인재정보`
- 좌우 사이드 배너와 모바일 버전 유도 배너
- 하단 고객센터/회사 정보/입금 안내

채용정보는 하나의 동일한 리스트가 아니라 여러 광고 등급 섹션으로 나뉜다. 섹션마다 카드 크기, 배경색, 테두리, 이미지 사용량, 노출 밀도가 다르다.

## 4. 채용 카드 패턴

Queenalba의 채용 카드는 다음 요소를 매우 압축적으로 담는다.

- 업체 로고 또는 배너 이미지
- 업체명 또는 홍보 문구
- 지역
- 업종
- 급여
- 남은 기간 또는 광고 기간
- `급구`, `추천`, `프리미엄` 같은 상품/상태 표시
- 작은 아이콘과 컬러 라벨

특히 `프리미엄채용정보`와 `스페셜채용정보`는 카드 자체가 작은 이미지 광고처럼 보인다. 구직자는 텍스트를 정독하기보다 시각 신호를 보고 빠르게 클릭 대상을 고르게 된다.

## 5. 밤비에 가져올 점

이번 캡처에서 Bambi에 반영할 만한 점은 다음이다.

- 메인/구직자 탐색 화면에 공고가 더 많고 활발하게 보이도록 `광고형 채용 섹션`을 추가한다.
- 기존 `프리미엄`, `추천`, `일반` 섹션 외에 `스페셜`, `급구` 같은 시각적 노출 그룹을 UI 레벨에서 표현한다.
- 대표 이미지가 있는 공고는 작은 썸네일 row뿐 아니라 배너형 compact card로도 노출한다.
- PC에서는 4열 또는 5열 compact grid를 사용해 한 화면 노출량을 늘린다.
- 모바일에서는 2열 compact card 또는 가로 스크롤 spotlight row로 변환한다.
- 각 섹션은 광고 상품/프로모션 상태와 연결되어야 하며, 구직자에게는 `프리미엄`, `추천`, `급구`처럼 투명한 라벨로 표시한다.

## 6. 밤비에서 제외할 점

그대로 가져오지 않을 요소는 다음이다.

- 깜빡이거나 과도하게 화려한 배너
- 좌우 고정 사이드 광고
- 서로 충돌하는 네온색 팔레트
- 공고 제목보다 광고 이미지가 모든 정보를 압도하는 구성
- 안전/검수 라벨이 묻히는 정도의 과밀 UI
- 사용자에게 광고 순위 조작처럼 보일 수 있는 불투명한 노출

밤비의 방향은 `더 많이 보이고 더 강하게 노출하되, 신뢰와 검수 신호는 유지하는 광고형 채용 UI`다.

## 7. 권장 1차 방향

1차 개선은 DB 상품 구조를 새로 크게 늘리기보다, 기존 promotion tier와 cover image 데이터를 활용해 Web UI를 재구성하는 방식이 좋다.

추천 방향:

- `/`와 `/seeker`에 `스페셜 채용`, `급구 채용`, `추천 채용`, `전체 공고` 섹션을 추가한다.
- `premium` 공고는 `스페셜 채용` 또는 `프리미엄 채용` compact grid에 우선 노출한다.
- `recommended` 공고는 `추천 채용` grid나 row에 노출한다.
- `lastBoostedAt`이 최근인 promoted 공고는 `급구 채용` 섹션에 일부 노출한다.
- organic 공고는 현재 dense list 구조를 유지하되, 카드 높이와 정보 배치를 더 압축한다.
- 구인자 화면에는 “대표 이미지가 목록에서 어떻게 보이는지” 미리보기 영역을 제공한다.

## 8. 성공 기준

구현 후 성공 기준은 다음이다.

- PC 첫 화면에서 기존보다 더 많은 공고가 보인다.
- 시각적으로 `광고 상품이 노출되고 있다`는 느낌이 생긴다.
- Bambi의 안전/검수/연락처 보호 메시지가 사라지지 않는다.
- 모바일에서 텍스트가 겹치거나 카드가 과하게 좁아지지 않는다.
- 프로모션 라벨과 실제 API promotion tier가 서로 어긋나지 않는다.
