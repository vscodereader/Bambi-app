# 모바일 채팅 첨부 말풍선 레이아웃 수정 계획

## 로컬 채팅 첨부 업로드 회귀 수정

- GCS 버킷이 설정된 환경에서는 개발·운영 구분 없이 서명 URL에 실제 첨부파일을 업로드한다.
- 채팅 메시지의 이미지 미리보기와 PDF·파일 링크는 저장된 GCS 원본 URL을 사용한다.
- GCS가 설정되지 않은 개발 환경에서만 기존 `local://` 업로드 의도와 로컬 미리보기 URL을 사용한다.
- 로컬 개발 서버는 서비스 계정 impersonation ADC로 서명 URL을 발급하며 JSON 키 파일을 추가하지 않는다.
- 업로드 없이 placeholder만 저장된 기존 메시지는 원본을 복구할 수 없으므로 인증 적용 후 다시 전송한다.
- PDF 허용 정책, 파일 크기·개수 제한 및 모바일 말풍선 레이아웃은 변경하지 않는다.

**Goal:** 768px 미만 모바일 채팅방에서 전송 아이콘을 중앙에 배치하고, 긴 첨부파일과 메시지 본문이 화면 밖으로 잘리지 않은 채 하나의 말풍선 안에 표시되도록 수정한다.

**Architecture:** 최신 `develop` 기반 `fix/mobile-chat-attachment-layout` 브랜치에서 기존 `ChatMessageBubble`, `ChatAttachmentPreview`, 모바일 `ChatComposer`를 재사용한다. 변경은 Tailwind의 `max-md` 변형으로 제한해 데스크톱 레이아웃을 유지한다.

## 확정 요구사항

- 첨부 카드와 전송 아이콘 변경 범위는 768px 미만 모바일 화면뿐이며 데스크톱 UI는 유지한다.
- 이미지와 PDF 첨부 카드는 사용 가능한 말풍선 너비 안에서 축소되어 320px 이상 일반 모바일 화면에서 가로로 잘리지 않아야 한다.
- 긴 파일명은 모바일에서 한 줄만 표시하고 이후 내용은 `…`으로 처리한다.
- 메시지와 첨부파일을 함께 전송하면 모바일 말풍선 안에 `메시지 본문 → 첨부파일 카드 → 전송 시간` 순서로 표시한다.
- 공백 없는 긴 영문·숫자 문자열은 모바일과 데스크톱 모두 말풍선의 사용 가능한 너비에서 줄바꿈하며, 화면이나 상대방 대화 영역을 침범하지 않는다.
- 모바일 일반 텍스트 말풍선은 채팅 본문 너비의 60%를 넘지 않으며, 긴 한글·영문을 입력해도 그 경계보다 왼쪽으로 확장되지 않는다.
- 뒤에 새 메시지가 추가되어도 앞선 메시지 말풍선의 너비와 줄 수가 다시 계산되어 달라지지 않도록 각 말풍선의 폭 계산을 독립적으로 고정한다.
- 영문을 고정 글자 수마다 임의 분리하지 않고 실제 말풍선 너비를 기준으로 줄바꿈한다. 한글의 기존 줄바꿈과 사용자가 입력한 개행은 유지한다.
- 모바일 원형 전송 버튼의 말풍선 아이콘은 버튼의 광학적 중앙에 배치한다.

## 구현

1. `chat-attachment-preview.tsx`
   - 모바일에서 링크·미리보기·메타 영역에 `min-w-0`, `max-w-full`, `overflow-hidden`을 적용한다.
   - 이미지 미리보기의 데스크톱 최소 너비는 유지하고 모바일에서만 최소 너비를 해제한다.
   - 파일명은 모바일에서 두 줄 말줄임, 데스크톱에서는 기존 한 줄 말줄임을 유지한다.
2. `seeker-chat-room-responsive.tsx`
   - 첨부가 있는 모바일 메시지에도 비어 있지 않은 본문을 첨부 카드보다 먼저 표시한다.
   - 첨부 말풍선과 내부 그리드가 부모 최대 너비를 넘지 않도록 모바일 너비 제약을 추가한다.
   - 모바일 전송 버튼 아이콘 래퍼를 정중앙 정렬하고 광학 위치를 미세 보정한다.
   - 메시지 본문에 `overflow-wrap: anywhere`를 적용해 공백 없는 긴 영문도 모바일·데스크톱 말풍선 내부에서 줄바꿈한다.
   - 말풍선과 내부 flex 영역에 독립적인 최소·최대 너비 제약을 적용해 후속 메시지 추가에 따른 기존 말풍선 폭 변동을 막는다.
3. 검증
   - 관련 웹 TypeScript 검사와 변경 파일 Biome 검사를 실행한다.
   - 320px, 375px, 390px, 412px 폭에서 긴 PDF 파일명·이미지 첨부·본문 동시 전송 레이아웃을 확인한다.
   - 768px 이상에서는 기존 말풍선과 첨부 카드 스타일이 유지되는지 확인한다.

## 구현 결과

### 모바일 첨부 말풍선 폭·아이콘 보완

- 768px 미만에서 첨부파일이 있는 메시지 말풍선의 최대 너비는 채팅 본문 너비의 58%로 제한한다.
- 768px 미만에서 첨부파일이 없는 일반 텍스트 말풍선의 최대 너비는 채팅 본문 너비의 60%로 제한한다.
- 긴 파일명은 카드의 고유 너비를 늘리지 않으며 한 줄만 표시한 뒤 말줄임표로 처리한다.
- PDF 파일 아이콘은 모바일에서 원형 배경보다 작게 축소하고 가로·세로 중앙에 배치한다.
- 768px 이상 데스크톱의 말풍선 너비와 아이콘 크기는 기존 동작을 유지한다.
- 360px 및 375px 화면에서 발신 첨부 카드가 대화 영역 중앙을 과도하게 침범하지 않는지 확인한다.

- 모바일 첨부 카드의 강제 최소 너비를 해제하고 말풍선 너비 안에서 축소되도록 수정했다.
- 모바일 파일명은 두 줄 말줄임으로 변경하고, 본문·첨부 카드·전송 시간을 하나의 말풍선 안에 배치했다.
- 모바일 전송 아이콘의 광학 위치를 미세 조정했으며 데스크톱 분기는 유지했다.
- 변경 파일 Biome 검사와 `pnpm.cmd --filter web exec tsc --noEmit` 검사를 통과했다.
