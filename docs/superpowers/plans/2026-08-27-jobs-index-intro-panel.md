# `/jobs` 소개 패널·프리미엄 광고 레일 계획

> **For agentic workers:** 정확히 공개 인덱스 `/jobs`의 소개 영역 시각 표현과 좌·우 프리미엄 광고 레일만 변경한다. 실루엣·임의 장식·애니메이션은 추가하지 않는다.

**Goal:** `/jobs`의 기존 소개 영역을 밤비 코럴 테마의 소프트 패널로 정돈하고, 로그인 후 메인페이지와 동일한 프리미엄 광고를 좌·우 레일에 노출한다.

**Architecture:** 최신 `develop`에서 분리한 `feat/jobs-moon-ad-rail` 브랜치를 사용한다. `PublicJobLanding`의 서버 컴포넌트·공고 조회·SEO HTML은 유지하고, `region`과 `industry`가 모두 없는 인덱스의 기존 header에만 디자인 토큰 클래스를 조건부 적용한다. 광고 데이터 훅 때문에 필요한 최소 클라이언트 경계를 별도 레이아웃 컴포넌트로 두고, 메인페이지의 `HorizontalAdBannerRail`·`AdBannerRail`과 `useAdBannerJobs`를 그대로 재사용한다.

## 확정 범위

- 소개 소프트 패널은 `/jobs`, `/jobs/[region]`, `/jobs/[region]/[industry]`에 공통 적용한다. `/jobs/guide`는 변경하지 않는다.
- 소개 소프트 패널의 코럴 배경·테두리는 모바일과 데스크톱 모두 유지한다. 공고 카드 폭 축소 문제는 패널이 아니라 광고 레일 flex 축소로 해결한다.
- 모바일 소개 패널은 테두리를 본문보다 좌우 8px 바깥에 두고 내부 좌우 패딩도 8px만 사용해, 기존 본문 시작선과 가용 너비를 유지한다. `md` 이상은 기존 32px 패딩을 유지한다.
- 모바일에서는 `/jobs` 소개 제목만 가운데 정렬하고 breadcrumb·설명은 기존 정렬을 유지한다. 패널의 breadcrumb와 설명은 Tailwind `text-xs`, 제목은 `text-xl`을 사용하며 `md` 이상에서는 기존 `text-sm`·`text-3xl`로 복원한다.
- 모바일에서는 `/jobs` 소개 제목과 두 회원가입 CTA(`회원가입하기`, `회원가입하고 시작하기`)를 가운데 정렬한다. CTA는 `md` 이상에서 기존 왼쪽 정렬로 복원한다.
- 초광폭 화면(`min-[1720px]`)에서 메인페이지와 동일한 좌측 가로형 3칸·우측 세로형 3칸 광고 레일을 노출한다.
- 가운데 `PremiumAdBannerSection`은 렌더하지 않는다.
- 좌우 레일은 판매 여부와 무관하게 대칭 공간을 유지하고, 로딩·빈 슬롯·클릭·GA4 계측 동작은 기존 컴포넌트에 위임한다.
- 광고 레일은 기존 중앙 콘텐츠와 공고 카드 폭을 축소하지 않고 바깥 여백에 배치한다.
- breadcrumb, h1, 소개 문단 2개, 회원가입·채팅 버튼의 문구·순서·링크·활성 상태를 유지한다.
- 공고 건수와 공고 목록 이후 콘텐츠는 변경하지 않는다.
- 공개 랜딩 공고 카드는 메인 공고 카드의 가로 썸네일 리듬을 재사용한다. 블러 썸네일 오른쪽에 `공고 제목 → 소속·위치 → 업종·인증`, 카드 하단에 `급여(왼쪽) ↔ 당일면접·초보 가능(오른쪽)`을 배치한다. 근무시간은 공개 카드에서 제외한다.
- 카드는 그리드 행 높이를 채우고 급여 줄에 `mt-auto`를 사용해 같은 행의 급여 위치를 맞춘다. 썸네일과 제목 열은 `gap-4`, 썸네일 행과 급여 줄은 `pt-2`로 분리한다. 당일면접·초보 가능은 실제 값이 참일 때만 표시한다.
- 기존 `rounded-2xl`, `border`, `primary`, spacing 토큰만 재사용한다.
- 실루엣, 이미지, 사이드 장식, 애니메이션은 두지 않는다.
- DB·API·env·마이그레이션 변경은 없다.
