# 회원 등급 아이콘 잘림 수정 계획

관련 이슈: #271

## 문제

- 공용 `Badge`는 `h-5`(20px)와 `overflow-hidden`을 사용한다.
- 회원 등급 아이콘은 `size-6`(24px)이므로 게시판 목록·상세·댓글에서 위아래가 잘린다.
- 공용 `Badge` 높이를 변경하면 사이트 전역의 다른 뱃지까지 영향을 받는다.

## 목표

- 회원 등급 아이콘의 24px 크기와 원본 비율을 유지한다.
- 아이콘 크기에 맞춘 별도 고정 높이를 추가하지 않고 콘텐츠가 뱃지 높이를 결정하게 한다.
- 공용 `Badge`와 다른 뱃지의 크기·스타일은 변경하지 않는다.

## 설계

1. 기존 `GradeBadge`와 `GradeIcon`을 재사용한다.
2. `GradeBadge`에 `h-auto min-h-5`를 적용한다.
   - `h-auto`가 공용 `Badge`의 고정 `h-5`를 해당 사용처에서만 해제한다.
   - 기존 `py-0.5`와 아이콘 높이가 뱃지의 실제 높이를 자연스럽게 결정한다.
   - `min-h-5`는 아이콘이 없는 상태에서도 공용 뱃지의 기존 최소 높이를 보존한다.
3. `GradeIcon`의 `size-6`·`object-contain`과 뱃지의 색상·간격·타이포는 유지한다.
4. 공용 `packages/ui/src/components/badge.tsx`는 수정하지 않는다.

## 검증

- 소스 회귀 테스트로 `GradeBadge`의 콘텐츠 기반 높이와 24px 아이콘 유지 계약을 확인한다.
- 관련 Vitest를 실행한다.
- 변경 파일 Biome/Ultracite 검사와 Web TypeScript 검사를 실행한다.
- 가능하면 게시판 목록에서 회원 등급 아이콘이 잘리지 않는지 브라우저로 확인한다.

## 제외 범위

- 회원 등급 아이콘 이미지·등급 정책 변경
- 누적 광고일수 등급 아이콘 변경
- 공용 `Badge` 높이 변경
- 게시판 목록의 다른 레이아웃·타이포 변경

## 구현 결과

- `GradeBadge`에 `h-auto min-h-5`를 적용해 공용 `Badge`의 고정 높이를 해당 사용처에서만 해제했다.
- 24px 등급 아이콘과 기존 `py-0.5`가 실제 뱃지 높이를 결정하므로 별도 고정 높이 없이 아이콘 잘림을 해소했다.
- `GradeIcon`의 `size-6`·`object-contain`, 뱃지 색상·간격·텍스트 스타일과 공용 `Badge`는 변경하지 않았다.
- 콘텐츠 기반 높이와 기존 아이콘 크기를 보호하는 소스 회귀 테스트를 추가했다.
