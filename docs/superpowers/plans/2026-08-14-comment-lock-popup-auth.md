# 댓글 제한 표시 및 로그인 전 팝업 차단 계획

## 목표

- 댓글 작성이 제한된 게시글에 댓글이 하나도 없으면 댓글 수, 빈 상태 문구, 제한 안내와 작성 영역을 모두 숨긴다.
- 기존 댓글이 있는 제한 글은 기존 댓글 열람을 유지하고 새 댓글·답글만 계속 차단한다.
- 메인 팝업은 로그인과 회원 유형 확인이 끝난 사용자에게만 노출한다.

## 구현

- 회원용·공개 게시글 상세에서 `commentsDisabled && commentCount === 0`이면 댓글 섹션을 렌더링하지 않는다.
- 공개 팝업 API는 세션이 없으면 빈 목록을 반환한다.
- 팝업 레이어는 인증 상태 확인 전과 비로그인 상태에서 조회·렌더링하지 않는다.
