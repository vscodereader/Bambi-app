# 최초 사업자 인증 서류 업로드 수정 계획

## 문제

업소회원이 사업자 정보를 처음 제출하면 인증 상태가 `pending`이 되지만, 웹과 API가
`pending` 상태의 사업자 인증 서류 추가를 모두 차단한다. 이 때문에 운영자 승인 전에는
이미지 또는 PDF를 제출할 수 없고, 운영자는 서류 없이 승인 여부를 판단하게 된다.

## 변경 범위

- `pending` 상태에서도 사업자 인증 이미지/PDF 추가 버튼을 활성화한다.
- 업로드 인텐트 생성과 서류 등록 API도 `pending` 상태의 조직 owner에게 허용한다.
- 심사 중 기존 서류 삭제 잠금은 그대로 유지한다.
- 파일 형식, 크기, 최대 개수, 조직 owner 권한 검증은 그대로 유지한다.

## 검증

- 사업자 인증 서류 라우터 테스트에서 `pending` 상태의 추가 성공과 삭제 거부를 확인한다.
- API 및 web 타입 검사를 실행한다.
- 변경 파일에 Biome 검사와 `git diff --check`를 실행한다.
