# 테스트 사이트 QA 이슈 통합 개선 설계

## 목표

테스트 사이트에서 확인된 공개 전체공고, 운영자 결제관리, 구인자 출석 메뉴·광고관리, 공고 급여 검증, 운영자 검수 상세의 여섯 가지 결함을 하나의 브랜치와 PR에서 수정한다.

## 확정 요구사항

1. 전체공고는 밤비 공고와 크롤링 공고를 합쳐 페이지마다 정확히 최대 48개를 반환한다. 최초 48개, 더보기마다 다음 48개를 누적하며 데스크톱은 4열 12행이다. 스페셜·추천 공고의 전체공고 중복 노출은 유지한다.
2. `job_boost_purchase`에 구매 경로를 추가한다. 유료 노출상품 등록과 동시에 산 옵션은 `job_registration`, 일반 무료 공고 등록 또는 광고관리에서 별도 구매한 옵션은 `standalone`이다. 기존 행은 전부 `standalone`으로 마이그레이션한다.
3. 운영자 결제관리의 공고 결제금액은 이용기간+디자인+`job_registration` 옵션 합계로 표시·정렬한다. 총액 아래에는 실제 구매한 디자인·끌어올리기·횟수권·자동 끌어올리기 금액만 표시한다. 묶음 옵션은 별도 옵션 결제 목록에서 제외한다.
4. 공고 결제완료/미결제 전환은 묶음 옵션과 같은 트랜잭션에서 처리한다. 결제완료는 옵션을 활성화하고, 미사용 옵션은 공고와 함께 미결제로 되돌린다. 횟수 차감 또는 실제 끌어올리기 실행 이력이 있는 옵션이 하나라도 있으면 전체 미결제 전환을 거절한다.
5. 운영자 결제관리의 두 목록은 데스크톱 표를 유지하고 모바일에서는 카드로 제공한다. 체크박스와 관리 버튼, 일괄 처리 기능은 유지한다.
6. 구인자 공통 상단 메뉴의 출석체크만 제거한다. 내 정보 사이드바·허브 카드와 직접 URL은 유지한다.
7. 자체 공고 급여는 등록·수정·운영자 수정 UI와 API 모두 최대 `123,456,789원`으로 제한한다. 크롤링 급여와 광고 관련 가격은 제외한다.
8. `/employer/promotions` 목록에서 제목은 앞 15자 뒤 `...`로 자르고 잘린 경우 `title`에 원문을 둔다.
9. `/moderator/queue/[id]`의 하단 결제관리 패널만 제거한다.

## 구현 구조

### 전체공고

서버의 밤비 공고와 크롤링 공고 병합 지점에서 요청 `limit`만큼 최종 슬라이스한다. 다음 커서는 실제로 소비한 각 소스 행 수를 사용해 중복·건너뜀 없이 전진한다. 클라이언트는 기존 infinite query 누적 방식을 유지한다.

### 구매 경로와 묶음 결제

Drizzle enum `job_boost_purchase_source`와 `purchase_source` 컬럼을 추가한다. 기본값은 `standalone`으로 두어 기존 행을 안전하게 백필한다. 공고 저장 흐름이 유료 노출상품과 옵션을 함께 생성할 때만 `job_registration`을 명시한다.

운영자 공고 결제 조회는 묶음 옵션을 공고별로 모아 반환한다. 공고 결제 상태 변경용 공용 트랜잭션 헬퍼가 공고 노출기간과 묶음 옵션 활성 필드를 함께 갱신한다. 미결제 전환 전 횟수권 잔여 감소 및 활성화 이후의 해당 옵션 실행 이력을 검사해 사용된 옵션이면 `BAD_REQUEST`로 거절한다.

### 반응형 결제관리

데스크톱 `DataTable`/`Table`은 `md` 이상에서 유지하고 같은 데이터를 쓰는 모바일 카드 목록을 `md` 미만에서 렌더링한다. 금액 상세 렌더러와 제목·상태·관리 액션을 공용화해 표와 카드의 정보 차이를 막는다.

### 소규모 UI·검증 수정

급여 상한은 공용 상수와 폼 검증, API Zod 스키마를 공유한다. 제목 말줄임은 광고관리 전용 헬퍼로 제한한다. 출석 상단 메뉴 항목과 검수 상세 결제 패널 import/렌더만 제거한다.

## 검증

- 전체공고 병합/커서 서비스 및 웹 infinite-query 테스트: 48개, 다음 48개, 밤비 공고 추가 시 정원 유지
- 묶음·단독 구매 경로, 기존 기본값, 결제완료 동시 활성화, 미사용 미결제 전환, 사용 후 거절 API 테스트
- 결제금액 합산·정렬, 모바일 카드, 제목 말줄임, 급여 상한 단위 테스트
- 관련 Vitest, web/API TypeScript, Biome, migration 이력과 `git diff --check`

## 제외 범위

- 부분 취소·환불 및 사용량/기간 복원
- 크롤링 급여 정규화
- 별도 결제관리 페이지나 관련 API 삭제
- 출석체크 기능 또는 직접 URL 제거
