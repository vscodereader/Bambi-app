# 모바일 구인 관리 카드 전환 설계

## 목적

구인자 모바일 화면에서 가로 스크롤이 필요한 표를 카드 목록으로 전환한다. 데스크톱 표와 운영자 화면은 변경하지 않는다.

## 범위

- `/employer`의 `내 공고`
- `/employer/promotions`의 `광고 관리`
- `/employer/analytics`의 `성과 분석`
- 구인 관리의 `멤버 관리`
- 화면 너비 768px 미만에서만 카드 목록 사용
- 768px 이상에서는 기존 `DataTable` 유지

## 내 공고

- 카드에 기존 표의 제목, 직종·지역, 급여, 공고 상태와 상태 안내를 모두 표시한다.
- 제목은 한 줄 이후 말줄임표로 처리한다.
- 수정·삭제는 기존 점 3개 메뉴를 그대로 사용한다.
- 카드 위에 최근 수정순, 제목순, 급여순, 상태순 정렬 선택창을 제공한다.
- 모바일 카드 영역 내부에 좌우 8px 여백을 두어 정렬 선택창과 공고 카드가 바깥 테두리에 붙지 않게 한다.
- 기존 목록과 동일하게 한 페이지에 10개를 표시하고 이전·다음 페이지 이동을 제공한다.

## 광고 관리

- 기존 상태 탭을 유지한다.
- 카드에 기존 표의 공고명·팀, 상태·입금 안내·대기열, 노출 위치·상품, 노출 마감, 수동·자동 끌어올리기, 최근 끌어올림을 모두 표시한다.
- 끌어올리기와 공고 보기는 기존 점 3개 메뉴를 그대로 사용한다.
- 기존 목록과 동일하게 한 페이지에 10개를 표시하고 이전·다음 페이지 이동을 제공한다.

## 성과 분석

- 카드에 기존 표의 공고명·상태, 노출, 상세, 채팅, 상세 전환, 게재 구분을 모두 표시한다.
- 기존 조회 결과 순서와 게재 구분 계산을 그대로 유지한다.

## 멤버 관리

- 카드에 기존 표의 이름, 이메일, 상태, 권한, 소속 팀, 등록 일시와 반려 사유를 모두 표시한다.
- 역할 변경·팀 지정·소유권 이전·삭제·재요청 등 기존 점 3개 메뉴의 관리 기능을 그대로 사용한다.
- 기존 필터, 조회 순서와 페이지네이션 동작을 유지한다.

## 구현 원칙

### 모바일 카드 액션 메뉴 위치

- 내 공고와 광고 관리 카드의 점 3개 액션 메뉴는 카드 제목과 같은 행의 우측 상단에 고정한다.
- 액션 메뉴를 위해 별도의 하단 행이나 빈 공간을 남기지 않고, 제목 다음 정보 영역이 바로 이어지게 한다.
- 이미 우측 상단에 배치된 멤버 관리 카드의 액션 메뉴 구조는 유지한다.

- 기존 상태·공개 여부·끌어올리기 계산과 액션 컴포넌트를 데스크톱 표와 모바일 카드가 공유한다.
- shadcn/ui 컴포넌트와 기존 디자인 토큰만 사용한다.
- 모바일 카드와 데스크톱 표는 CSS 반응형 표시만 전환하며 데이터 요청은 추가하지 않는다.
- 기존 채팅 첨부파일 변경 등 이 브랜치의 다른 작업은 수정하지 않는다.

## 검증

- 375px, 390px, 430px에서 가로 스크롤 없이 모든 정보와 점 3개 메뉴를 사용할 수 있는지 확인
- 정렬 4종과 모바일 페이지 이동 확인
- 768px 이상에서 기존 표의 열, 정렬, 페이지네이션과 액션이 그대로인지 확인
- TypeScript 및 Biome 검사
