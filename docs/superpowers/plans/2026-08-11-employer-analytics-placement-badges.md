# 구인자 성과 분석 게재 구분 뱃지 설계

## 목적

구인자 성과 분석의 공고별 `게재 구분`을 구분점으로 연결된 문장 대신 색상이 다른 뱃지 목록으로 표시해 모바일과 데스크톱에서 빠르게 구분할 수 있게 한다.

## 범위

- 대상 화면: `apps/web/src/app/employer/analytics/page.tsx`
- 현재 분석 집계가 제공하는 7개 게재 구분을 지원한다.
  - 일반
  - 스페셜
  - 급구
  - 추천
  - 프리미엄 배너·상단
  - 프리미엄 배너·좌측
  - 프리미엄 배너·우측
- 각 뱃지는 `명칭 횟수` 형식으로 표시한다.
- 공고가 구매한 상품에 속한 게재 구분은 집계가 0이어도 표시한다.
- 일반은 모든 공고에 표시하고, 다른 상품에서 실제 노출된 횟수가 있으면 함께 표시한다.
- 모바일 카드와 데스크톱 표에 같은 컴포넌트와 색상 규칙을 적용한다.

## UI 설계

- 게재 구분 셀은 줄바꿈 가능한 `flex-wrap` 목록으로 렌더링한다.
- 종류별 색상은 고정 매핑하여 같은 구분이 화면 크기와 공고에 관계없이 같은 색으로 보이게 한다.
- 프리미엄 배너의 상단·좌측·우측은 같은 계열 안에서 서로 다른 색으로 구분한다.
- 기존 공고 상태 뱃지, 집계 기준, 정렬 및 API는 변경하지 않는다.

## 구현

1. 게재 구분 항목의 키·라벨·값을 생성하는 기존 로직을 배열 반환 함수로 바꾼다.
2. 키별 스타일 매핑과 공통 `PlacementMetricBadges` 렌더러를 추가한다.
3. 모바일 카드와 데스크톱 표의 문자열 출력 위치를 공통 뱃지 렌더러로 교체한다.
