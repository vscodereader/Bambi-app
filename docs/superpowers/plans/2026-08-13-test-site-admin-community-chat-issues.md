# 테스트 사이트 운영자·커뮤니티·채팅 발견 사항 수정 설계

## 기준

- 기준 커밋: 최신 `origin/develop` `4a545666`
- 브랜치: `fix/test-site-admin-community-chat-issues`
- 커밋과 푸시는 사용자가 직접 수행한다.
- 기존 PR #168의 프로필·신고 채팅·팝업 기능을 유지하면서 발견된 일곱 가지 문제만 수정한다.

## 1. 운영자 내 정보 뱃지

- 운영자 개인의 `/seeker/me` 내 정보 프로필 카드에서만 `운영자` 뱃지를 숨긴다.
- 다른 역할 뱃지와 운영자 콘텐츠·댓글에 표시되는 운영자 뱃지는 변경하지 않는다.

## 2. 운영자 신고 채팅 내역

- 사용자 채팅방에서 쓰는 `annotateChatMessages`를 운영자 채팅 내역에도 재사용한다.
- 같은 발신자가 같은 날짜·같은 분에 연속해서 보낸 일반 메시지는 하나의 그룹으로 묶는다.
- 발신자 이름은 그룹 첫 메시지에만, 시간은 그룹 마지막 메시지에만 표시한다.
- 연락처 요청 같은 특수 메시지는 기존 그룹을 끊는다.
- 대화 영역의 제한 높이와 세로 스크롤, 하단 고정 첨부파일 줄은 유지한다.

## 3. 메시지와 첨부파일 연결 강조

- 첨부파일이 있는 `첨부 파일을 보냈습니다.` 메시지를 클릭할 수 있게 한다.
- 클릭한 메시지의 실제 첨부 ID들과 일치하는 이미지·PDF 카드를 하단 첨부파일 줄에서 모두 강조한다.
- 첨부파일 줄은 첫 대상 카드가 보이도록 가로로 자동 스크롤한다.
- 강조 테두리는 약 2초 뒤 자동으로 사라진다.
- 이미지 새 창 열기와 PDF 새 창·다운로드 동작은 유지한다.

## 4. 신고 대상 채팅방 아이콘

- 신고 대상이 채팅방이면 사용자용 사람 아이콘 대신 채팅방용 말풍선 아이콘을 표시한다.
- 신고자나 실제 사용자 대상에는 기존 사람 아이콘을 유지한다.

## 5. 팝업 내부 링크

- 상대 URL은 기존처럼 허용한다.
- 절대 URL은 `localhost`, 루트 `bambialba.com`, 모든 `*.bambialba.com` 하위 도메인을 허용한다.
- 유사 도메인(`bambialba.com.evil.test`)과 다른 프로토콜은 거부한다.
- 클라이언트와 서버가 동일한 검증 규칙을 사용하도록 공통 순수 함수를 재사용하고 경계 테스트를 추가한다.

## 6. 비회원 댓글 프로필 사진

- 비회원 공개 게시글 상세에서도 회원이 작성한 댓글의 현재 프로필 사진을 내려준다.
- 비회원 댓글·탈퇴 회원·사진이 없는 회원은 기존 사람 아이콘 기본 프로필을 유지한다.
- 작성자 이름 공개 정책과 수정·삭제 권한은 변경하지 않는다.

## 7. 운영자 게시글 댓글 작성 잠금

- `community_post`에 `comments_disabled boolean not null default false`를 Drizzle migration으로 추가한다.
- 운영자가 작성·수정하는 모든 실제 게시판 글에서만 작성인 입력 아래에 `댓글 작성 불가` 체크박스를 표시한다.
- 일반 회원과 비회원은 해당 입력을 보거나 API로 설정할 수 없다.
- 기존 글은 backfill 기본값 `false`로 댓글 작성 가능 상태를 유지한다.
- 잠긴 글의 기존 댓글과 답글은 그대로 열람·수정·삭제할 수 있다.
- 새 댓글과 새 답글 작성만 회원·비회원·다른 운영자·글 작성자 모두 서버에서 거부한다.
- 상세 응답에 댓글 잠금 상태를 포함하고 입력 폼 대신 댓글 작성 불가 안내를 표시한다.
- 운영자는 글 수정 화면에서 잠금 상태를 다시 변경할 수 있다.
