# 광고 배너 1시간 랜덤 로테이션 노출 설계

- 날짜: 2026-07-21
- 상태: 승인됨. 사용자 확정: **매시간 완전 랜덤 선발**(정해진 순서를 도는 순환 아님),
  프리미엄 2개 캡+로테이션 포함, 좌/우측도 동일 방식.

## 배경·문제

`listAdBanners`는 결제완료·미만료 배너 공고를 `publishedAt desc`로 정렬해
`groupAdBannerJobs`가 좌/우 사이드는 앞에서 3개(`SIDE_BANNER_MAX_SLOTS`)만 자르고,
프리미엄은 상한 없이 전부 내린다. 이 구조에서는:

- 좌/우 배너가 4개 이상 팔리면 최신 3개가 슬롯을 고정 점유하고 **나머지는 영원히 노출되지 않는다**.
- 프리미엄은 "1행 2열" 의도와 달리 판매분만큼 행이 무한 확장된다.

## 목표

- 활성 배너가 슬롯 수를 초과해도 **1시간마다 완전히 새로 랜덤 선발**해 모든 광고주가
  노출 기회를 얻는다. 예: 프리미엄 100개면 매시간 그중 랜덤 2개.
- **노출 횟수 기준**: 매시간 같은 위치의 활성 배너 전원이 동일 확률(`슬롯수/M`)로
  선발된다. 시간이 지나면 광고주별 노출 시간이 기대값 `24×슬롯수/M`시간/일로 수렴한다.
- 프리미엄 배너를 2개 슬롯으로 캡하고 동일한 로테이션에 포함한다.

## 결정: 시간 시드 결정적 랜덤 셔플 (DB·크론 없음)

`groupAdBannerJobs(rows, now)` 내부에서 순수 함수로 적용한다. 시그니처 불변.

위치 타입별로:

1. 활성 후보를 `id` 기준 안정 정렬한다(SQL 정렬 순서 비의존).
2. **시간 버킷**(`⌊now/3,600,000⌋`, 타임존 무관) **+ 위치 타입**을 시드로 한 결정적
   셔플(의존성 없는 소형 PRNG + Fisher–Yates)로 매시간 새 랜덤 순서를 만든다.
3. 앞에서 슬롯수만큼 자른다. 후보가 슬롯 이하면 전부 노출되며, 레일 안의 표시 순서도
   매시간 섞인다(슬롯 내 위치까지 공평해지는 부수 효과, 별도 분기 없음).

정해진 링을 도는 순환이 아니라 **매시간 독립적인 랜덤 추첨**이다. 특정 배너가 몇 시간
연속 선발되거나 빠질 수 있으나 확률은 전원 동일하다. 시드가 결정적이므로 같은 시간대에는
어느 서버 인스턴스·어느 요청이든 같은 결과다. 상태 저장·스케줄러·마이그레이션 불필요.

### 슬롯 수

| 위치 | 슬롯 | 비고 |
| --- | --- | --- |
| 좌측 사이드 | 3 | 기존 `SIDE_BANNER_MAX_SLOTS` 유지 |
| 우측 사이드 | 3 | 〃 |
| 프리미엄 | 2 | `PREMIUM_BANNER_MAX_SLOTS = 2` 신설(1행 2열 고정) |

## 변경 범위

- `packages/api/src/services/bambi-ad-exposure.ts` — 시드 PRNG·셔플 추가,
  `groupAdBannerJobs`의 `pick`에 적용, `PREMIUM_BANNER_MAX_SLOTS` 신설, 주석 갱신.
- `packages/api/src/services/bambi-ad-exposure.test.ts` — 로테이션 테스트 추가.
- `apps/web/src/components/bambi/premium-ad-banner-section.tsx` — 주석만 갱신
  (placeholder 로직은 0~2개 범위에서 이미 올바름).
- 광고 가이드·매뉴얼에 배너 노출 방식 서술이 있으면 "판매분이 슬롯을 초과하면 1시간
  단위 랜덤 로테이션 노출" 문구를 동기화한다(구현 시 확인).

프론트 데이터 흐름·`listAdBanners` 라우터·임프레션 기록은 무변경. 로테이션 결과만
기록되므로 광고주별 임프레션 수는 자연히 수렴하고 기존 최근 7일 지표로 확인한다.

## 엣지 케이스

- **후보 ≤ 슬롯**: 전원 노출(집합 불변), 표시 순서만 매시간 변동.
- **하루 중 후보 변동**(신규 결제·만료): 다음 조회부터 새 후보 집합으로 추첨. 문제없음.
- **멀티 인스턴스/요청 간 일관성**: 결정적 시드로 보장.
- **프론트 캐시**: react-query 기본 동작(마운트·포커스 재조회)으로 충분. 페이지를 켜둔
  채 정각을 넘기면 다음 상호작용까지 이전 선발이 보일 수 있으나 허용(별도 갱신 없음).

## 비범위 (YAGNI)

- 균등 보장 순환·임프레션 수 기반 보정 — 매시간 동일 확률로 충분(사용자 확정).
- 회전 상태의 DB 물질화·운영자 수동 핀 고정.
- 프론트 정각 자동 재조회.

## 테스트 전략

`bambi-ad-exposure.test.ts` 순수 함수 테스트(시드 결정적이라 전부 비플레이키):

- 같은 시간 버킷 → 동일 결과(결정성), 인접 시간 버킷들 → 선발 변화 발생(로테이션).
- 슬롯 초과 후보(M>슬롯)에서 충분한 시간(예: 72버킷) 순회 시 전원이 1회 이상 선발(고정 배제 없음).
- 후보 ≤ 슬롯이면 집합 기준 전원 노출.
- 프리미엄 2개 캡 적용, 좌/우 3개 유지.
- 위치 타입별 시드 독립(같은 후보 집합이라도 위치가 다르면 선발이 달라질 수 있음).
