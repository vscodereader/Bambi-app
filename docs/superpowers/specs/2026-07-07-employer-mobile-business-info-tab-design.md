# 구인자 모바일 하단탭 "업체 정보 / 내 정보" 분리 설계

날짜: 2026-07-07

## 배경 / 문제

구인자(employer)로 로그인했을 때, 같은 화면·라벨이 뷰포트에 따라 어긋나 있었다.

| 위치 | 라벨 | 목적지 | 내용 |
|---|---|---|---|
| 데스크톱 헤더 좌측 nav | "업체 정보" | `/employer/me` | 사업자 인증·매장 정보 (페이지 제목은 "매장 정보") |
| 데스크톱 헤더 우측 버튼 | "내 정보" | `/seeker/me` | 개인 계정 (신고 내역·예정된 면접·차단·계정 설정) |
| 모바일 하단탭 | "내 정보" | `/employer/me` | ← 데스크톱 "업체 정보"와 같은 곳 |

문제는 두 가지다.

1. **라벨 불일치** — 하나의 `/employer/me`가 데스크톱에선 "업체 정보", 모바일에선 "내 정보"로 불렸다.
2. **모바일에 개인 계정 진입점 부재** — 데스크톱에는 "업체 정보"(`/employer/me`)와 "내 정보"(`/seeker/me`)가 둘 다 있으나, 모바일 구인자 하단탭에는 `/employer/me`로 가는 "내 정보" 하나뿐이라 개인 계정(`/seeker/me`)에 갈 길이 없었다.

## 결정

구인자에게 **사업자 화면(업체 정보)**과 **개인 계정 화면(내 정보)**을 명확히 분리하고, 개인 계정은 role 공용 페이지 `/seeker/me`를 재사용한다. 모바일 하단탭을 데스크톱과 동일하게 두 진입점을 모두 갖도록 맞춘다.

## 변경 범위

**단일 파일: `apps/web/src/components/bambi/persona-nav.tsx`의 `EmployerNav`**

### 1. 하단탭 항목 4개 → 5개

`설정`과 `내 정보` 사이에 **"업체 정보"** 탭을 신설한다.

```
내 공고 / 등록 / 설정 / [업체 정보] / 내 정보
```

- `업체 정보`: 신규 탭, 아이콘 `StoreIcon`(`./icons`에 존재), 목적지 `/employer/me`
- `내 정보`: 기존 탭 유지, 아이콘 `UserIcon`, 목적지를 `/employer/me` → **`/seeker/me`**로 변경

### 2. `go()` 핸들러

- 신규 value(예: `"business"`) → `router.push("/employer/me")`
- 기존 `"me"` value → `router.push("/seeker/me")` (기존 `/employer/me`에서 변경)

### 3. 활성 탭(value) 매핑

- `path === "/employer/me"` → 활성 탭을 `"business"`(신규)로 매핑 (기존엔 `"me"`였음)
- `"me"` 탭은 `/seeker/me`용이 되며, 이 경로는 `EmployerNav`의 `showNav` 조건에 없으므로 employer 셸에서 `me` 탭이 활성 표시될 일은 없다(셸이 전환됨).

`showNav` 조건(`/employer`, `/employer/new`, `/employer/me`, `/employer/settings*`)은 **변경하지 않는다.**

## 의도된 동작 (부작용 아님)

`/seeker/me`와 `/employer/me`는 라우트 세그먼트가 달라 앱 셸이 통째로 전환된다. 구인자가 하단탭 "내 정보"를 누르면 `SeekerNav` 셸로 전환되어 하단탭이 구직자용(`탐색`/`채팅`/`구인 관리`/`수다방`/`내 정보`)으로 바뀐다. 이는 데스크톱 우측 "내 정보" 버튼이 이미 하던 동작과 동일하며, **의도된 동작으로 승인됨.**

## 명시적 비범위 (하지 않음)

- **페이지 제목 "매장 정보"는 그대로 둔다.** `/employer/me` 페이지 내부 제목은 수정하지 않는다.
- 데스크톱 헤더(`responsive-shell.tsx`, `employer/layout.tsx`)는 이미 "업체 정보" + "내 정보"로 분리돼 있어 수정하지 않는다.
- `/seeker/me` 페이지 내용(구직 전용 메뉴 role 조건부 숨김 등)은 이번 범위 밖. 현재 그대로 재사용한다.
- `MobileTabBar`(구직자·공개 셸), `SeekerNav` 등 다른 셸은 수정하지 않는다.
