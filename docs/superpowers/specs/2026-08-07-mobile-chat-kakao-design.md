# 모바일 채팅방 카카오톡식 재설계 — 디자인 스펙

날짜: 2026-08-07 · 브랜치: worktree-mobile-chat-kakao (base: develop)

## 문제

모바일에서 채팅방이 카드형 레이아웃(문서 흐름 + 아래에 사이드 카드 스택)이라,
키보드가 올라오면 브라우저가 문서를 스크롤해 UI가 밀리고 아래 빈 공간이 생긴다.
기존 대응(`--chat-visual-viewport-height`로 패널 높이만 축소)은 높이만 조절할 뿐
위치를 고정하지 않는 것이 근본 원인.

## 목표 / 비목표

- 목표: `<md`(768px 미만)에서 채팅방을 카카오톡처럼 풀스크린 고정 레이아웃 +
  카카오톡식 비주얼로 재설계. 키보드가 올라오면 입력창이 키보드 바로 위에 붙는다.
- 비목표: DB·API·기능(전송/첨부/읽음/면접/연락처 공개/신고/차단) 변경 없음.
  `md+` 데스크톱은 현행 유지(무변경). 대상 화면은
  `apps/web/src/components/bambi/screens/seeker-chat-room-responsive.tsx`
  하나(구직자·구인자 공용).

## 설계

### 1. 풀스크린 고정 구조 (키보드 대응 핵심)

- 모바일에서 채팅 패널을 `fixed inset-x-0 top-0` +
  `height: var(--chat-visual-viewport-height, 100dvh)`로 뷰포트에 고정.
  기존 `useMobileKeyboardState` 훅·CSS 변수 배선 재사용.
- 키보드가 올라오면 visualViewport 높이 → 패널 높이가 줄어 입력창이 키보드
  바로 위에 붙고 메시지 영역만 압축된다. 문서 스크롤은 발생하지 않는다.
- 채팅방이 떠 있는 동안 모바일에서 body 스크롤 잠금 +
  `window.scrollTo(0, 0)` 보정(iOS 자동 스크롤 상쇄).
- 이 라우트(`/seeker/chats/[id]`)의 모바일에서 셸 헤더(`responsive-shell.tsx`
  모바일 헤더)와 하단 탭바(`persona-nav.tsx` 경로 조건) 숨김. 데스크톱 헤더 유지.

### 2. 모바일 채팅 헤더

- 한 줄 슬림 헤더: ← 뒤로가기 | 상대 이름(굵게)+공고 제목(작게 truncate) | ≡ 메뉴.
- 실시간 연결 상태는 이름 옆 작은 점(연결=green, 그 외=muted)으로 축소.
- "공고 보기"·차단됨 배지·상태 배지는 서랍(Sheet)으로 이동.
- 안전 안내 바는 한 줄 슬림 배너(방패 + "면접 확정 전 연락처 보호 중")로 축소,
  신고·차단 버튼은 서랍으로 이동.

### 3. 서랍 Sheet (사이드 카드의 새 자리)

- 헤더 ≡ → 우측 `Sheet`(`@bambi-app/ui/components/sheet`, 설치돼 있음).
- 내용: 공고 정보(공고 보기 링크·급여·상태) / 면접 일정(제안 폼(구인자만)·일정
  카드·확정/거절/취소) / 연락처 공개 요청(구인자)·구인자 인증 연락처(구직자) /
  신고(구직자만)·차단.
- 데스크톱 aside는 현행 유지 — 내부 컴포넌트를 aside와 Sheet 양쪽에서 재사용.

### 4. 메시지 영역 비주얼 (모바일 한정)

- 배경 `bg-secondary`, 말풍선 상대=`bg-background`·내 것=`bg-coral-500`(밤비
  브랜드 유지, raw hex 금지).
- 시간은 말풍선 밖 하단 옆(`text-[11px]` muted): 내 메시지=왼쪽, 상대=오른쪽.
- 날짜 구분 칩: 날짜가 바뀌는 지점에 중앙 pill(예: "2026년 8월 6일 목요일").
- 상대 메시지에 아바타(이니셜 `AvatarFallback`)+이름. 연속 그룹핑: 같은 사람이
  같은 분(minute)에 연속 전송 시 첫 메시지만 아바타·이름, 마지막만 시간.
- 그룹핑·날짜 칩 로직은 순수 함수(`apps/web/src/lib/bambi/chat-message-grouping.ts`)
  로 분리 + vitest 단위 테스트. `contact_request` 등 특수 메시지는 그룹을 끊는다.
- 데스크톱(md+) 말풍선은 현행 스타일 유지.

### 5. 입력창 (모바일)

- 하단 고정 바: 첨부(+) 버튼 + 둥근(`rounded-full`) 입력 필드 + 전송 버튼(내용
  있을 때만 코럴 활성). `env(safe-area-inset-bottom)` 패딩.
- 첨부 초안 패널·업로드 상태·검증 로직은 기존 그대로.

### 6. 검증

- 순수 로직 vitest 단위 테스트(워크트리 안에서 해당 파일만 실행 —
  `src/routers/bambi` 스위트 실행 금지).
- `pnpm dlx ultracite fix <경로>`(경로 인자 필수) + 타입체크.
- 시각 확인은 사용자가 HMR로 진행(개발 서버·스크린샷 금지 규칙).
