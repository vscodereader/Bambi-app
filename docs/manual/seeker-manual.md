## 1. 이런 분을 위한 안내서

밤비알바는 일할 사람을 찾는 업체(구인자)와 일자리를 찾는 분(구직자)이 만나는 아르바이트 사이트예요. 이 설명서는 **일자리를 찾는 구직자**를 위한 것이에요.

밤비알바를 쓸 때 꼭 알아 둘 세 가지예요.

- **내 전화번호는 내가 정할 때만 공개돼요**: 업체와의 첫 연락은 모두 밤비알바 안의 채팅으로 시작해요. 내 전화번호는 업체가 **연락처 공개 요청**을 보내고, 내가 **공개**를 눌렀을 때만 상대에게 넘어가요. **거절**을 누르면 넘어가지 않아요.
- **검수한 공고예요**: 밤비알바에 올라온 공고는 운영팀이 살펴보고 결제를 거쳐 보여 줘요. 목록에는 다른 사이트에서 모아 온 **수집 공고**도 함께 나오는데, 이 공고는 밤비알바가 검수하지 않아요([3-3](#3-3-외부에서-수집된-공고) 참고).
- **신고와 차단을 할 수 있어요**: 공고와 조건이 다르거나, 밖에서 연락하자고 하는 등 이상한 점이 있으면 언제든 신고하거나 상대를 차단할 수 있어요.

밤비알바는 만 **19세 이상**만 쓸 수 있어요. 로그인·회원가입 화면에는 이용 연령 안내가 항상 보여요.

> 운영자가 정한 **법률자문가** 계정도 구직자와 같은 화면을 써요. 그래서 이 설명서를 같이 보시면 돼요. 다만 쓸 수 있는 범위가 조금 달라요. 그 차이는 [3-11. 법률자문가 계정](#3-11-법률자문가-계정-지정된-분만)에 따로 모아 두었어요.

## 2. 시작하기 (가입·로그인·둘러보기)

### 회원가입하기

회원가입은 **① 본인인증 → ② 정보 입력** 두 단계로 해요. 본인인증을 끝내야 가입 폼(정보를 적는 칸)이 열려요.

**① 본인인증**

1. 로그인 화면 아래의 "밤비알바가 처음이신가요? **회원가입**"을 눌러요. 화면 위 카드 제목이 `밤비알바 계정 만들기`로 바뀌어요.
2. 카드 위쪽에 `본인인증 — 정보 입력` 두 단계 표시가 보여요.
3. **본인인증하고 계속하기** 버튼을 누르고, 열린 창에서 휴대폰 본인인증을 끝내요.
   - 만 19세 미만이면 "만 19세 이상만 이용할 수 있어요."라고 나오고 가입할 수 없어요.
   - 그 명의로 이미 가입한 계정이 있으면 "이미 가입된 계정이 있어요. 로그인해 주세요."라고 나오고, 화면이 저절로 로그인으로 바뀌어요.

**② 정보 입력**

인증이 끝나면 아래 칸을 적는 폼이 열려요.

| 적는 칸 | 안내 |
| --- | --- |
| 닉네임 | 2자 이상. 공고·채팅에 보이는 이름이에요. |
| 아이디 | 3~30자. 영문·숫자와 밑줄(_)·마침표(.)·하이픈(-)만 쓸 수 있어요. 대문자는 소문자로 저장돼요. |
| 비밀번호 / 비밀번호 확인 | 8자 이상, 두 칸의 값이 같아야 해요. |
| 이메일 | 아이디 대신 이메일로도 로그인할 수 있어요. |
| 가입 유형 | 구직자는 **개인회원**을 골라요. (일자리를 올리려는 업체라면 업소회원) |
| 약관 동의 | **이용약관 및 개인정보 처리방침에 동의합니다.** 칸을 켜요. |

마지막으로 **회원가입** 버튼을 누르면 가입이 끝나고, 바로 공고를 볼 수 있는 화면으로 넘어가요.

> 참고: 로그인 화면의 회원가입 링크 아래에 "지금 회원가입 시, N포인트 지급!" 같은 안내가 보일 때가 있어요. 가입만 해도 포인트를 주는 이벤트가 열려 있을 때만 나와요.

> 인증 단계에서 화면을 새로 고치면 다시 본인인증 단계로 돌아가요. 인증부터 다시 해 주세요.

### 로그인하기

1. **아이디** 칸에 가입할 때 만든 아이디 또는 이메일을 넣어요. (한 칸에서 둘 다 받아요.)
2. **비밀번호**(8자 이상)를 넣어요. 오른쪽 눈 모양을 누르면 넣은 비밀번호를 볼 수 있어요.
3. **로그인** 버튼을 눌러요.

> 아이디·이메일이 없거나 비밀번호가 틀리면 "아이디(이메일) 또는 비밀번호가 틀렸습니다."라고만 나와요. 탈퇴한 계정으로 아이디·비밀번호를 맞게 넣으면 "탈퇴한 계정이에요. 로그인할 수 없어요."라고 따로 나와요.

### 아이디·비밀번호를 잊었을 때

로그인 화면의 칸 이름 옆에 찾기 링크가 있어요. 두 경우 모두 **휴대폰 본인인증**을 먼저 해요.

**아이디 찾기**

1. 아이디 이름 오른쪽의 **아이디 찾기**를 눌러요.
2. 열린 창에서 본인인증을 끝내요.
3. 인증이 끝나면 안내 창이 뜨고 **가입된 아이디**가 그대로 보여요.
4. **이 아이디로 로그인**을 누르면 창이 닫히고 로그인 칸에 아이디가 저절로 채워져요.

**비밀번호 재설정**

1. 비밀번호 이름 오른쪽의 **비밀번호를 잊으셨나요?**를 눌러요.
2. 열린 창에서 본인인증을 끝내요.
3. 안내 창에 **새 비밀번호**와 **새 비밀번호 확인**을 넣고(8자 이상 128자 이하) **확인**을 눌러요.
4. "비밀번호가 변경되었어요" 안내가 나오고, 이 창은 5초 뒤 저절로 닫혀요. 기다리지 않고 직접 닫아도 돼요.
5. 새 비밀번호로 다시 로그인해 주세요.

> 안전을 위해 비밀번호를 바꾸면 **다른 기기에 남아 있던 로그인이 모두 풀려요.** 쓰던 기기에서도 새 비밀번호로 다시 로그인해 주세요.

> 본인인증 결과와 맞는 계정을 못 찾으면 "가입된 계정이 없어요"라고 나오고, 회원가입 화면으로 갈 수 있어요. 아이디 없이 이메일로만 가입한 계정은 "이메일로 가입된 계정이에요"라고 나와요.

> 인증 정보는 한 번 쓰면 없어져요. 같은 인증으로 다시 하면 "본인인증 정보가 만료되었거나 이미 사용되었어요."라고 나오니, 이럴 땐 인증부터 다시 해 주세요. 본인인증 서비스가 준비되지 않은 환경에서는 두 링크가 보이지 않아요.

### 회원가입 없이 둘러보기 (비회원)

가입 전에 어떤 공고가 있는지 먼저 보고 싶다면 비회원으로 둘러볼 수 있어요.

1. 로그인 화면의 **비회원으로 인증하기** 버튼을 눌러요. (회원가입 화면에는 이 버튼이 없어요.)
2. 열린 창에서 휴대폰 본인인증을 끝내요.
3. 인증이 끝나면 공고 목록 화면으로 넘어가요.

비회원은 **공고 목록**과 **수다방**을 볼 수 있어요. 공고를 눌러 상세를 보거나, 채팅·내 정보 같은 다른 화면으로 들어가려 하면 "회원가입 후에 볼 수 있어요" 안내와 함께 가입 화면으로 넘어가요.

> 수다방은 본인인증에서 **여성으로 확인된 비회원**에게만 열려요. 들어와서 게시판을 읽고, 일부 게시판에는 글·댓글·추천까지 남길 수 있어요([3-8. 수다방](#3-8-수다방) 참고). 남성으로 확인된 비회원은 공고 목록만 볼 수 있어요.

### 지역·업종별 채용 정보 페이지 (가입·인증 없이)

본인인증도 하지 않은 채로 어떤 공고가 있는지 먼저 보고 싶다면 **채용 정보 페이지**를 쓰세요. 인터넷 검색 결과에서 바로 들어올 수도 있어요.

| 주소 | 보이는 내용 |
| --- | --- |
| `/jobs` | 서비스 소개와 지역·업종별 바로가기, 최신 공고 |
| `/jobs/seoul` 처럼 지역이 붙은 주소 | 그 지역의 공고와 업종별 바로가기 |
| `/jobs/seoul/room-salon` 처럼 지역·업종이 붙은 주소 | 그 지역·업종의 공고 |

- 공고 카드에는 제목, 업체명, 근무 지역, 급여, 인증 여부가 보여요. 사진은 흐리게 처리돼 있어요.
- 공고를 누르면 상세 화면으로 넘어가는데, 이때 로그인(또는 회원가입) 안내가 떠요. 상세 내용과 채팅 문의는 가입 후에 쓸 수 있어요.
- 지역·업종 주소에서는 제목 위에 **채용 정보 › 서울 › 룸싸롱** 같은 현재 위치 표시가 나와요. 앞 단계를 누르면 위 목록으로 돌아갈 수 있어요.

> 어느 화면에서든 **맨 아래 푸터**(화면 밑쪽 안내줄)에 `지역별 채용 정보`·`커뮤니티 게시판`·`공지사항` 링크가 있어요. 로그인 화면에서도 이 링크로, 가입 없이 볼 수 있는 페이지로 바로 갈 수 있어요.

### 화면 이동 방법 (내비게이션)

로그인 뒤 화면 이동은 이렇게 해요.

**데스크톱(넓은 화면)** — 위쪽 메뉴 줄

| 메뉴 | 하는 일 |
| --- | --- |
| 채용정보 | 공고를 찾아보는 시작 화면이에요. |
| 수다방 | 회원과 본인인증을 마친 비회원이 이야기하는 커뮤니티예요. |
| 포인트몰 | 모은 포인트로 아이템을 바꾸는 화면이에요. ([3-14](#3-14-포인트몰) 참고) |
| 고객센터 | 자주 묻는 질문과 1:1 문의예요. |
| 알림 (오른쪽 위 종 모양) | 면접·검수·답변 같은 새 소식을 모아 보는 화면이에요. ([3-12](#3-12-알림) 참고) |
| 채팅 (오른쪽 위) | 업체와 주고받은 대화방 목록이에요. |
| 내 정보 (오른쪽 위) | 내 프로필, 신고 내역, 면접, 차단 목록, 포인트 내역, 계정 설정이에요. |

**휴대폰** — 화면 아래쪽 탭 줄: `탐색`, `채팅`, `수다방`, `내 정보` (**종 모양** 알림 버튼은 화면 맨 위 오른쪽에 있어요.)

> 안 읽은 대화가 있으면 데스크톱에서는 **채팅** 버튼 오른쪽 위에 작은 점이, 휴대폰에서는 **채팅** 탭 아이콘에 안 읽은 방 수 숫자가 보여요. 대화를 읽으면 곧 사라져요.

> 종 모양 버튼의 숫자와 채팅 숫자는 서로 달라요. 채팅 숫자는 안 읽은 대화방 수, 종 모양 숫자는 안 읽은 알림 수예요.

> 고객센터, 공고 상세, 채팅방 안에서는 휴대폰 아래쪽 탭 줄이 보이지 않아요. 화면 위쪽의 되돌아가기 링크나 브라우저 뒤로가기를 써 주세요.

> 포인트몰은 위쪽 메뉴에만 있고 휴대폰 아래쪽 탭 줄에는 없어요. 휴대폰에서는 화면 위쪽 머리줄의 **상점 아이콘**(돋보기 검색과 알림 종 사이)을 누르면 들어가요. 구매 내역은 휴대폰에서도 **내 정보 > 포인트 내역**에서 볼 수 있어요.

## 3. 화면별 기능 안내

### 3-1. 공고 탐색 (채용정보)

**무엇을 할 수 있나요?**
지역·업종·급여 같은 조건으로 공고를 찾고, 마음에 드는 공고의 상세를 보거나 채팅을 시작할 수 있어요.

**화면 구성**

- **검색**: 화면 위쪽의 **돋보기 버튼**을 누르면 검색창이 열려요(채용정보 화면에서만 보여요). `업종, 지역, 공고 제목`으로 찾을 수 있고, 결과를 누르면 그 공고 상세로 바로 가요.
- **빠른 탐색(필터)**: 아주 넓은 화면에서는 왼쪽에 **빠른 탐색** 상자가 있어요. 여기서 **지역, 세부지역, 업종, 최소 시급**을 고르고, `검증 완료만 보기`·`당일면접 가능만 보기`·`초보 가능만 보기`를 켤 수 있어요. 시/도를 바꾸면 세부지역은 `전체`로 돌아가요. 고른 조건은 **바로 목록에 반영**돼서 따로 적용 버튼이 없고, 맨 아래 **필터 초기화**로 한 번에 지울 수 있어요. 화면이 좁거나 휴대폰이면 이 상자가 없고, 위쪽 돋보기 검색으로 찾아요.
- **공고 목록**: `스페셜 채용`, `추천 채용`, `전체 공고`로 나뉘어 나오고, 사이에 수다방 미리보기가 끼어요. (`급구 채용` 묶음은 보통 숨겨져 있다가 운영자가 켜면 보여요.) 각 공고 카드에는 **업체명**, **지역 · 업종**, **급여**(금액을 모르면 `급여 협의`)가 보여요. 대표 사진이 없으면 업체명 앞 두 글자 타일이 대신 나와요. 반응이 많은 유료 공고에는 오른쪽 위에 `HIT` 표시가 붙어요.
- **공고 개수**: 화면 위 오른쪽에 `N개 · 실시간`처럼 지금 조건에 맞는 전체 공고 수가 보여요.
- **공고 더보기**: `전체 공고` 아래 **공고 더보기** 버튼을 누르면 다음 공고가 이어서 채워져요. 더 볼 공고가 없으면 버튼이 사라져요.

**공고를 찾는 방법**

1. 돋보기 검색으로 업종·지역·제목을 찾거나, 넓은 화면이면 왼쪽 빠른 탐색으로 조건을 좁혀요.
2. 마음에 드는 공고 카드를 누르면 **상세 화면**으로 가요. 채팅은 상세 화면에서 시작해요.

> 조건에 맞는 공고가 없으면 "조건에 맞는 공고가 없어요"라고 나와요. 지역이나 최소 급여 조건을 조금 낮춰 다시 찾아보세요.

> 고른 조건은 화면을 새로 고치거나 뒤로 갔다 오면 처음으로 돌아가요. 밤비알바에는 공고를 저장해 두는 **찜·스크랩 기능은 없어요.**

### 3-2. 공고 상세 보기

**무엇을 할 수 있나요?**
공고의 자세한 내용을 보고, 채팅을 시작하거나 문제가 있으면 신고할 수 있어요.

**화면에 보이는 것**

- 위쪽에 `검수 통과한 공고`, `연락처 보호` 표시
- 공고 제목과 `지역 · 고용형태`, 업체명과 **등록자** 이름
- **급여**(그 해 최저시급도 옆에 함께 보여요), **근무시간**, **고용형태**, **후기**(개수·별점)
- **구인자 연락처**: 공고를 올린 업체가 휴대폰 본인인증을 마친 경우에만 보여요. 눌러서 바로 전화를 걸 수 있어요.
- **공고 설명**: 업체가 쓴 자세한 내용과 사진. 처음에는 접혀 있고, **더보기**를 누르면 다 펼쳐져요.
- **후기**: 이 공고에서 면접을 마친 구직자들이 남긴 후기예요.
- **안전 확인**: 연락처 비공개·공고 검수·신고 가능 안내예요.

화면은 위에서 아래로 **공고 설명 → 후기 → 안전 확인** 순서로 나와요.

**사용법**

1. 내용을 보고 채팅을 시작하려면 **1:1 채팅 시작** 버튼을 눌러요.
   - 데스크톱에서는 오른쪽에, 휴대폰에서는 화면 맨 아래에 이 버튼이 있어요.
2. 목록으로 돌아가려면 왼쪽 위 **목록으로** 버튼을 눌러요.
3. 공고에 문제가 있으면 **공고 신고** 버튼을 눌러요.
   - **데스크톱**: 오른쪽 정보 영역의 `1:1 채팅 시작` 아래에 있어요.
   - **휴대폰**: 왼쪽 위 `목록으로` 버튼 바로 오른쪽에 있어요.

신고 방법은 [4. 안전과 신고](#4-안전과-신고)를 보세요.

> 차단한 업체의 공고를 열면 `1:1 채팅 시작` 자리에 "차단한 상대의 공고입니다"라고 나오고 채팅을 시작할 수 없어요. [내 정보 > 차단한 상대](#차단한-상대)에서 차단을 풀면 다시 쓸 수 있어요.

**후기 확인하기**

공고 아래 **후기**에서 이 공고에서 면접을 마친 구직자들의 후기를 볼 수 있어요.

- 후기 보기는 **회원(로그인)만** 돼요. 비회원은 공고 상세로 못 들어와서 후기도 안 보여요.
- 각 후기에는 별점, 후기 내용, 날짜, 작성자 표시가 보여요. 작성자는 **익명** 또는 **이름 일부를 가린 형태**(예: 김\*지)로만 보여요.
- 다른 구직자의 후기는 처음에 **흐리게 가려져** 있어요. 후기를 누르면 "후기를 확인할까요?" 창이 뜨고, "후기를 확인하기 위해서는 N pt를 사용해야합니다!"라는 안내와 함께 **포인트를 써서** 그 후기 하나만 볼 수 있어요. 내가 쓴 후기는 포인트 없이 그냥 보여요.
- 포인트로 연 후기는 **지금 화면에서만** 보여요. 화면을 새로 고치거나 다른 화면에 갔다 오면 다시 가려지고, 볼 때 포인트를 또 써야 해요. 그러니 열었을 때 꼼꼼히 봐 주세요.
- 후기가 많으면 아래 **후기 더보기** 버튼으로 5개씩 더 볼 수 있어요.
- 아직 후기가 없으면 "아직 후기가 없어요"라고 나와요.

### 3-3. 외부에서 수집된 공고

공고 목록과 검색 결과에는 밤비알바에 직접 올린 공고 말고도, 다른 곳에서 모아 온 **수집 공고**가 함께 나와요. 목록·상세 어디에도 수집 공고라는 표시는 없지만, 열었을 때 쓸 수 있는 기능이 달라요.

- 업체가 남긴 **연락처**가 있으면 바로 보여요. 급여·근무시간은 원문 그대로(예: "면접 후 협의") 나올 수 있어요.
- **채팅·지원, 신고, 후기 쓰기는 안 돼요.** 담당자가 밤비알바 이용자가 아니라 응대할 사람이 없기 때문이에요. (후기 자리와 안전 확인은 화면에 나오지만 비어 있어요.)
- 검수·인증 배지도 붙지 않아요.

> 근무 조건·급여·장소는 꼭 **올린 사람에게 직접 확인**해 주세요.

### 3-4. 채팅 시작 전 안전 확인

**1:1 채팅 시작**을 누르면 바로 대화가 열리는 게 아니라, **채팅 전에 안전 상태를 확인하는 화면**이 먼저 나와요.

이 화면(보호 체크)에서는 아래 네 가지 상태를 보여 줘요.

- **로그인 상태**: 로그인이 돼 있는지
- **구직자 프로필**: 구직자 프로필이 준비됐는지
- **휴대폰 인증**: 연락처 보호와 신고 대응을 위한 휴대폰 인증이 됐는지
- **공고 안전 상태**: 공고가 정상 공개 상태인지

**사용법**

1. 표시된 상태를 봐요.
2. 준비가 됐으면 **밤비알바 채팅으로 이동** 버튼을 눌러 대화방을 만들어요. (데스크톱은 오른쪽, 휴대폰은 화면 아래에 버튼이 있어요.)
3. 휴대폰 인증이 안 돼 있으면 채팅을 시작할 수 없다는 안내가 나와요. 이때는 [계정 설정](#계정-설정)에서 휴대폰 인증을 먼저 마쳐 주세요.
4. 앞 화면으로 돌아가려면 위쪽 **공고로 돌아가기**를 눌러요.

> 같은 공고에서 채팅을 여러 번 시작해도 대화방은 하나만 만들어져요. 방을 만들기만 하고 메시지를 안 보내면 채팅 목록에는 안 나와요.

> 로그인이 안 돼 있으면 로그인 화면으로 가요. 차단한 업체의 공고에서는 버튼이 눌리지 않아요.

### 3-5. 채팅 (채팅 탭)

#### 채팅 목록

**무엇을 할 수 있나요?**
지금까지 대화한 방을 한눈에 보고, 이어서 대화할 수 있어요.

- 각 방에는 공고 제목, 상대 이름, 마지막 메시지, 최근 업데이트 시각이 보여요.
- 방 상태 표시가 있어요: `대화 가능`, 차단한 방은 `차단됨`, 상대가 탈퇴한 방은 `대화 불가능`. 안 읽은 메시지가 있으면 데스크톱에서는 `N개 미확인`, 휴대폰에서는 작은 숫자가 붙어요.
- 새 메시지나 새 대화방은 실시간으로 목록에 나타나요.
- 각 방 오른쪽의 **⋮(더보기)** 버튼에서 **신고**, **차단**, **삭제**를 할 수 있어요. 차단과 삭제는 확인 단계 없이 바로 되니 누를 때 조심해 주세요.
- **삭제**는 내 목록에서만 방을 감춰요. 상대가 새 메시지를 보내면 다시 나타나요.
- 차단된 방은 내용이 흐리게 보이고 열 수 없어요. "차단된 채팅입니다."라고 나오고, 더보기에는 삭제만 남아요.

대화방을 누르면 채팅방으로 들어가요. 아직 대화가 없으면 "진행 중인 채팅이 없어요"라고 나와요.

> 참고: 내가 신고한 방은 운영팀이 살펴보는 동안 채팅 목록에서 잠시 감춰져요. 조치가 끝나면 알림으로 알려 드려요.

#### 채팅방에서 대화하기

**무엇을 할 수 있나요?**
업체와 메시지를 주고받고, 면접 일정에 응답하고, 필요하면 신고·차단할 수 있어요.

- 화면 위쪽에는 공고 제목과 상대 이름, **공고 보기** 버튼, `대화 가능`/`차단됨` 상태, `실시간 연결` 상태가 보여요. **공고 보기**를 누르면 대화 중인 공고 상세로 가요. 공고가 내려갔거나 지워졌으면 버튼이 `공고 비공개`·`공고 삭제됨`으로 바뀌어 눌리지 않아요.
- 그 아래에 "연락처 보호 중" 안내와 함께 **신고**·**차단하기** 버튼이 있어요.
- 상대가 글자를 치는 중이면 "상대가 입력 중이에요"라고 보여요.

**메시지 보내기**

1. 아래쪽 입력창에 메시지를 적고 **전송** 버튼을 눌러요. (입력창 안내는 "메시지를 입력하세요"예요.)
2. 사진이나 파일을 함께 보낼 수도 있어요. **JPG·PNG·WebP 이미지나 PDF**를 붙일 수 있고, 한 개당 **10MB**까지예요.

> 상대가 대화방을 지웠어도 새 메시지를 보내면 상대 목록에 다시 나타나요.

### 3-6. 면접 일정과 연락처

#### 면접 일정에 응답하기

면접 일정은 **업체만 제안할 수 있어요.** 구직자는 제안을 받아 응답해요.

1. 업체가 일정을 제안하면 날짜·시간과 함께 `제안됨` 표시가 나와요. 장소 메모가 있으면 같이 보여요.
2. **확정** 또는 **거절** 버튼으로 응답해요.
3. 일정을 확정하면 `확정` 표시로 바뀌고, 그 아래에 **취소** 버튼이 생겨요. 마음이 바뀌면 취소할 수 있어요.
4. 면접을 실제로 마쳤다는 **완료 처리**는 업체가 해요.
5. 한 번 거절하거나 취소한 일정은 되돌릴 수 없어요. 다시 잡으려면 업체가 새로 제안해야 해요.

아직 제안된 일정이 없으면 "아직 제안된 면접 일정이 없어요. 채팅에서 가능한 시간을 조율해보세요."라고 나와요. 원하는 시간대는 채팅으로 알려 주세요.

> 업체가 면접을 제안하면 **대화 중간에 "면접 일정 제안이 도착했어요" 안내 카드**도 같이 나타나요. 오른쪽 "면접 일정" 영역까지 가지 않아도 이 카드의 **확정**·**거절** 버튼으로 바로 응답할 수 있고, 상태가 바뀌면 카드 문구도 따라 바뀌어요.

#### 내 연락처 공개 요청에 응답하기

업체는 채팅방에서 **연락처 공개 요청**을 보낼 수 있어요. 공개할지 말지는 **구직자**가 정해요.

1. 요청이 오면 대화 중간에 "**○○님께서 연락처 공개 요청이 왔습니다. 공개하시겠습니까?**"라는 카드가 나와요.
2. **공개**를 누르면 본인인증으로 등록한 **내 전화번호**가 상대에게 넘어가고, 카드가 "연락처를 공개했습니다."로 바뀌어요.
3. **거절**을 누르면 번호는 넘어가지 않고 "연락처 공개를 거절했습니다."로 바뀌어요.

> 연락처를 공개하려면 **휴대폰 본인인증**이 돼 있어야 해요. 인증 전이면 "본인인증 후 연락처를 공개할 수 있습니다."라고 나와요.

> 한 번 거절해도 업체가 나중에 다시 요청할 수 있어요. 원치 않으면 계속 거절해도 되고, 상대를 차단해도 돼요. 한 번 공개한 번호는 다시 되돌릴 수 없으니 잘 생각하고 정해 주세요.

#### 업체 연락처 확인하기

업체가 휴대폰 본인인증을 마친 경우, 채팅방 "면접 일정" 영역 아래에 **구인자 인증 연락처**가 보여요. 번호를 누르면 바로 전화를 걸 수 있어요. 공고 상세 화면에서도 같은 번호를 볼 수 있어요.

### 3-7. 후기

#### 후기 남기기 (내 정보 → 예정된 면접)

면접이 **완료**된 뒤에 업체 후기를 남길 수 있어요. 후기는 채팅방이 아니라 **내 정보 → [예정된 면접](#예정된-면접)** 화면에서 남겨요. (방을 나가거나 대화가 끝난 뒤에도 남길 수 있도록 자리를 옮겼어요.)

1. **내 정보 → 예정된 면접**에서 후기를 남길 면접 줄을 눌러 펼쳐요.
2. 면접 일시·장소 아래에 **후기 남기기**가 있어요. 오른쪽에 `작성 가능` 또는 `작성 완료` 표시가 붙어요.
3. **별점**(1~5점)을 골라요.
4. **후기** 내용을 **20자 이상 1000자 이하**로 써요. 면접 안내, 공고와 실제 조건이 맞았는지, 응대 경험 같은 것을 적어 주세요. 20자보다 짧으면 **후기 등록** 버튼이 눌리지 않아요.
5. 이름을 드러내고 싶지 않으면 **익명으로 표시**를 켜요. 켜지 않으면 이름 일부를 가린 형태(예: 김\*지)로 보여요.
6. **후기 등록** 버튼을 눌러요. "후기를 등록할까요?" 확인 창이 뜨고, 여기서 **확인**을 누르면 등록돼요.

후기를 등록하면 "후기가 등록됐어요."라고 나와요. 한 공고에는 후기를 **한 번만** 남길 수 있고, 등록한 뒤에는 고치거나 지울 수 없어요.

> 후기를 등록하면 **포인트를 받아요.** 받는 포인트는 운영자가 정하며, 지급되면 알림으로 알려 드려요.

> 후기 남기기는 **구직자에게만**, 그리고 면접이 **완료** 처리된 뒤에만 보여요. 아직 `제안됨`·`확정` 단계면 보이지 않아요.

> 예정된 면접 목록에는 확정 면접이 **면접일로부터 30일**, 완료 면접이 **완료 처리로부터 30일**까지 남아요. 그 기간이 지나 항목이 사라지면 후기를 남길 수 없어요.

> 전화번호, 외부 메신저 아이디, 협박성 표현 등이 들어 있으면 후기가 바로 공개되지 않고 `검수 중인 후기`가 되어 운영팀 확인을 거쳐요. 문제가 없는 후기는 바로 공개돼요.

> **상대를 차단한 뒤에도 그 면접의 후기는 남길 수 있어요.** 차단은 그 상대와 더 대화하지 않겠다는 뜻일 뿐이고, 실제로 면접까지 해 본 경험은 다른 구직자에게 중요한 정보이기 때문이에요.

### 3-8. 수다방

회원과 본인인증을 마친 비회원이 함께 이야기하는 커뮤니티(모임) 공간이에요.

**들어갈 수 있는 분**

수다방의 일반 게시판은 **여성 회원과 광고 중인 업소회원**이 쓸 수 있어요. 본인인증을 마친 남성 구직자는 수다방에 들어가 **공지사항과 비밀게시판**만 이용할 수 있고, 다른 게시판은 열 수 없어요. 성별은 휴대폰 본인인증으로 확인하니 인증을 안 하면 들어갈 수 없어요.

> 계정이 **이용정지**된 경우에는 "차단된 유저는 확인이 불가합니다"가 먼저 뜨고 수다방을 열 수 없어요. 이용정지 중에도 화면 오른쪽 아래 운영자 **1:1 상담**은 계속 쓸 수 있어요.

> 업소회원(구인자) 계정은 성별과 상관없이 **광고 중일 때만** 들어오고 글·댓글을 쓸 수 있어요.

> 가입하지 않은 분도 휴대폰 본인인증에서 **여성으로 확인되면** 수다방에 들어올 수 있어요. 읽기는 회원과 같지만, 글·댓글·추천을 남길 수 있는 게시판은 조금 좁아요 — 아래 **비회원도 글·댓글·추천을 남길 수 있어요**를 보세요.

홈(채용정보) 화면의 수다방 영역에서는 자격과 상관없이 누구나 게시판별 최근 글을 **4개까지 미리보기**로 볼 수 있어요. 여기서 글이나 `더보기`를 눌렀을 때 나오는 안내는 상태에 따라 달라요.

- 로그인했지만 자격이 없는 회원, 또는 남성으로 인증된 비회원: "일반 여성 회원과 광고 중인 업소회원만 가능합니다" 안내가 나와요.
- 아직 로그인도 본인인증도 안 한 분: "본인인증이 필요해요" 창이 뜨고, **본인인증하고 이용하기**로 인증을 마치면 누른 화면으로 돌아와요.

**로그인 없이 볼 수 있는 공개 게시판**

인터넷 검색으로 들어온 분도 읽을 수 있게 `공지사항`·`자유수다`·`밤문화 이야기` 세 게시판은 `밤비알바 주소/board`에서 공개돼요. 화면 위쪽에는 **커뮤니티 게시판 › 공지사항** 같은 현재 위치 표시가 있어 위 목록으로 바로 돌아갈 수 있어요. 중고거래·무료 법률 자문·베스트글, 비밀글, 외부에서 수집된 글은 공개되지 않아요. 본문 이미지도 공개 화면에는 안 보이고 "이미지는 회원 화면에서 볼 수 있어요" 안내로 바뀌어요. 공개 게시판은 이 **세 곳으로 고정**이라, 운영자가 수다방에 게시판을 새로 만들어도 여기에는 안 늘어나요.

> **공개 게시판과 수다방의 차이**: 공개 게시판은 로그인·인증 없이 읽을 수 있는 대신 게시판이 셋으로 좁고 이미지·비밀글이 빠져 있어요. 수다방은 회원 자격이 있거나 본인인증(성인·여성)을 마쳐야 들어가고, 대신 모든 게시판과 본문 이미지를 그대로 볼 수 있어요. 로그인한 회원이 공개 게시판의 글을 열면 "회원 화면에서 보기" 안내가 나와요.

**비회원도 글·댓글·추천을 남길 수 있어요**

가입하지 않아도 **휴대폰 본인인증(성인·여성)** 을 마치면 글·댓글·답글·추천을 남길 수 있어요. 공개 게시판 오른쪽 위 [본인인증하고 글쓰기], 글 아래 안내 카드, 홈 수다방 영역의 안내 창 어디에서 인증해도, 마친 뒤에는 하던 자리로 돌아와요.

글·댓글을 남길 수 있는 게시판은 지금 보고 있는 화면에 따라 달라요.

| 보고 있는 화면 | 참여할 수 있는 게시판 |
| --- | --- |
| 공개 게시판(`밤비알바 주소/board`) | 자유수다, 밤문화 이야기 |
| 수다방(본인인증 후 들어온 화면) | 공지사항과 베스트글을 뺀, 글 쓸 수 있는 게시판 모두 (자유수다, 밤문화 이야기, 중고거래, 무료 법률 자문, 비밀글, 운영자가 새로 만든 게시판) |

- 공지사항은 운영자 게시판이라 비회원은 읽기만 돼요. 베스트글은 자동으로 모이는 곳이라 글을 쓸 수 없어요.
- 비회원 글·댓글에는 **4자 이상 비밀번호**가 꼭 필요해요. 계정이 없으니 이 비밀번호가 본인 확인 수단이고, **고치거나 지울 때 같은 비밀번호를 넣어야** 해요(잊으면 되돌릴 방법이 없어요).
- 작성인 이름은 기본 "비회원"이고 자유롭게 바꿀 수 있지만, 회원과 같은 금칙어(쓰면 안 되는 말) 검사가 돼요. 댓글에는 작성인 칸이 없어 늘 `비회원`으로 보여요.
- 공개 게시판과 비회원 화면에서는 댓글 작성인이 계정 이름 대신 `회원`·`업소 회원`·`비회원` 같은 **유형**으로만 보여요.
- 비회원은 **신고와 이미지 파일 올리기는 못 해요**(회원만 돼요). 본문에 이미지 **주소를 붙여 넣는 것**은 비회원도 돼요.
- 인증은 30일간 이어져요. 지나면 다시 인증해야 글·댓글을 남길 수 있어요(비밀번호만 알면 만료 뒤에도 내 글을 고치거나 지울 수 있어요).
- 로그인한 회원은 공개 화면 대신 회원 화면(`수다방`)에서 참여해요.

**게시판**

| 게시판 | 내용 | 글쓰기 |
| --- | --- | --- |
| 공지사항 | 밤비알바 수다방 공지 | 운영자만 |
| 베스트글 | 최근 30일 동안 추천을 많이 받은 글 | 불가(자동 모음) |
| 자유수다 | 밤비알바 회원들의 자유로운 이야기 | 가능 |
| 밤문화 이야기 | 일·알바 경험과 정보 | 가능 |
| 중고거래 | 회원 간 중고 물품 거래 | 가능 |
| 무료 법률 자문 | 법률자문에게 비밀글로 물어보는 무료 상담 | 가능 |
| 비밀글 | 본인인증 이용자가 익명으로 이야기를 나누는 곳 | 가능 |

> **게시판 목록은 바뀔 수 있어요.** 운영자가 새 게시판을 만들거나 기존 게시판을 감출 수 있어, 화면에 보이는 게시판이 위 표와 다를 수 있어요. 각 게시판의 이름·설명과 순서도 운영자가 바꿀 수 있고, 운영자가 글쓰기를 잠근 게시판은 읽기만 되고 **글쓰기** 버튼이 안 보여요.

> 게시판 이름 앞에 **작은 아이콘**(말풍선·커피·하트 등)이 붙어 있을 수 있어요. 운영자가 게시판마다 정하는 표시예요. 아이콘이 없는 게시판도 쓰는 방법은 똑같아요.

**비밀글 게시판**

`비밀글`은 본인인증을 마친 분들이 **익명으로(이름을 숨기고)** 이야기하는 게시판이에요.

- 글과 댓글의 작성자는 이름 대신 **`밤비`** 와 인증 성별 아이콘으로만 보여요. 실제 닉네임은 다른 사람에게 보이지 않아요.
- **성인 본인인증과 성별 확인**을 마친 분이면 회원·비회원 상관없이 읽고 쓸 수 있어요. 로그인한 회원은 성별·생년월일이 아직 없어도 **읽기**는 되지만, 글·댓글을 **쓰려면** 성별이 포함된 본인인증을 마쳐야 해요.
- 신고는 로그인 회원만 할 수 있어요.

**무료 법률 자문 게시판**

일하다 겪은 임금·계약·부당 대우 같은 문제를 밤비알바가 정한 **법률자문가**에게 무료로 물어볼 수 있는 게시판이에요.

- 이 게시판의 글은 **모두 비밀글**이에요. 글쓰기 화면에 "법률 자문 글은 비밀글로 등록됩니다" 안내가 뜨고, 비밀글 스위치 없이 **비밀번호(4자 이상)** 만 정해요.
- **연락처 (선택)** 를 남길 수 있어요. 답변 안내를 받을 휴대폰 번호이고, 글을 열 수 있는 **본인·운영자·법률자문에게만** 보여요. 비워 둬도 등록돼요.
- 목록에서는 다른 사람에게 제목이 "비밀글입니다"로만 보여요. 본인은 비밀번호로, 운영자와 법률자문은 비밀번호 없이 열어 봐요.
- 가입하지 않은 분도 본인인증(성인·여성)을 마치면 **수다방 화면에서** 이 게시판에 질문할 수 있어요. 로그인 없이 보는 공개 게시판(`/board`)에는 이 게시판이 없어요.
- 답변 댓글에는 **법률자문** 배지가 붙어 전문가 답변임을 알 수 있어요.
- 이 게시판 글은 추천을 많이 받아도 `베스트글`에 올라가지 않아요.

> 답변하는 쪽, 즉 **법률자문가로 지정된 분**의 쓰는 방법은 [3-11. 법률자문가 계정](#3-11-법률자문가-계정-지정된-분만)에 정리돼 있어요.

**글 목록 보기**

- 글 제목 옆에 `공지`(또는 이벤트 글이면 `이벤트`), `광고`, 새 글 표시(`N`, 쓴 뒤 48시간), 댓글 수가 보이고, 아래줄에 작성인·날짜·조회수·추천수가 보여요. 비밀글에는 자물쇠 아이콘이 붙어요.
- 본문에 이미지가 있는 글은 오른쪽에 작은 그림이 붙는데, 목록에서는 **흐리게** 보여요. 원본은 글을 열면 그대로 보여요.
- 글은 20개씩 나뉘어 나오고, 목록 아래 번호로 페이지를 넘겨요.
- 목록 위 **검색창**에 낱말을 넣고 Enter를 누르면 그 게시판에서 **제목·본문**에 그 낱말이 든 글만 보여요. 검색창을 비우고 다시 Enter를 누르면 전체 목록으로 돌아가요.
- `베스트글`·`공지사항`·`무료 법률 자문`을 뺀 게시판에는 **필터** 버튼이 있어 `광고 글보기`, `업소 회원 글보기`, `내가 쓴 글`을 각각 켜고 끌 수 있어요.
- 검색·필터·페이지는 주소에 남아, 2페이지에서 뒤로가기를 하면 1페이지로 돌아와요.
- 글 상세 아래에는 **이전 글·다음 글**로 넘어가는 버튼이 있어요.

**글쓰기**

1. 게시판 오른쪽 위의 **글쓰기** 버튼을 눌러요.
2. **작성인**(30자까지, 기본은 내 이름), **제목**(2~100자), **본문**을 넣어요.
3. 본문 편집기에서 굵게·기울임·취소선·글머리 목록·번호 목록·링크·이미지를 넣을 수 있어요. 이미지는 파일을 올리거나 이미지 주소를 붙여 넣어요.
4. 링크는 글자를 고른 뒤 **링크** 아이콘을 눌러 주소를 넣어요. `example.com`처럼 `https://` 없이 적어도 알아서 붙어요. 본문에 주소를 그대로 적어도 링크로 바뀌고, 링크는 새 창에서 열려요.
5. 다른 사람이 못 보게 하려면 **비밀글로 잠그기**를 켜고 **비밀번호**(4자 이상)를 정해요. `자유수다`에는 이 스위치가 없어요(자유수다에는 비밀글을 쓸 수 없어요). `무료 법률 자문`은 스위치 없이 비밀번호만 정하면 자동으로 비밀글이 돼요.
6. **등록하기**를 눌러요.

> 참고: 구직자는 글 쓸 수 있는 게시판에서 **익명** 칸을 켜서 이름을 숨기고 쓸 수 있어요.

> 제목·본문에 쓰면 안 되는 말이 들어 있으면 "게시할 수 없는 단어가 포함되어 있습니다"라고 나오고 등록되지 않아요.

> 도배를 막으려고 글은 **1분에 한 번만** 등록할 수 있어요. 너무 빨리 다시 등록하면 "글은 1분에 한 번만 등록할 수 있어요. 잠시 후 다시 시도해 주세요."라고 나와요. 댓글은 1분에 5건까지예요.

**글 수정·삭제**

- 내가 쓴 글은 상세 화면에서 **수정**·**삭제**할 수 있어요.
- 글을 쓴 계정으로 로그인한 상태가 아니면, 수정 화면에서 **글 비밀번호**를 넣어야 해요.
- 삭제한 글은 되돌릴 수 없어요. 게시판을 옮길 수는 없어요.

**댓글**

- 글 아래 입력창에서 댓글을 남겨요(1~1000자). 댓글에는 **답글**을 한 번 더 달 수 있고, 답글에 다시 답글은 못 달아요.
- 내 댓글은 고치거나 지울 수 있고, 다른 사람의 댓글에는 깃발(신고) 아이콘이 보여요(회원 화면에만 있어요).
- 업소회원의 댓글이 있으면 **업소 댓글 숨기기** 스위치가 나와요.
- 운영자가 댓글을 잠근 글에는 "운영자가 댓글 작성을 제한한 글입니다."라고 나와요.

**추천**

글 아래 **추천** 버튼으로 마음에 드는 글을 추천할 수 있고, 다시 누르면 취소돼요. 추천을 많이 받은 글은 **베스트글** 게시판에 모여요. 싫어요·비추천은 없어요.

**외부에서 수집된 글**

`밤문화 이야기` 게시판에는 다른 곳에서 모아 온 글이 섞여 나와요. 목록·상세에 따로 표시는 없어요. 이 글에는 **추천·신고는 없지만 댓글은 다른 글과 똑같이** 달 수 있어요(회원·비회원 모두, 답글 1단계까지). 모아 올 때의 댓글이 먼저 보이고 그 아래로 회원·비회원 댓글이 이어져요. 모아 온 댓글은 원본 그대로라 고치거나 지우거나 답글을 달 수 없어요.

### 3-9. 내 정보 (내 정보 탭)

내 프로필을 보고, 신고 내역·글 관리·면접·차단 목록·포인트 내역·계정 설정으로 가고, 로그아웃할 수 있어요.

화면 위쪽에 내 이름과 역할, **인증완료**/**인증 필요** 표시가 있는 프로필 카드가 보여요. 그 아래에 다음 메뉴가 있어요.

- **내 신고 내역**
- **글 관리**
- **예정된 면접**
- **차단한 상대**
- **포인트 내역** ([3-13](#3-13-출석체크) 참고)
- **계정 설정**
- **고객센터**와 **로그아웃**도 쓸 수 있어요. 로그아웃은 데스크톱은 왼쪽 메뉴 맨 아래, 휴대폰은 내 정보 화면 또는 계정 설정 화면 아래에 있어요.

#### 내 신고 내역

내가 넣은 신고를 모아 보여 줘요. 각 항목에는 신고 사유, 신고 대상 종류, 접수 날짜와 처리 상태가 보여요.

| 상태 표시 | 뜻 |
| --- | --- |
| 접수됨 | 신고가 막 들어온 상태 |
| 검토 중 | 운영팀이 살펴보는 중 |
| 처리 완료 | 조치가 끝난 상태 |
| 반려됨 | 신고가 받아들여지지 않은 상태 |

넣은 신고가 없으면 "신고 내역이 없어요"라고 나와요. 한 번 넣은 신고는 취소할 수 없어요.

#### 글 관리

내가 수다방에서 남긴 자취를 모아 보는 곳이에요. **좋아요 누른 글**과 **내가 작성한 글** 두 목록이 있어요. 각 목록 제목을 누르면 아래로 펼쳐지고, 다시 누르면 접혀요. 처음 들어오면 둘 다 접혀 있어요.

- 각 목록은 **10개씩** 보여 주고, 아래 페이지 번호로 넘겨요.
- 표에는 **게시판 / 제목 / 날짜**가 보여요.
- 제목을 누르면 그 글로 가요. 다만 그 글이 지워지거나 옮겨지거나 숨겨져 있으면, 눌렀을 때 "게시판에서 글이 삭제되었거나 이동되어 불러올 수 없습니다"라는 안내가 떠요. 이런 글도 이력에는 그대로 남아 있어요.

#### 예정된 면접

제안·확정된 면접과 최근 완료한 면접을 모아 보여 줘요. 접힌 줄에는 면접 일시, `제안됨`/`확정`/`완료` 상태, 상대 이름과 공고가 보이고, 줄을 누르면 아래로 펼쳐져요.

펼치면 다음이 차례로 보여요.

- **면접 일시와 장소 메모** (장소를 안 적었으면 "장소 메모가 없어요."라고 보여요.)
- **후기 남기기** — 면접이 **완료**된 경우에만 나와요. 쓰는 방법은 [3-7. 후기](#3-7-후기)를 보세요.
- **그 방의 채팅 내역** — 읽기 전용이에요. 위쪽 **이전 메시지 더 보기**로 지난 대화를 거슬러 볼 수 있어요. 여기서는 메시지를 보낼 수 없고, 읽음 표시도 남지 않아요.

목록에는 앞으로의 `제안됨` 면접, 면접일로부터 **30일** 안의 `확정` 면접, 완료 처리로부터 **30일** 안의 `완료` 면접이 남아요. 예정된 면접이 없으면 "예정된 면접이 없어요 / 제안·확정된 면접과 최근 완료한 면접이 여기에 표시됩니다."라고 나와요.

> 일정 **확정·거절·취소**는 채팅방에서 하고, 면접 **완료 처리**는 업체가 해요. 이 화면에서 구직자가 하는 일은 내역 확인과 후기 작성이에요.

#### 차단한 상대

채팅에서 차단한 상대의 목록이에요. 각 항목에는 상대 이름과 차단한 날짜가 보여요.

**차단 해제하기**

1. 풀고 싶은 상대의 **차단 해제** 버튼을 눌러요.
2. 확인 창에서 다시 **차단 해제**를 누르면 풀려요. (**취소**로 되돌릴 수 있어요.)

차단한 상대가 없으면 "차단한 상대가 없어요"라고 나와요.

#### 계정 설정

**무엇을 할 수 있나요?**
표시 이름을 바꾸고, 기본 정보를 보고, 휴대폰 본인인증을 하고, 프로필 사진을 넣고, 회원 탈퇴를 할 수 있어요.

- **프로필**: **표시 이름**은 공고·채팅에 보이는 이름이에요. 2자 이상 넣고 **저장**을 눌러요.
- **기본 정보**: 성별과 생년월일이 보여요. 이 값은 휴대폰 본인인증으로 채워지고 직접 고칠 수 없어요.
- **본인인증**: `인증완료`/`인증 필요` 상태가 보여요.
  1. **휴대폰 인증하기**(이미 인증했다면 **휴대폰 재인증**) 버튼을 눌러요.
  2. 인증 창이 열리면 안내에 따라 통신사 본인인증을 해요.
  3. 인증이 끝나면 인증된 번호가 보이고, 성별·생년월일이 저절로 채워져요.
- **프로필 사진 설정**: **JPG, PNG, WebP** 형식의 **5MB 이하** 이미지를 넣을 수 있어요. **사진 선택**으로 고른 뒤 **저장**을 눌러요. **기본 이미지로 변경**으로 다시 지울 수 있어요.
- **로그아웃**: 휴대폰에서는 이 화면 아래쪽 **로그아웃** 버튼을 써요.
- **회원 탈퇴**: 화면 맨 아래에 있어요. 아래 안내를 봐 주세요.

> 휴대폰 인증을 마쳐야 채팅 시작, 연락처 공개 같은 기능을 쓸 수 있어요.

> 본인인증은 **만 19세 이상**만 할 수 있어요. 또 같은 명의로는 한 계정에서만 인증할 수 있어, 이미 다른 계정에서 인증한 명의로는 인증이 안 돼요.

> 아이디·이메일·비밀번호는 계정 설정에서 바꿀 수 없어요. 비밀번호를 바꾸려면 로그아웃 뒤 로그인 화면의 **비밀번호를 잊으셨나요?**를 써 주세요.

#### 회원 탈퇴

계정 설정 화면 맨 아래 **회원 탈퇴**에서 탈퇴할 수 있어요.

1. 안내 문구를 봐요.
2. **회원 탈퇴** 버튼을 눌러요.
3. "정말 탈퇴하시겠어요?" 확인 창에서 **탈퇴하기**를 누르면 탈퇴가 끝나요. (**취소**로 되돌릴 수 있어요.)

탈퇴하면 이렇게 돼요.

- 바로 모든 기기에서 로그아웃되고, 그 계정으로는 다시 로그인할 수 없어요. 탈퇴한 계정으로 로그인하려고 하면 **"탈퇴한 계정이에요. 로그인할 수 없어요."** 라고 나와요.
- 프로필은 '탈퇴한 회원'으로 보이고, 남긴 채팅·후기도 '탈퇴한 회원'이 쓴 것으로 남아요.
- **포인트로 산 보유 아이템·쿠폰도 함께 사라지고 되돌릴 수 없어요.**
- 아이디·이메일·비밀번호·연락처와 본인인증 정보는 화면에 나온 **보관 기간(기본 30일)** 동안 남았다가 지나면 저절로 지워져요. 보관 기간은 운영팀 설정에 따라 다를 수 있어, 실제 일수는 탈퇴 안내에 그대로 나와요. 그동안에는 **같은 명의로 본인인증을 다시 할 수 없고, 같은 아이디·이메일로 다시 가입할 수도 없어요.**

> 업체 팀에 다른 멤버가 남아 있으면 탈퇴 버튼이 눌리지 않아요. 팀 관리에서 멤버를 모두 정리한 뒤 다시 해 주세요.

### 3-10. 고객센터

데스크톱은 위쪽 메뉴의 **고객센터**, 휴대폰은 **내 정보 > 고객센터**로 들어가요. 로그인한 회원만 쓸 수 있어요.

**자주 묻는 질문(FAQ)**

- 화면 위쪽에서 `전체`, `계정·로그인`, `공고·지원`, `결제·광고`, `신고·제재`, `디자인 제작`, `기타` 갈래를 골라 볼 수 있어요.
- 질문을 누르면 답이 펼쳐져요.

**1:1 문의하기**

1. 고객센터의 **문의 글 등록하기** 버튼을 눌러요.
2. **문의 유형**을 고르고, **제목**(2~100자)과 **내용**(5자 이상)을 적어요. 내용은 굵게·목록·링크와 이미지 첨부를 지원해서, 화면 사진을 붙여 상황을 보여 줄 수 있어요.
3. **문의 등록**을 누르면 접수되고, "문의가 등록됐어요."라고 나오며 문의 상세 화면으로 가요.

**내 문의 내역**

- 고객센터의 **내 문의 내역**에서 지금까지 남긴 문의를 볼 수 있어요. 상태는 `접수됨`, `답변완료`, `종료`로 보여요.
- 문의를 누르면 운영자와 주고받은 내용이 시간순으로 보여요. 아래 입력창에 적고 **보내기**를 누르면 이어서 물어볼 수 있어요.
- 문의를 **종료하는 버튼은 없어요.** 답변이 끝난 문의는 운영자가 종료해요. 종료된 문의에는 더 답할 수 없으니, 새 질문은 새로 등록해 주세요.

> 답변이 올라와도 따로 알림이 안 와요. **내 문의 내역**에서 직접 봐 주세요.

고객센터 화면의 **이용 가이드** 버튼을 누르면 이 설명서를 화면에서 바로 볼 수 있어요. 화면 아래 푸터의 **이용 가이드** 링크로도 들어갈 수 있어요.

**운영자 문의(오른쪽 아래 말풍선 버튼)**

위 **문의 글 등록하기**와는 별개로, 어느 화면에서든 오른쪽 아래에 떠 있는 동그란 **말풍선 버튼**으로 운영자에게 바로 물어볼 수 있어요. **로그인하지 않아도** 돼요. (아주 넓은 화면에서는 이 버튼이 오른쪽 광고 자리 아래에 **1:1 상담**이라는 네모 버튼으로 보이기도 해요.) 버튼을 누르면 아래쪽에 **홈**과 **메시지** 두 탭이 있는 문의 창이 열려요.

**홈 탭**

- 창을 열면 처음 보이는 화면이에요. "안녕하세요 👋 / 무엇을 도와드릴까요?" 인사와 함께 **메시지를 보내주세요** 버튼이 있어, 누르면 바로 대화를 시작해요. 진행 중인 대화가 있으면 그 대화로 이어져요.
- 운영자가 올린 **공지 문구**가 있으면 인사 아래에 보여요(없으면 안 보여요).
- 아래쪽 **자주 묻는 질문** 목록에서 항목을 누르면 고객센터 FAQ로 가요.

**메시지 탭**

- 지금까지 운영자와 나눈 **대화 목록**이 최근 순으로 보여요. 각 대화에는 마지막 메시지 미리보기와 시각, 안 읽은 개수 표시가 붙고, 끝난 대화에는 `종료` 표시가 보여요.
- 대화를 누르면 주고받은 내용이 열려요. 아래 입력창에 적어 **전송**(또는 Enter)하면 접수돼요. 한 번에 1,000자까지, **1분에 10번**까지 보낼 수 있어요.
- 목록 아래 **메시지를 보내주세요** 버튼으로 언제든 **새 대화**를 시작할 수 있어요.

**대화 종료와 새 대화**

- 운영자가 답을 마치면 대화를 **종료**할 수 있고, 마지막 메시지 뒤 **7일 동안 오간 내용이 없으면 저절로 종료**돼요.
- 종료된 대화에는 더 보낼 수 없어요. 대화 화면에 "종료된 대화예요." 안내와 **새 대화 시작** 버튼이 나오니, 이어서 궁금한 게 생기면 새 대화를 시작해 주세요. 지난 대화는 **메시지** 탭에 그대로 남아요.

**안 읽은 답변·발신 잠금**

- 운영자가 답하면 말풍선 버튼과 **메시지** 탭에 안 읽은 표시가 붙어요. 로그인한 회원은 **알림함(종 모양)** 으로도 답변 도착을 볼 수 있고, 그 알림을 누르면 문의 창이 저절로 열려요.
- 운영자가 도배 등을 이유로 발신을 잠근 경우 "문의 발신이 제한된 상태예요."라고 나오고 더 보낼 수 없어요. 이 잠금은 새 대화를 시작해도 그대로예요.

> 참고: 운영자 문의 말풍선은 로그인 없이 보는 공개 화면(`/jobs`·`/board`)과 채팅방 안에서는 보이지 않아요. 운영자 계정에서도 안 보여요.

### 3-11. 법률자문가 계정 (지정된 분만)

**법률자문가란?**
수다방 `무료 법률 자문` 게시판에 올라온 상담 글을 열어 보고 답변하는 역할이에요. 운영자가 **구직자 계정에** 지정하며, 지정과 해제 모두 운영자만 해요(본인이 신청하거나 스스로 해제하는 메뉴는 없어요). 업소(구인자)·운영자 계정에는 지정할 수 없어요.

지정되면 **내 정보** 화면 위쪽 프로필 카드의 역할 표시가 **법률자문가**로 바뀌어요. 로그인 뒤 첫 화면과 메뉴는 구직자와 같아요. (게시판·댓글에 붙는 배지에는 `법률자문`으로 보여요.)

**수다방 입장**

- 성별이나 광고 여부와 상관없이 수다방에 들어갈 수 있어요. 일반 회원에게 있는 입장 조건(여성 회원·광고 중인 업소회원)이 법률자문가에게는 적용되지 않아요.

**쓸 수 있는 범위**

- 수다방에서 쓸 수 있는 게시판은 `무료 법률 자문` **하나뿐**이에요. 나머지 게시판은 공지사항·베스트글을 포함해 읽기·글쓰기가 모두 막혀요.
- 수다방 홈과 구직자 홈의 수다방 미리보기에는 다른 게시판 카드도 **그대로 보여요.** 그 카드의 글이나 `더보기`를 누르면 "법률자문 계정은 무료 법률 자문 게시판만 이용할 수 있어요." 안내만 뜨고 이동하지 않아요(`무료 법률 자문` 카드와 수다방 홈 링크는 정상적으로 이동해요).
- 다른 게시판 탭을 누르거나 주소로 직접 들어가면 곧바로 `무료 법률 자문` 목록으로 되돌아와요.

**무료 법률 자문 게시판에서 할 수 있는 일**

- 목록에서 제목이 "비밀글입니다"로 가려지지 않고 **실제 제목**이 보여요.
- 글을 열 때 **비밀번호를 묻지 않아요.** 상담 글은 모두 비밀글이지만 법률자문가는 그대로 열어 봐요.
- 글쓴이가 남긴 **연락처**(선택 입력)를 볼 수 있어요.
- 댓글로 답을 남길 수 있고, 그 댓글에는 **법률자문** 배지가 붙어요. 댓글에 달린 답글에도 한 번 더 답할 수 있어요.
- 내가 남긴 댓글은 고치거나 지울 수 있어요.
- 이 게시판에 직접 글을 쓸 수도 있어요. 이때도 글은 자동으로 비밀글이 되고 **비밀번호(4자 이상)** 를 정해야 해요.
- 금칙어 검사, 글 1분에 한 번 등록 제한 같은 수다방 공통 규칙은 [3-8. 수다방](#3-8-수다방)과 같아요.

**할 수 없는 일**

- 지정돼 있는 동안에는 **새 채팅을 시작할 수 없어요.** 공고 상세에 채팅 버튼이 안 나오고, 채팅 시작 화면 주소로 직접 들어가도 홈으로 돌아와요. 지정 전에 만든 대화방은 **채팅** 탭에서 그대로 이어 볼 수 있어요.
- **채팅방·채팅 메시지 신고**는 구직자만 할 수 있어요. 공고 신고와 수다방 글·댓글 신고는 그대로 할 수 있어요.
- **출석·포인트 적립**은 이용할 수 없어요.
- 그 밖의 화면(채용정보 탐색, 고객센터, 내 정보, 계정 설정)은 구직자와 똑같이 써요. 알림(종 모양)도 그대로 쓸 수 있고, 담당 게시판에 새 상담 글이 올라오면 알림이 와요.

**지정이 풀리면**

- 운영자가 **법률자문 해제**를 하면 바로 구직자로 돌아와요. 역할 표시가 `구직자`로 바뀌고, 수다방의 다른 게시판과 새 채팅도 다시 쓸 수 있어요.
- 다만 해제 뒤 수다방 이용 자격은 일반 구직자 기준으로 돌아가요. 본인인증에서 여성으로 확인된 계정이 아니면 수다방에 못 들어가요.
- 지정 기간에 쓴 글과 답변 댓글은 그대로 남아요.

### 3-12. 알림

**무엇을 할 수 있나요?**
면접·검수·답변처럼 바로 알아야 하는 소식을 한곳에 모아 보고, 누르면 그 화면으로 바로 갈 수 있어요.

**화면 구성과 사용법**

1. 화면 오른쪽 위(휴대폰은 화면 맨 위 오른쪽)의 **종 모양 버튼**을 누르면 **알림** 화면으로 가요.
2. 안 읽은 알림이 있으면 종 위에 숫자가 붙어요. 9개를 넘으면 **9+**로 보여요.
3. 각 알림에는 소식 제목과 받은 시각이 보이고, 아직 안 읽은 알림에는 **새 알림** 표시와 함께 테두리가 강조돼요.
4. 알림을 누르면 저절로 읽음 처리되고 그 화면으로 가요.
5. 오른쪽 위 **모두 확인**을 누르면 안 읽은 알림이 한 번에 읽음 처리돼요. (안 읽은 알림이 없으면 버튼이 잠겨요.)
6. 그 옆의 **알림 비우기**를 누르면 "알림을 모두 비울까요?" 창이 뜨고, **비우기**를 고르면 읽은 알림까지 다 지워져요. 되돌릴 수 없고, 알림이 하나도 없으면 이 버튼은 안 보여요.
7. 알림이 20개를 넘으면 아래 **더보기** 버튼으로 이어 볼 수 있어요.

**받게 되는 알림(예시)**

| 알림 | 누르면 가는 곳 |
| --- | --- |
| 면접 제안이 도착했어요 | 예정된 면접 |
| 면접 일정이 확정됐어요 / 면접 제안이 거절됐어요 / 면접이 취소됐어요 / 면접이 완료 처리됐어요 | 예정된 면접 |
| 연락처가 공개됐어요 | 해당 채팅방 |
| 문의에 답변이 도착했어요 / 문의 채팅에 답변이 도착했어요 | 해당 문의 |
| 신고 처리 결과가 나왔어요 | 내 신고 내역 |
| 내 글에 새 댓글이 달렸어요 / 내 댓글에 답글이 달렸어요 | 해당 수다방 글 |
| 내 글이 숨김 처리됐어요 / 삭제됐어요 | 해당 수다방 글 |
| 내 후기가 게시됐어요 / 숨김 처리됐어요 | 후기를 남긴 공고 |
| 운영자로부터 포인트가 지급됐어요 | 포인트 내역 |
| 보유 아이템이 곧 만료돼요 | 포인트 내역 |
| 운영자 쪽지가 도착했어요 | 쪽지함([3-15](#3-15-쪽지함)) |

> 새 채팅 메시지는 알림 목록에 쌓이지 않아요. 채팅은 **채팅** 탭의 안 읽은 숫자로 봐 주세요.

**브라우저 알림 허용**

알림 화면 위쪽에 **탭이 꺼져 있어도 알림을 받을 수 있어요** 안내가 보이면, **브라우저 알림 허용** 버튼을 눌러 켤 수 있어요. 켜면 밤비 탭을 안 보고 있을 때도 새 알림이 바로 뜨고, 그 알림을 누르면 그 화면이 열려요. 켜지 않아도 알림함은 그대로 쓸 수 있어요.

### 3-13. 출석체크

**어떤 화면인가요?**
`내 정보 > 포인트 내역` 화면이에요. 여기서 하루 한 번 출석 도장을 찍고, 모은 포인트와 등급, 산 아이템, 구매 내역을 한곳에서 볼 수 있어요.

**어디에 있나요?**
**내 정보** → **포인트 내역**으로 들어가요.

**오늘 출석**

1. **오늘 출석** 칸에서 **연속 출석**, **총 출석**, **포인트** 잔액을 봐요. 포인트 옆에는 내 등급 배지가 함께 보여요.
2. **출석하기** 버튼을 누르면 오늘 출석이 기록되고 "출석했어요. +N 포인트 적립!"이라고 나와요. (받는 포인트 수는 운영자가 정하며 화면에 그대로 보여요.)
3. 출석을 마치면 버튼이 **출석 완료**로 바뀌며 잠겨요. 하루에 한 번만 되고, 같은 날 다시 눌러도 포인트가 더 쌓이지 않아요.

**출석 달력**

- **출석 달력** 줄을 누르면 아래로 펼쳐져 이번 달 출석 현황이 나와요.
- **색이 채워진 날**이 출석한 날이고, **테두리가 있는 날**이 오늘이에요.
- 달력 오른쪽 위의 **‹ ›** 버튼으로 이전 달·다음 달을 볼 수 있어요.

**내 아이템·구매 내역·포인트 내역**

- 달력 아래에 포인트몰에서 산 **내 아이템(보유함)**, **구매 내역**, 포인트가 들고 난 **내역**이 이어져요. 자세한 내용은 [3-14. 포인트몰](#3-14-포인트몰)을 보세요.

> 출석 날짜는 한국 시간(KST) 기준으로 서버가 정해요. 기기 시계를 바꿔도 출석일은 달라지지 않아요.

> **연속 출석**은 오늘 아직 출석하지 않았어도 어제까지 이어진 기록이 그대로 보여요. 하루를 건너뛰면 다시 1일부터예요.

> **운영자가 포인트를 더해 주거나 뺄 수 있어요.** 이벤트 보상이나 잘못 쌓인 포인트를 되돌리는 경우이며, 바뀌면 포인트 잔액에 바로 보여요. 잔액이 마이너스가 되지는 않아요. 이유를 모르는 변동이 있으면 고객센터로 물어봐 주세요.

> 출석체크는 따로 알림을 보내지 않아요. 출석하러 올 때는 **내 정보 → 포인트 내역**을 직접 열어 주세요.

**포인트 광고로 포인트 받기**

공고 목록의 광고에는 하루에 하나씩 **포인트 대상** 광고가 정해져요.

- 매일 00시(한국 시간)에 프리미엄·스페셜·추천 광고에서 대상이 각각 하나씩 뽑혀요.
- `POINT` 표시가 붙은 광고를 눌러 공고 상세를 확인하면 포인트를 받고, 알림과 포인트 내역에 남아요. 받을 때 "N포인트를 받았어요."라고 나와요.
- 프리미엄·스페셜·추천은 서로 따로예요. 각 유형은 포인트를 받은 순간부터 24시간 뒤에 다시 받을 수 있어요.
- 날짜가 바뀌어 대상 광고가 달라져도 내 24시간이 남아 있으면 아직 못 받아요. 아직 안 받은 유형은 시간이 시작되지 않아요.

### 3-14. 포인트몰

**무엇을 할 수 있나요?**
출석과 수다방 활동으로 모은 포인트로, 운영팀이 준비한 아이템을 신청(구매)할 수 있어요. 아이템에는 운영팀이 직접 챙겨 주는 **직접 지급·쿠폰 발송** 유형과, 사 두었다가 내 공고에 쓰는 **끌어올리기·광고 기간 연장** 혜택이 있어요. (끌어올리기는 내 공고를 목록 위쪽으로 올리는 것을 말해요.) 목록은 로그인하지 않아도 볼 수 있고, **구매만 회원**이 해요.

**어디에 있나요?**
데스크톱은 위쪽 메뉴의 **포인트몰**(수다방과 고객센터 사이)이에요. 휴대폰에서는 화면 위쪽 머리줄의 **상점 아이콘**(돋보기 검색과 알림 종 사이)을 누르면 들어가요.

**화면 구성**

- 맨 위에 광고 배너가 보이고, 그 아래 **포인트 아이템** 목록이 카드로 깔려요. 카드에는 아이템 그림, 오른쪽 위에 가격(예: `5,000P`), 아래에 이름이 보여요. (그림을 안 넣은 아이템은 선물 상자 그림으로 보여요.)
- 재고가 다 팔린 아이템에는 그림 위에 **품절** 도장이 찍혀요. 눌러서 창은 열리지만 구매는 안 돼요.
- 내 포인트 잔액은 화면 위쪽의 **보유 포인트 칩**(예: `1,200P`)에 보여요. 로그인한 회원에게만 보여요.
- 아직 아이템이 없으면 "준비 중인 아이템이 없어요"라고 나와요.

**혜택 유형**

구매 창을 열면 아이템 이름 옆에 혜택 유형이 배지로 보여요(직접 지급 아이템은 배지가 없어요).

| 유형 | 무엇인가요 |
| --- | --- |
| (표시 없음) 직접 지급 | 운영팀이 확인한 뒤 직접 챙겨 주는 아이템 |
| 쿠폰 발송 | 본인인증한 휴대폰 번호로 운영팀이 쿠폰을 보내 주는 아이템 |
| 끌어올리기(기간) · 끌어올리기 횟수권 · 자동 끌어올리기(기간) | 사 두었다가 내 공고를 목록 위로 올리는 혜택 |
| 광고 기간 연장 | 사 두었다가 내 공고의 노출 기간을 늘리는 혜택 |

**구매하는 방법**

1. 원하는 아이템 카드를 눌러요. 창이 열리고 그림·이름·설명·유형 배지와 함께 **필요 포인트**·**내 포인트**가 나란히 보여요.
2. 포인트가 모자라면 "포인트가 3,000P 부족해요."처럼 부족한 양이 나오고 **구매하기** 버튼이 잠겨요.
3. 끌어올리기·광고 연장 혜택이면 "구매 후 N일 이내에 보유함에서 사용해야 하며, 기한이 지나면 소멸돼요(환불 불가). 사용 후에는 취소·환불이 불가하고, 사용 전에는 취소·환불할 수 있어요."라는 안내가 함께 떠요.
4. 쿠폰 발송 아이템이면 "본인인증 시 등록된 휴대폰 번호로 발송돼요. 지급완료 전에는 취소·환불할 수 있어요."라고 나와요. 아직 휴대폰 본인인증을 안 했다면 "본인인증을 완료하면 구매할 수 있어요."가 뜨고 **본인인증 하기** 버튼이 나와요. 그 자리에서 인증을 마치면 구매 버튼이 열려요.
5. **구매하기**를 누르면 그 자리에서 포인트가 빠지고 주문이 접수돼요. "구매했어요. 내 정보 → 포인트 내역에서 확인할 수 있어요."라고 나오고, 위쪽 보유 포인트 칩도 바로 줄어들어요. (**닫기**를 누르면 구매하지 않고 창만 닫혀요.)
6. 로그인하지 않은 채로 카드를 누르면 로그인 화면으로 가요. 로그인 뒤 다시 포인트몰로 들어와 주세요.

> **직접 지급·쿠폰 발송 아이템은 운영팀이 확인한 뒤 챙겨 드려요.** 자동으로 바로 오지 않으니, 구매 뒤에는 **내 정보 → 포인트 내역**의 **구매 내역**에서 처리 상태를 봐 주세요. 끌어올리기·광고 연장 혜택은 아래 **내 아이템**에서 직접 써요.

> 아이템에 따라 **구인 회원 전용** 또는 **구직 회원 전용**인 것이 있어요. 대상이 아니면 "구인 회원 전용 혜택이에요."처럼 나오고 구매 버튼이 안 나와요. 끌어올리기·광고 연장 혜택은 공고가 있는 회원만 쓸 수 있어요.

> 구매는 **구직자·업소 회원**만 할 수 있어요. 법률자문가 계정으로는 살 수 없어요.

> 품절된 아이템을 사려 하면 "지금은 품절된 아이템이에요."라고 나오고, 운영팀이 판매를 내린 아이템이면 "판매가 종료된 아이템입니다."라고 나와요.

> 포인트몰에서 쓴 포인트는 **수다방 등급 계산에서 빠져요.** 아이템을 사도 등급이 내려가지 않고, 환불받아도 등급이 올라가지 않아요.

#### 내 아이템(보유함)

끌어올리기·광고 연장 혜택은 사는 즉시 쓰이는 게 아니라 **내 정보 → 포인트 내역**의 **내 아이템** 카드에 담겨요. 이 카드를 펼치면 "사용할 수 있는 혜택 N건"과 함께 각 혜택의 이름·유형 배지·사용 기한(`2026.08.25까지` 또는 `무기한`)이 보여요.

- **사용하기**를 누르면 "혜택을 사용할 공고를 선택해 주세요." 창이 열려요. 공고를 고르면 "사용하면 되돌릴 수 없어요. 선택한 공고에 바로 적용돼요."라는 확인이 뜨고, **이 공고에 사용하기**를 누르면 "혜택을 사용했어요."라고 나와요.
- 혜택은 **게시 중인 유료 공고**에만 쓸 수 있어요. 쓸 수 있는 공고가 없으면 "사용할 수 있는 공고가 없어요. 게시 중인 유료 공고에만 쓸 수 있어요."라고 나와요.
- 아직 안 쓴 혜택은 **취소·환불** 버튼으로 되돌릴 수 있어요. "{아이템} 구매를 취소할까요? N P를 돌려드려요." 확인 뒤 취소하면 포인트가 바로 잔액으로 돌아와요.
- **사용 기한이 지나면** 항목에 **기한 만료** 표시가 붙고 "사용 기한이 지나 더는 사용하거나 취소할 수 없어요."라고 나와요.
- 보유한 혜택이 없으면 "보유한 혜택이 없어요..."라고 나와요.

> 보유한 혜택의 사용 기한이 다가오면 **보유 아이템이 곧 만료돼요** 알림이 와요. 알림을 누르면 포인트 내역 화면으로 가요.

#### 구매 내역

**내 정보 → 포인트 내역**의 **구매 내역**을 펼치면 지금까지 신청한 아이템을 최신순으로 볼 수 있어요. 각 항목에는 아이템 이름, 빠진 포인트(예: `-5,000P`), 상태 배지, 주문 일시가 보여요.

| 상태 표시 | 뜻 |
| --- | --- |
| 주문완료 | 직접 지급·쿠폰 주문이 접수되어 운영팀 지급을 기다리는 상태 |
| 지급완료 | 운영팀이 아이템(또는 쿠폰)을 준 상태 |
| 보유 중 | 끌어올리기·광고 연장 혜택을 사서 아직 안 쓴 상태(사용은 **내 아이템**에서) |
| 사용 완료 | 끌어올리기·광고 연장 혜택을 공고에 쓴 상태 |
| 취소·환불 | 주문이 취소되고 포인트를 돌려받은 상태 |

- 취소된 주문에는 "주문이 취소되어 포인트를 돌려드렸어요."라는 안내가 함께 보이고, 빠진 포인트에 취소선이 그어져요. 돌려받은 포인트는 바로 잔액에 다시 더해져요.
- 운영팀이 메모를 남긴 주문에는 **운영자 메모**가 함께 보여요. 취소 사유는 보통 여기에 적혀 있어요.
- **주문완료** 상태의 직접 지급·쿠폰 주문에는 **취소·환불** 버튼이 있어, 지급 전이면 직접 취소하고 포인트를 돌려받을 수 있어요(끌어올리기·광고 연장 보유 건의 취소는 **내 아이템**에서 해요).
- 산 아이템이 없으면 "아직 구매한 아이템이 없어요"라고 나와요.

> 이미 **지급완료**되었거나 **사용 완료**한 주문은 직접 취소할 수 없어요. 잘못 지급됐거나 지급이 너무 늦으면 포인트몰의 **1:1 상담** 또는 [고객센터](#3-10-고객센터)로 물어봐 주세요.

> 구매 내역은 따로 알림을 보내지 않아요(보유 아이템 만료 임박 알림은 예외). 처리 상태는 이 화면에서 직접 봐 주세요.

### 3-15. 쪽지함

**무엇을 할 수 있나요?**
운영팀이 보내는 안내 쪽지를 받아 보는 곳이에요. 이벤트 안내나 계정 관련 알림처럼 운영팀이 직접 전하는 소식이 여기로 와요. **운영팀이 보내는 쪽지만 받는 곳이라, 여기서 답장을 보내지는 못해요.** 물어볼 것이 있으면 [고객센터](#3-10-고객센터)의 문의하기를 이용해 주세요.

**어디에 있나요?**
**내 정보 → 쪽지함**으로 들어가요. (데스크톱은 화면 오른쪽 위 **내 정보**, 휴대폰은 아래 탭 **내 정보**로 들어간 다음 **쪽지함**을 눌러요.) 안 읽은 쪽지가 있으면 메뉴의 **쪽지함** 옆에 안 읽은 개수가 코럴색 숫자로 붙고, 99개를 넘으면 **99+**로 보여요.

**쪽지가 오면**
새 쪽지가 도착하면 **운영자 쪽지가 도착했어요** 알림이 와요. 이 알림을 누르면 바로 쪽지함으로 가요.

**화면 구성과 사용법**

1. 위쪽에 **받은 쪽지**와 **보관함** 두 갈래가 있어요. 처음에는 **받은 쪽지**가 보여요.
2. 목록의 각 줄에는 제목과 내용 첫 줄, 받은 시각이 보여요. 아직 안 읽은 쪽지에는 **새 쪽지** 표시가 붙고 제목이 진하게 보여요.
3. 쪽지를 누르면 전체 내용이 담긴 창이 열리고, **여는 순간 자동으로 읽음 처리돼요**(안 읽은 표시와 숫자가 사라져요).
4. 목록이 길면 아래 **더 보기** 버튼으로 이어서 봐요.

**보관하기**
쪽지 창 아래 **보관** 버튼을 누르면 그 쪽지가 **보관함**으로 옮겨져 받은 쪽지 목록에서는 빠져요. 나중에 보관함에서 그 쪽지를 열어 **보관 해제**를 누르면 다시 받은 쪽지로 돌아와요.

**삭제하기**
쪽지 창 아래 **삭제** 버튼을 누르면 "쪽지를 삭제할까요?" 확인 창이 떠요. **삭제**를 한 번 더 누르면 지워져요.

> ⚠ **삭제한 쪽지는 쪽지함에서 사라지고 되돌릴 수 없어요.** 두고 보고 싶은 쪽지는 삭제 대신 **보관**을 써 주세요.

> 받은 쪽지가 없으면 "도착한 쪽지가 없어요", 보관함이 비어 있으면 "보관한 쪽지가 없어요"라고 나와요.

## 4. 안전과 신고

문제가 되는 공고나 상대를 만나면 신고하거나 차단할 수 있어요.

### 신고하기

신고는 아래 자리에서 시작할 수 있어요.

- **공고 상세 화면**의 **공고 신고** 버튼 (데스크톱은 오른쪽, 휴대폰은 `목록으로` 버튼 오른쪽)
- **채팅방 안**의 **신고** 버튼
- **채팅 목록**의 **⋮(더보기) > 신고**
- **수다방** 글·댓글의 깃발 아이콘 (신고는 회원만 돼요)

신고 방법은 같아요.

1. 신고 창이 열리면 아래 사유 중 하나를 골라요.
   - 성매매·성적 서비스 암시
   - 강요·협박·착취
   - 미성년 관련
   - 허위 공고·사기
   - 외부 연락처 유도
   - 욕설·혐오 표현
   - 기타
2. 필요하면 어떤 상황인지 글로 적어요. (선택이며, 적어 주시면 처리가 빨라져요.)
3. **신고 접수** 버튼을 눌러요.
4. "신고가 접수됐어요" 안내가 나오면 **확인**을 눌러요.

> 신고는 익명으로 운영팀에 전해지고, 운영팀이 내용을 보고 조치해요. 넣은 신고는 [내 정보 > 내 신고 내역](#내-신고-내역)에서 처리 상태를 볼 수 있어요.

> 같은 대상을 여러 번 신고해도 한 건으로 처리돼요. 외부에서 수집된 공고는 신고 대상이 아니에요(밤비알바에 등록된 공고가 아니에요).

### 차단하기

채팅방에서 상대와 더 대화하고 싶지 않으면 차단할 수 있어요.

1. 채팅방 위쪽의 **차단하기** 버튼을 눌러요.
2. "이 상대를 정말 차단할까요? 차단하면 서로 대화할 수 없어요." 확인이 나오면 **차단**을 눌러요. (**취소**로 되돌릴 수 있어요.)
3. 차단하면 서로 대화할 수 없게 되고, 채팅 목록으로 가요.

채팅 목록의 **⋮(더보기) > 차단**으로도 차단할 수 있어요. 이 경우에는 확인 없이 바로 차단돼요.

차단한 상대는 [내 정보 > 차단한 상대](#차단한-상대)에서 언제든 풀 수 있어요.

> 차단하면 그 상대와의 대화방에 못 들어가서 메시지·면접 응답·연락처 공개도 이어갈 수 없어요. 다만 공고 목록에서는 차단한 업체의 공고가 계속 보일 수 있고, 공고를 열면 채팅 버튼이 눌리지 않아요. 수다방 글에는 차단이 적용되지 않아요.

> **후기는 차단해도 남길 수 있어요.** 완료된 면접이라면 상대를 차단한 뒤에도 [내 정보 > 예정된 면접](#예정된-면접)에서 후기를 등록할 수 있어요([3-7. 후기](#3-7-후기) 참고).

### 안전을 위한 주의사항

- 내 전화번호·카카오톡 같은 **외부 연락처를 먼저 알려주지 마세요.** 밤비알바에서는 업체가 **연락처 공개 요청**을 보내고, 내가 **공개**를 눌렀을 때만 번호가 넘어가요.
- 채팅에서 **밖의 메신저로 옮겨 연락하자는 유도**를 받으면 신고해 주세요.
- 공고에 적힌 조건과 실제 조건이 다르면 신고할 수 있어요.
- 외부에서 수집된 공고는 밤비알바 검수를 거치지 않았어요. 조건은 꼭 올린 사람에게 직접 확인해 주세요.

### 경고·이용 정지 안내 배너

운영팀이 계정에 경고나 이용 정지 같은 조치를 하면, 로그인 뒤 화면 위쪽에 안내 띠(배너)가 보여요.

- **운영자 경고를 받았어요**: 정책 위반 소지가 확인돼 경고가 온 상태예요. 같은 문제가 되풀이되면 이용이 막힐 수 있으니 활동을 다시 봐 주세요. 경고 띠는 오른쪽 **X(닫기)**로 닫을 수 있어요. 닫은 경고는 다시 안 뜨지만, 운영팀이 **새 경고**를 보내면 다시 나타나요. 경고 상태에서도 기능 이용에는 제한이 없어요.
- **계정 이용이 정지되었어요**: 정책 위반이 확인돼 이용이 막힌 상태예요. "정책 위반이 확인되어 공고 등록·지원·채팅 등 일부 이용이 제한되었어요."라고 나와요. 정지 띠는 **닫을 수 없고**, 정지가 풀릴 때까지 계속 보여요. 정지 중에는 공고 지원 채팅·신고·차단·후기·수다방 같은 기능이 막히지만, 화면 오른쪽 아래 **운영자 문의(1:1 상담)**의 기존 대화 보기·새 문의·메시지 보내기는 계속 쓸 수 있어요.

띠에는 운영팀이 남긴 조치 사유와 함께 "이 조치에 이의가 있다면 고객센터로 문의해 이의를 신청할 수 있어요."라는 안내가 보여요. 조치가 풀려 계정이 정상으로 돌아오면 띠는 저절로 사라져요.

## 5. 자주 묻는 질문

### 가입 후 이용 안내

신규 구직자 가입이 완료되면 공고 탐색, 채팅, 면접·연락처, 후기·안전 기능을 소개하는 4단계 이용 안내가 한 번 표시됩니다. 좌우로 밀거나 `이전`·`다음` 버튼으로 이동하고, 마지막 `시작하기`를 누르면 채용정보 메인에서 검색·채팅·내 정보 위치를 차례로 안내합니다. `건너뛰기`를 누르면 남은 화면과 위치 안내를 모두 생략합니다.

이용 안내는 처음 화면이 표시된 기기와 브라우저에 완료 상태가 저장됩니다. 브라우저 데이터를 지우거나 다른 기기·브라우저를 사용하면 다시 나타날 수 있습니다. `내 정보 > 계정 설정 > 이용 안내`에서 구직자 안내와 공통 기능 안내를 언제든 다시 볼 수 있습니다.

**Q. 회원가입을 꼭 해야 하나요?**
공고 목록은 비회원(휴대폰 본인인증)으로도 볼 수 있고, 여성으로 인증되면 수다방까지 쓸 수 있어요. 공고 상세 보기와 채팅은 회원가입이 필요해요.

**Q. 회원가입할 때 본인인증부터 하라고 나와요.**
맞아요. 밤비알바 회원가입은 본인인증을 먼저 마쳐야 정보 입력 폼이 열리는 2단계 방식이에요. 만 19세 이상만 가입할 수 있어요.

**Q. 제 전화번호는 언제 상대에게 보이나요?**
업체가 채팅방에서 **연락처 공개 요청**을 보내고, 회원님이 **공개**를 눌렀을 때만 넘어가요. **거절**을 누르면 넘어가지 않아요. 공개하려면 휴대폰 본인인증이 돼 있어야 해요.

**Q. 업체 전화번호는 어디서 보나요?**
업체가 휴대폰 본인인증을 마쳤다면 공고 상세 화면과 채팅방 "면접 일정" 영역 아래에 보여요.

**Q. 채팅을 시작하려는데 휴대폰 인증을 하라고 나와요.**
채팅 시작에는 휴대폰 본인인증이 필요해요. [내 정보 > 계정 설정 > 본인인증](#계정-설정)에서 먼저 마쳐 주세요.

**Q. 면접 일정은 제가 제안할 수 있나요?**
면접 일정 제안은 **업체만** 할 수 있어요. 구직자는 제안된 일정을 채팅방에서 **확정**하거나 **거절**할 수 있고, 확정한 뒤에는 **취소**할 수 있어요. 가능한 시간은 채팅으로 맞춰 보세요.

**Q. 후기는 언제 남길 수 있나요?**
면접이 **완료**된 뒤에 **내 정보 → 예정된 면접**에서 그 면접을 펼치면 나오는 "후기 남기기"에서 별점(1~5점)과 20자 이상의 후기를 남길 수 있어요(채팅방에서는 안 남겨요). 한 공고에 한 번만 되고, 등록 뒤에는 고치거나 지울 수 없어요. 후기를 남기면 포인트도 받아요.

**Q. 마음에 드는 공고를 저장해 둘 수 있나요?**
찜·스크랩 기능은 없어요. 검색이나 빠른 탐색으로 다시 찾아 주세요.

**Q. 채팅을 시작했는데 채팅 목록에 안 보여요.**
메시지를 한 번도 주고받지 않은 방은 목록에 안 나와요. 공고 상세에서 다시 채팅을 시작하면 같은 방으로 들어가요.

**Q. 수다방에 들어가려니 이용할 수 없다고 나와요.**
일반 수다방 게시판은 여성 회원과 광고 중인 업소회원이 쓸 수 있어요. 인증된 남성 구직자는 공지사항과 비밀게시판만 이용할 수 있습니다. 인증을 안 했다면 먼저 [계정 설정](#계정-설정)에서 인증해 주세요. 가입하지 않은 분도 여성으로 인증되면 들어올 수 있어요.

**Q. 가입하지 않고도 수다방에 글을 쓸 수 있나요?**
휴대폰 본인인증(성인·여성)을 마치면 수다방에서 공지사항·베스트글을 뺀 게시판(자유수다·밤문화 이야기·중고거래·무료 법률 자문·비밀글 등)에 글·댓글·답글·추천을 남길 수 있어요. 글·댓글마다 4자 이상 비밀번호를 정해야 하고, 나중에 고치거나 지울 때 그 비밀번호가 필요해요. 신고와 이미지 파일 올리기는 회원가입 후에 할 수 있어요.

**Q. 법률자문가로 지정받았는데 다른 게시판에 들어가지지 않아요.**
정상이에요. 법률자문가 계정은 수다방에서 `무료 법률 자문` 게시판만 쓸 수 있고, 다른 게시판은 눌러도 안내만 뜨거나 곧바로 `무료 법률 자문` 목록으로 돌아와요. 지정 중에는 새 채팅도 시작할 수 없어요. 자세한 건 [3-11. 법률자문가 계정](#3-11-법률자문가-계정-지정된-분만)을 보세요. 원래대로 돌리려면 운영자에게 해제를 부탁하세요.

**Q. 출석으로 모은 포인트는 어디에 쓰나요?**
**포인트몰**에서 아이템으로 바꿀 수 있어요. 데스크톱은 위쪽 메뉴의 **포인트몰**, 휴대폰은 화면 위쪽 머리줄의 **상점 아이콘**(검색과 알림 종 사이)을 누르면 돼요. 자세한 건 [3-14. 포인트몰](#3-14-포인트몰)을 보세요.

**Q. 포인트몰에서 구매했는데 아이템이 오지 않아요.**
직접 지급·쿠폰 발송 아이템은 운영팀이 하나씩 확인한 뒤 주기 때문에 시간이 걸릴 수 있어요. **내 정보 → 포인트 내역**의 **구매 내역**에서 상태가 `주문완료`인지 `지급완료`인지 보고, 오래 걸리면 포인트몰의 **1:1 상담**이나 고객센터로 물어봐 주세요. 끌어올리기·광고 연장 혜택은 지급을 기다리는 게 아니라 **내 아이템**에 담겨 있으니, 거기서 직접 공고에 써 주세요.

**Q. 잘못 구매했어요. 취소할 수 있나요?**
아직 지급되지 않은 직접 지급·쿠폰 주문은 **구매 내역**의 `주문완료` 항목에서 **취소·환불** 버튼으로 직접 취소할 수 있고, 안 쓴 끌어올리기·광고 연장 혜택은 **내 아이템**에서 취소할 수 있어요. 취소하면 빠졌던 포인트가 바로 돌아와요. 이미 `지급완료`되었거나 `사용 완료`한 주문은 직접 취소할 수 없으니 포인트몰의 **1:1 상담** 또는 고객센터로 부탁해 주세요.

**Q. 포인트몰에서 포인트를 쓰면 수다방 등급이 내려가나요?**
아니요. 포인트몰 구매·환불은 등급 계산에서 빠져서 등급에 영향을 주지 않아요.

**Q. 비밀번호를 잊어버렸어요.**
로그인 화면에서 **비밀번호를 잊으셨나요?**를 누르고 휴대폰 본인인증을 마치면, 그 자리에서 새 비밀번호를 정할 수 있어요. 바꾸면 다른 기기에 남아 있던 로그인이 모두 풀리니 새 비밀번호로 다시 로그인해 주세요.

**Q. 아이디가 기억나지 않아요.**
로그인 화면에서 **아이디 찾기**를 누르고 휴대폰 본인인증을 마치면 가입된 아이디를 바로 알려 드려요. 아이디 없이 이메일로 가입한 계정이라면 "이메일로 가입된 계정이에요"라고 나오니, 가입한 이메일로 로그인하시면 돼요.

**Q. 탈퇴한 뒤에 다시 가입할 수 있나요?**
같은 계정으로는 다시 로그인할 수 없어요. 새로 가입할 수는 있지만, 부정 재가입을 막으려고 본인인증 정보가 남아 있는 보관 기간 동안에는 **같은 명의로 본인인증을 다시 할 수 없어요.**
