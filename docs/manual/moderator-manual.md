## 1. 이 매뉴얼과 운영자 역할

밤비는 아르바이트 구인·구직을 연결하는 플랫폼입니다. 운영자는 이 플랫폼에서 오가는 공고, 후기, 채팅, 커뮤니티 글, 사용자, 업소 정보를 점검해 서비스가 안전하고 신뢰할 수 있게 유지하는 역할을 맡습니다.

운영자가 콘솔에서 주로 하는 일은 다음과 같습니다.

- **공고 검수·관리**: 게시 전 대기 중인 공고를 확인해 게시할지 반려할지 결정하고, 이미 게시된 공고를 내리거나 광고 기간을 조정합니다.
- **사용자 관리**: 문제 사용자에게 경고·이용 정지 등 제재를 적용하고, 사유가 해소되면 정상으로 복구합니다. 무료 법률 자문에 답변할 **법률자문 계정을 지정·해제**하는 것도 여기서 합니다.
- **채팅 관리**: 신고·차단·나감 표시가 붙은 대화방을 확인하고, 필요하면 대화방을 삭제합니다.
- **신고 처리**: 사용자가 접수한 신고(공고·채팅방·채팅 메시지·후기·사용자·커뮤니티 글·커뮤니티 댓글 대상)를 검토하고 조치합니다.
- **업소 승인**: 구인자가 제출한 사업자 정보를 확인해 승인하거나 반려합니다.
- **팀 합류 승인**: 구인자가 팀에 초대한 담당자의 합류를 승인하거나 반려합니다.
- **광고·결제 관리**: 광고 상품과 노출 위치를 관리하고, 무통장입금이 확인된 공고를 결제완료로 전환합니다. **포인트몰**의 판매 아이템을 등록하고, 회원이 포인트로 신청한 주문을 지급하거나 취소·환불하는 것도 여기서 합니다.
- **콘텐츠 관리**: 커뮤니티(수다방) 글·댓글과 고객센터 문의를 숨기거나 삭제하고, 후기 게시 상태를 조정합니다. 수다방에는 로그인하지 않은 **비회원이 쓴 글·댓글**도 섞여 있습니다.
- **게시판 관리**: 수다방 게시판을 새로 만들고, 이름·설명·아이콘·노출 순서를 바꾸고, 글쓰기를 잠그거나 게시판을 감춥니다. 글이 하나도 없는 새 게시판은 삭제할 수도 있습니다.
- **고객센터 운영**: 1:1 문의에 답변하고 FAQ를 등록·관리합니다.
- **금칙어 관리**: 커뮤니티·고객센터 글쓰기에서 차단할 단어를 등록·관리합니다.
- **크롤링 운영**: 외부 사이트 공고·게시글 수집을 켜고 끄며, 수집된 항목의 노출을 관리합니다.
- **사이트 정보 관리**: 푸터 사업자 정보, 무통장입금 계좌, 회원 정책(탈퇴 정보 보존기간·파기 배치 실행 시각), 최저시급 표기 등을 관리합니다.

운영자 계정에는 등급 구분이 없습니다. 콘솔이 열리는 계정이면 위 기능을 모두 사용할 수 있으므로, 조작 권한이 곧 책임이라고 생각하고 다뤄 주세요.

이 매뉴얼은 실제 화면에 보이는 메뉴명·버튼명·한글 라벨만 사용합니다. 화면과 표현이 일치하므로, 안내된 이름 그대로 화면에서 찾으시면 됩니다.

## 2. 운영자 콘솔 접속

### 접속 조건

- 운영자 콘솔은 **운영자 권한이 부여된 계정으로 로그인**해야만 들어갈 수 있습니다.
- 로그인하지 않은 상태로 콘솔 주소에 접근하면 **구직자 화면 위에 로그인 창이 뜬 상태**로 이동됩니다. 여기서 운영자 계정으로 로그인한 뒤 다시 콘솔 주소로 들어오면 됩니다.
- 운영자가 아닌 일반 계정(구직자·구인자)으로 접근하면 각자의 홈 화면으로 자동 이동되며, 콘솔은 열리지 않습니다.

즉, 콘솔 화면이 열린다는 것 자체가 현재 계정이 운영자 권한을 가지고 있다는 뜻입니다.

> 참고: 콘솔 화면은 열리는데 어느 목록도 뜨지 않고 조작할 때마다 오류가 난다면, 본인 운영자 계정이 **이용 정지 상태**일 수 있습니다. 이 경우 화면은 열려도 모든 조작이 거부되므로 다른 운영자에게 계정 복구를 요청하세요.

### 화면 구성과 이동

콘솔에 들어오면 화면 위쪽(또는 모바일에서는 아래쪽 탭)에 메뉴가 보입니다. 넓은 화면(PC)의 상단 메뉴는 다음과 같이 구성됩니다.

- **검수 큐**: 게시 대기 중인 공고 검수
- **공고 관리**: 모든 상태의 공고 조회·숨김·검수 보류 공고 마무리·수정·삭제·광고 기간 조정
- **회원 관리**(묶음 메뉴)
  - **사용자**: 사용자 계정 관리·제재
  - **채팅**: 신고·차단·삭제 표시가 붙은 대화방 관리
  - **신고**: 접수된 신고 처리
  - **업소 승인**: 사업자 정보 심사
  - **팀 합류 승인**: 구인자 팀 초대 승인
  - **출석 관리**: 회원 출석 현황 조회, 포인트 지급·차감
- **광고·결제**(묶음 메뉴)
  - **광고 상품**: 광고 노출 위치·상품·가격 관리
  - **결제 관리**: 유료 공고의 결제 상태 전환
  - **포인트몰**: 포인트 아이템 등록·관리, 회원 주문 지급·취소
- **콘텐츠**(묶음 메뉴)
  - **게시물**: 커뮤니티 글·댓글·고객센터 문의 조치
  - **게시판 관리**: 수다방 게시판 추가·이름·아이콘·순서·노출 관리
  - **고객센터**: 1:1 문의 답변, FAQ 관리
  - **운영자 매뉴얼**: 역할별 사용 설명서 화면 열람
  - **금칙어**: 차단 단어 등록·관리
  - **후기 관리**: 후기 게시·숨김 관리
  - **크롤링**: 외부 공고·게시글 수집 운영
- **사이트 정보**: 푸터 사업자 정보, 무통장입금 계좌, 회원 정책 등 편집

화면 오른쪽 위에는 현재 운영자 모드임을 알리는 **운영자 모드** 표시와 **종 모양** 알림 버튼이 항상 떠 있습니다.

> 참고: 좁은 화면(모바일)에서는 아래쪽 탭에 **검수·신고·사용자·후기·광고 상품** 다섯 개가 표시되고, 나머지 메뉴는 오른쪽 끝 **더보기** 탭을 눌러 열리는 목록에서 이동합니다. 더보기 목록은 공고(공고 관리) / 승인 관리(업소 승인·팀 합류 승인) / 회원(출석 관리) / 광고·결제(광고 상품·결제 관리·포인트몰) / 콘텐츠·고객센터(게시물·게시판 관리·고객센터·운영자 매뉴얼·금칙어·크롤링) / 사이트(사이트 정보) 순서로 묶여 있습니다. 더보기를 다시 누르면(표기가 **닫기**로 바뀝니다) 목록이 닫힙니다.

> 참고: 목록에서 항목을 선택해 둔 상태로 다른 메뉴로 이동하면 선택이 해제됩니다. 일괄 처리는 한 화면 안에서 선택·적용까지 마쳐 주세요.

콘솔 메뉴의 **콘텐츠 → 운영자 매뉴얼**에서 이 매뉴얼을 화면으로 볼 수 있습니다. 운영자 계정은 구직자·구인자 가이드도 함께 열람할 수 있어, 이용자 문의를 처리할 때 해당 역할의 화면 안내를 바로 확인할 수 있습니다.

### 알림

**언제 사용하나요**

새 심사거리가 도착했는지 확인할 때 사용합니다. 콘솔 헤더의 **종 모양 버튼**을 누르면 **알림** 화면으로 이동합니다. 읽지 않은 알림이 있으면 종 위에 숫자 뱃지가 붙고, 9개를 넘으면 **9+**로 표시됩니다.

**도착하는 알림**

| 알림 | 누르면 이동하는 곳 |
| --- | --- |
| 새 공고 검수 요청이 들어왔어요 | 검수 큐 |
| 새 1:1 문의가 접수됐어요 / 문의자가 다시 질문했어요 | 고객센터 관리 |
| 새 신고가 접수됐어요 | 신고 처리 |
| 사업자 인증 심사 요청이 들어왔어요 | 업소 승인 |
| 팀 초대 심사 요청이 들어왔어요 | 팀 합류 승인 |
| 후기 심사 요청이 들어왔어요 | 후기 관리 |

**운영자 알림은 전원이 함께 보는 하나의 알림입니다**

- 운영자 알림은 개인별로 복제되지 않고 **운영자 전체가 공유하는 한 건**입니다. 한 명이 알림을 열어 확인하면 **다른 운영자의 뱃지에서도 함께 사라지고**, 그 알림 아래에 **확인: 확인한 사람 이름**이 표시됩니다.
- 여기서 "확인"은 **내가 이 건을 보았다는 표시일 뿐**이며, 실제 검수·답변·처리는 각 큐 화면에서 따로 해야 합니다. 대상을 처리해도 알림이 자동으로 확인 처리되지는 않고, 반대로 알림을 확인해도 대상이 처리되지는 않습니다.
- 오른쪽 위 **모두 확인**을 누르면 남아 있는 알림이 한 번에 확인 처리됩니다. **다른 운영자의 뱃지에서도 함께 사라지므로**, 아직 아무도 손대지 않은 건이 남아 있을 때는 각 큐 화면의 대기 건수로 실제 잔여 업무를 확인해 주세요.
- 알림이 20개를 넘으면 목록 아래 **더보기** 버튼으로 이어서 봅니다. 알림 화면 위에 **브라우저 알림 허용** 안내가 보이면 허용해 두면 다른 탭을 보고 있을 때도 새 심사거리를 바로 알 수 있습니다.

> 콘솔 헤더의 요약 숫자([3.0](#30-콘솔-요약-현황상단-헤더))가 실제 잔여 업무량의 기준이고, 알림은 "새로 들어왔다"는 신호입니다. 두 숫자는 서로 연동되지 않습니다.

## 3. 화면별 업무 안내

### 3.0 콘솔 요약 현황(상단 헤더)

**언제 보나요**

검수 큐·신고·사용자 등 목록 화면 위쪽에는 항상 **운영자 콘솔** 제목과 함께 현재 처리량을 요약한 숫자 세 개가 표시됩니다. 하루 업무를 시작할 때 밀린 일이 얼마나 있는지 한눈에 파악하는 용도입니다.

- **검수 대기**: 게시를 기다리는 공고 수(검수 큐에 남아 있는 건수)
- **신고 대기**: 아직 처리하지 않은 신고 수
- **경고 사용자**: 현재 경고 상태인 사용자 수

이 숫자는 실제 처리 현황에 따라 자동으로 갱신됩니다. 별도의 조작은 없으며, 각 숫자가 가리키는 화면으로 이동해 실제 처리를 진행하시면 됩니다.

---

### 3.1 검수 큐

**언제 사용하나요**

구인자가 올린 공고 중 **아직 게시되지 않고 검수를 기다리는 공고**를 확인하고, 게시할지 반려할지 결정할 때 사용합니다. 밤비는 예외 없이 모든 신규 공고가 검수를 거치므로, 인증된 업소가 올린 공고도 이곳을 지나갑니다.

**목록에서 보이는 정보**

각 공고 줄에는 업소명, 업종, 지역, 급여, 위험도 배지(위험: 높음/중간/낮음), 자동으로 잡힌 감지 문구, 접수 시각과 공고 번호가 표시됩니다.

목록 위에는 두 개의 선택 상자가 있습니다.

- **상태 필터**: 전체 상태 / 높은 위험 / 중간 위험 / 낮은 위험 중에서 골라 위험도별로 걸러 볼 수 있습니다.
- **정렬**: 회신순(먼저 접수된 공고부터) / 최신순 / 위험도순 중에서 정렬 방식을 바꿀 수 있습니다.

> 위험도는 자동 필터가 잡아낸 **감지 문구가 있는지 없는지**로만 나뉩니다. 감지 문구가 있으면 **중간**, 없으면 **낮음**입니다. 따라서 **높은 위험 필터를 고르면 결과가 비는 것이 정상**입니다. 우선 처리 대상을 추릴 때는 **중간 위험**을 쓰세요.

검수 큐는 한 번에 최근 50건까지만 보여 줍니다. 밀린 건이 많을 때는 회신순으로 오래된 건부터 처리해 큐를 비워 주세요.

**한 건씩 처리하는 절차**

1. 목록에서 검수할 공고 줄을 누릅니다.
2. **공고 검수** 화면이 열리면 제목·업소·지역·급여·접수 시각을 확인합니다.
3. **자동 필터가 감지한 신호** 영역에서 시스템이 표시한 신호(위험 표현 감지, 금칙어 감지, 공고 구성 등)를 확인합니다.
4. **공고 본문**에서 감지된 표현이 색으로 강조되어 있으니, 실제 문맥을 읽어 문제 여부를 판단합니다.
   - 판단 기준 안내가 화면 하단에 표시됩니다: 성적 서비스 암시·강요·외부 연락 유도는 반려, 단순 오해 소지는 승인 후 안내합니다.
5. 공고에 등록된 대표 이미지·상세 이미지도 함께 확인합니다.
6. 문제가 없으면 **승인**을 누릅니다. **승인 사유 작성** 창이 열리며, 사유를 확인하고 **승인하기**를 누르면 공고가 게시됨 상태가 되고 목록에서 사라집니다. 무료 공고는 바로 게시되고, **유료 상품 공고는 입금 확인(결제완료 처리) 후에야 게시**됩니다.
7. 문제가 있으면 **반려**를 누릅니다. **반려 사유 작성** 창에서 사유를 적고 **반려하기**를 누릅니다.
8. 지금 결론을 내기 어려우면 **보류**를 누릅니다. **보류 사유 작성** 창에서 사유를 적고 **보류하기**를 누릅니다. 일괄 처리의 보류와 같은 조치로, 공고가 **검수 보류** 상태로 내려가고 큐에서 빠집니다. 다시 처리하려면 **공고 관리**의 **검수 보류** 탭에서 찾아 승인·반려로 마무리합니다.

> **사유는 선택지에서 고르거나 직접 적을 수 있습니다.** 세 판정(승인·보류·반려) 모두 사유 창이 열리고, 위쪽 선택지를 누르면 아래 입력칸에 그 문구가 채워집니다. 채워진 문구를 그대로 써도 되고, 이 건에 맞게 고쳐 써도 됩니다. **두 글자 이상**이어야 확정 버튼이 눌립니다. 목록 일괄 처리와 같은 방식입니다.
>
> 참고 선택지 — 승인: 운영 검수 기준 충족 / 감지 표현이 오해 소지 수준 / 업소 정보 확인 완료 / 보완 요청 반영 확인 / 기타 승인 사유. 보류: 업소 정보 추가 확인 필요 / 사업자 인증 확인 필요 / 공고 내용 보완 요청 예정 / 내부 논의 필요 / 기타 확인 필요. 반려: 성적 서비스 암시 표현 / 강요·착취 의심 조건 / 외부 연락 유도 / 허위·과장 정보 / 기타 정책 위반.

> 반려하면 공고가 반려 상태가 되고, 구인자 화면에는 **공통 반려 안내 문구**가 반려 사유로 표시됩니다. 어떤 표현이 문제였는지 구체적으로 알려야 하는 건이라면, 고객센터 문의 답변 등 별도 경로로 안내해 주세요. 상세에서 작성한 승인·보류·반려 사유는 처리 기록에 그대로 남습니다.

**여러 건을 한 번에 처리하는 절차(일괄 처리)**

1. 목록에서 각 공고 줄 왼쪽의 선택 칸을 눌러 처리할 공고를 여러 개 선택합니다. **한 번에 최대 50건까지** 처리할 수 있습니다. 선택한 줄은 코럴색 테두리로 표시됩니다.
2. 화면 아래에 나타나는 처리 막대에서 **반려 / 보류 / 승인** 중 하나를 누릅니다. 막대 왼쪽에는 **"검수 공고 N건 선택됨"**과 **선택 해제** 버튼이 있습니다.
   - **승인**: 선택한 공고를 모두 승인합니다. 무료 공고는 바로 게시되고, 유료 상품 공고는 입금 확인 후 게시됩니다.
   - **반려**: 선택한 공고를 모두 반려합니다.
   - **보류**: 선택한 공고를 **검수 보류** 상태로 내려 둡니다. 큐에서는 빠지며, 다시 처리하려면 **공고 관리**의 **검수 보류** 탭에서 찾습니다. 운영자가 직접 내리는 **숨김**과는 다른 상태이며, 구인자 화면에도 "검수 보류"로 표시됩니다.
3. **처리 사유**를 입력하는 창이 뜹니다. 기본 문구가 채워져 있으며, 필요하면 수정합니다. (사유는 두 글자 이상 입력해야 합니다.)
4. **적용**을 누르면 처리됩니다. 처리 후 성공·실패 건수와 실패한 공고 번호가 안내됩니다.

**유료 광고 공고의 결제 처리**

유료 노출 상품을 붙인 공고는 검수 상세 화면 아래에 **결제 패널**이 함께 표시됩니다(일반 구인 공고에는 나타나지 않습니다).

- **결제완료 처리**: 무통장입금이 확인되면 누릅니다. 이때부터 광고 기간이 시작되어 종료일이 새로 계산됩니다.
- **미결제로 되돌리기**: 입금 확인이 잘못됐을 때 사용합니다.

> ⚠ **미결제로 되돌리면 계산돼 있던 광고 종료일이 지워집니다.** 나중에 다시 결제완료 처리하면 광고 기간이 **그 시점부터 새로 시작**되어 원래 종료일이 사라집니다. 되돌리기 전에 종료일을 따로 적어 두세요.
> 배너형 광고는 전체 10자리 정원이 있어, 만석이면 결제완료 처리가 거부되고 안내가 표시됩니다([3.10 결제 관리](#310-결제-관리) 참고).

**처리하면 무슨 일이 일어나나요**

- 승인한 공고는 게시됨 상태가 됩니다. 다만 **유료 공고는 결제완료까지 되어야 실제로 노출**됩니다.
- 반려한 공고는 반려 상태가 되고, 구인자에게 반려 안내가 표시됩니다.
- 보류한 공고는 **검수 보류** 상태가 되어 노출되지 않고 큐에서 빠집니다. 구인자 목록에도 "검수 보류"로 표시되며, 구인자가 그 공고를 수정해 다시 제출하면 **검수 대기**로 돌아와 큐에 다시 올라옵니다.
- 모든 처리는 사유와 함께 기록으로 남습니다(아래 [처리 원칙과 주의사항](#5-처리-원칙과-주의사항) 참고).

### 3.2 공고 관리

**언제 사용하나요**

모든 상태의 공고를 상태 탭·검색으로 찾아 확인하고, 공개된 공고를 강제로 내리거나(숨김) 숨긴 공고를 재공개할 때 사용합니다. 검수에서 **보류**한 공고를 다시 찾아 마무리하는 곳도 여기입니다. 본문·이미지 수정과 삭제, **광고 기간 연장·단축**도 이 화면에서 진행합니다.

**화면 구성**

- 상태 탭: 전체 / 검수 대기 / 검수 보류 / 공개 / 숨김 / 반려
- 검색: 공고 제목·업소명으로 걸러 볼 수 있습니다.
- 표에는 제목·업소·업종·지역·급여·상태·노출 종류·결제 상태·만료(남은 기간)와 처리 메뉴가 표시됩니다.
- **제목 링크는 실제로 공개 중인 공고에만 걸립니다.** 구직자에게 보이는 공고 상세는 검수를 통과(**공개**)하고 결제까지 끝난 공고만 열리기 때문입니다. 그 조건을 못 채운 공고는 제목이 링크가 아닌 글자로 표시되고, 아래에 **"비공개 공고 · 상세 보기 불가"**와 현재 상태(검수 대기 / 검수 보류 / 미공개 / 숨김 / 반려)가 함께 적힙니다. 내용을 확인하려면 처리 메뉴의 **수정**을 여세요 — 수정 화면은 상태와 관계없이 언제나 열립니다.
- **대기열에 든 스페셜·추천 공고**는 **상태** 열에 게시 상태 대신 **스페셜 #N · 추천 #N**(N은 대기 순번)이 표시됩니다. 아래 정원 카드의 대기열 목록과 같은 순번이며, 대기 중이므로 제목도 링크가 아닌 글자로 표시됩니다.

**광고 정원·대기열 현황 카드**

화면 맨 위에는 **광고 정원·대기열 현황** 카드가 있습니다. **프리미엄 · 스페셜 · 추천** 세 자리마다 **사용 N/정원** 배지와 남은 자리·대기 건수가 표시되고, 30초마다 자동으로 갱신됩니다. 자리가 다 차면 배지가 붉게 바뀌고 **만석**으로 표시됩니다.

- 스페셜·추천 자리에 **대기 중인 공고가 있으면** 배지 아래에 대기열 목록이 **#N 제목 · 업소** 형식으로 순번대로 나열됩니다. 대기가 없으면 목록은 표시되지 않습니다.
- 만석인 자리에 유료 공고의 결제가 완료되면 그 공고는 바로 노출되지 않고 이 대기열에 접수되며, 앞선 공고가 만료돼 자리가 나면 순번대로 자동 노출됩니다.

각 줄 오른쪽 끝의 점 세 개 버튼을 누르면 상태에 맞는 처리 메뉴가 열립니다.

- 공개 공고: 숨김 / 광고 연장 / 광고 단축 / 수정 / 삭제
- 숨김 공고: 재공개 / 광고 연장 / 광고 단축 / 수정 / 삭제
- **검수 보류 공고: 승인 / 반려** / 광고 연장 / 광고 단축 / 수정 / 삭제
- 그 밖의 상태(검수 대기·반려): 광고 연장 / 광고 단축 / 수정 / 삭제
- **대기열에 든 스페셜·추천 공고**: 위 메뉴에 더해 **대기열에서 빼기**가 함께 표시됩니다.

**검수 보류 공고 마무리**

검수 큐는 **검수 대기** 공고만 보여 주므로, 보류한 공고는 큐에 다시 나타나지 않습니다. **검수 보류** 탭에서 찾아 처리 메뉴의 **승인** 또는 **반려**를 누르고, 사유를 두 글자 이상 입력해 확정합니다. (승인해도 유료 상품 공고는 입금 확인 전까지 노출되지 않습니다.) (보류 공고에는 "재공개"가 없습니다 — 검수 결론을 건너뛴 채 게시되지 않게 하기 위해서입니다.)

> 이 화면은 한 번에 최근 100건까지 조회합니다. 검색·정렬도 그 100건 안에서 동작하므로, 오래된 공고를 찾을 때는 상태 탭으로 범위를 먼저 좁혀 주세요.

**공개 공고 숨김 / 숨긴 공고 재공개**

1. 처리 메뉴에서 **숨김**(공개 중인 공고) 또는 **재공개**(숨김 상태 공고)를 누릅니다.
2. 창에 **사유**를 두 글자 이상 입력하고 확정합니다. 기본 문구가 미리 채워져 있습니다.
3. 숨긴 공고는 즉시 노출에서 내려가고, 재공개하면 다시 노출됩니다. 재공개 시 이전에 남아 있던 반려 사유는 지워집니다.

**광고 기간 연장·단축**

모든 공고의 메뉴에 **광고 연장**과 **광고 단축**이 함께 표시됩니다.

1. **광고 연장**(또는 **광고 단축**)을 누릅니다.
2. 창에 조정할 **일수**(1~365)를 입력합니다. 입력하는 즉시 현재 종료일과 적용 후 종료일이 함께 표시되므로 결과를 확인한 뒤 진행하세요.
3. **사유**를 두 글자 이상 입력하고 **연장 확정**(또는 **단축 확정**)을 누릅니다.

- 종료일이 없는 공고(미결제이거나 기간 제한이 없는 공고)는 **지금 시각을 기준**으로 계산합니다. 예를 들어 7일 연장하면 오늘부터 7일 뒤가 새 종료일이 됩니다. 즉 **무기한 공고가 기한부 공고로 바뀌므로**, 창에 표시되는 적용 후 종료일을 확인한 뒤 확정하세요.
- 단축한 종료일이 이미 지난 시각이 되면 해당 공고는 곧바로 만료 처리되어 노출에서 내려갑니다. 되돌리려면 같은 방법으로 다시 연장하세요.
- 결제 상태나 광고 종류는 바뀌지 않습니다. 다만 배너형 광고를 만료시키면 **프리미엄 배너 정원의 자리가 즉시 반환**되어 다음 대기 건을 승인할 수 있게 됩니다.
- 조정 내역(이전 종료일·변경 후 종료일·사유)은 기록으로 남습니다.

**대기열에서 빼기**

스페셜·추천 대기열에 든 공고(상태가 **스페셜 #N · 추천 #N**인 공고)의 처리 메뉴에는 **대기열에서 빼기**가 함께 나타납니다.

1. 처리 메뉴에서 **대기열에서 빼기**를 누릅니다. "…공고를 리스팅 대기열에서 뺍니다. 결제가 미결제로 되돌아가고 순번에서 제외돼요."라는 안내가 뜹니다.
2. **사유**를 두 글자 이상 입력하고 **대기열에서 빼기 확정**을 누릅니다.

- 뺀 공고는 대기열에서 사라지고 **결제 상태가 미결제로 되돌아갑니다.** 다시 진행하려면 입금을 확인해 [결제 관리](#310-결제-관리)에서 결제완료 처리하세요(자리가 있으면 바로 노출, 만석이면 대기열 맨 뒤로 다시 접수됩니다).
- 뺀 자리의 **뒤 순번 공고들은 순번이 하나씩 자동으로 당겨집니다.** 정원 카드의 대기열 목록과 상태 열의 **#N**도 함께 갱신됩니다.
- 처리 사유는 감사 로그에 남습니다.

**공고 수정**

처리 메뉴의 **수정**을 누르면 운영자가 직접 공고 내용을 고칠 수 있는 편집 화면이 열립니다.

- 제목·본문·급여·지역·노출 옵션 등을 고칠 수 있고, 저장하면 **검수를 다시 거치지 않고 곧바로 반영**됩니다. **검수 상태·결제 상태·광고 종료일은 수정 전 그대로 유지**됩니다(게시 중인 공고를 고쳐도 내려가지 않고, 검수 대기 공고가 큐에서 사라지지도 않으며, 결제가 끝난 공고가 미결제로 되돌아가지도 않습니다).
- 노출 상품이나 이용 기간을 바꿔도 **결제 상태와 광고 종료일은 그대로**입니다. 구인자 수정과 달리 재결제 대기로 넘어가지 않으니, 금액을 다시 받아야 한다면 [결제 관리](#310-결제-관리)에서 **미결제로 되돌리기**를, 노출 기간만 조정하려면 처리 메뉴의 **광고 연장·단축**을 쓰세요.
- **상세이미지 디자인 제작 옵션은 운영자 편집으로 바뀌지 않습니다.** 편집 화면에 옵션 체크박스가 아예 나오지 않고, 저장해도 신청 여부·옵션 금액·제작 상태가 그대로 유지됩니다(결제 축을 건드리지 않는 편집 모드이기 때문입니다). 제작 상태는 [결제 관리](#310-결제-관리)의 **디자인 제작 관리**에서 바꾸세요.
- **새 이미지를 올릴 수는 없습니다.** 기존 이미지를 지우거나 설명을 고치는 것만 가능하며, 새 파일을 붙인 채 저장하면 "운영자 편집에서는 새 이미지를 올릴 수 없습니다."라는 안내와 함께 저장이 중단됩니다. 이미지 교체가 필요하면 구인자에게 요청하세요.
- 수정 내역은 기록으로 남습니다.

**공고 삭제**

1. 처리 메뉴에서 **삭제**를 누릅니다.
2. 창에 사유를 두 글자 이상 입력하고 **삭제 확정**을 누릅니다.

> ⚠ **공고 삭제는 되돌릴 수 없습니다.** 공고뿐 아니라 **그 공고로 열린 채팅방과 대화 내용, 첨부 이미지, 그 채팅방에서 작성된 후기까지 함께 사라집니다.** 노출만 막으면 되는 경우에는 반드시 **숨김**을 쓰고, 삭제는 중복 등록·테스트 공고처럼 남길 이유가 없는 건에만 사용하세요.

### 3.3 사용자 관리

**언제 사용하나요**

문제가 되는 사용자 계정을 확인하고 **경고·이용 정지 등 제재를 적용**할 때, 그리고 **법률자문 계정을 지정·해제**할 때 사용합니다.

**목록에서 보이는 정보**

각 사용자 줄에는 이름, 이메일, 로그인 아이디, 역할(구직자/구인자/운영자/법률자문), 현재 계정 상태 배지(정상/경고/정지/탈퇴), 누적 신고 건수, 경고 횟수, 가입일이 표시됩니다.

목록 위에서 다음 조건으로 걸러 볼 수 있습니다.

- 상태 탭: 전체 / 정상 / 경고 / 정지 / **탈퇴**
- 검색: 이름·이메일·로그인 아이디
- **역할**, **휴대폰 인증**(인증/미인증), **누적 신고**(1건 이상~10건 이상), **경고 횟수**(1회 이상~5회 이상) 선택 상자

> 아직 가입 절차를 다 마치지 않은 계정도 목록에는 나타납니다. 이런 계정은 제재를 적용할 수 없고 "아직 온보딩을 마치지 않은 계정이라 제재할 수 없어요."라는 안내가 표시됩니다.

**한 명씩 처리하는 절차**

1. 목록에서 사용자 줄을 누르면 **사용자 상세** 화면이 열립니다.
2. 누적 신고·경고 횟수·차단당한 횟수와 함께 계정 정보(이메일·로그인 아이디·소속 업소·탈퇴 시각)를 확인합니다.
3. 필요하면 **신고 내역 보기**를 눌러 이 사용자를 대상으로 접수된 신고만 걸러 볼 수 있습니다.
4. **제재 이력** 영역에서 이 계정에 지금까지 적용된 조치(최신 50건)를 사유·처리자·시각과 함께 확인합니다.
5. **제재 적용** 영역에서 조치를 선택합니다.
   - **경고 보내기**: 정책 안내와 함께 경고를 1회 누적합니다.
   - **이용 정지**: 공고·채팅 이용을 막습니다. **자동 해제 기간은 없으며, 운영자가 정상으로 복구할 때까지 유지됩니다.**
6. 조치를 고르면 **사유 작성 창**이 열립니다. 기본 문구가 미리 채워져 있으며, 상황에 맞게 수정할 수 있습니다. (사유는 두 글자 이상 입력해야 합니다.)
7. 확정하면 조치가 적용되고, 처리 결과가 짧게 안내됩니다. 잘못 눌렀다면 **취소**로 되돌릴 수 있습니다.

**정상으로 되돌리는 절차**

**정상이 아닌 계정(경고·정지 모두)**의 상세 화면에는 제재 적용 영역 위에 **계정 상태 복구** 영역이 표시됩니다.

1. 목록에서 대상 사용자 줄을 눌러 **사용자 상세** 화면을 엽니다.
2. **계정 상태 복구** 영역에서 현재 상태를 확인합니다.
3. 제재 사유가 해소되어 계정을 되돌려도 된다고 판단되면 **정상으로 복구**를 누릅니다.
4. 계정 상태가 정상으로 바뀝니다. **이 버튼은 사유 입력 창 없이 곧바로 적용되니** 누르기 전에 대상 계정이 맞는지 확인하세요.

그동안 쌓인 경고 횟수는 조치 기록을 세는 값이라 복구해도 줄어들지 않습니다. 경고 자체는 별도 해제 절차가 없으며, 사용자가 경고 안내 배너를 직접 닫는 방식입니다.

**법률자문 지정·해제**

수다방 `무료 법률 자문` 게시판의 비밀글을 열람하고 답변할 계정을 지정하는 절차입니다. **사용자 목록**(`/moderator/users`)에서 대상 계정을 선택해 진행합니다.

1. 목록에서 대상 계정 줄 왼쪽의 선택 칸을 체크합니다(역할 선택 상자에서 `구직자`·`법률자문`으로 좁히면 찾기 쉽습니다). **정확히 한 명**을 선택해야 역할 수정 버튼이 나타납니다.
2. 목록 위에 나타난 안내 줄의 버튼을 누릅니다. 대상이 구직자면 **법률자문 지정**, 이미 법률자문이면 **법률자문 해제**가 보입니다.
3. 사유 작성 창에 **지정 사유**를 두 글자 이상 입력하고 확정합니다. 기본 문구가 미리 채워져 있습니다.
4. 적용되면 역할이 바뀌어 목록의 역할 표기가 갱신되고, 창이 닫히며 선택이 풀립니다. 실패하면 창이 그대로 남아 사유를 고쳐 다시 시도할 수 있습니다.
5. 조치는 사유·처리자와 함께 해당 계정 상세 화면의 **제재 이력**에 **법률자문 지정** 또는 **법률자문 해제**로 남습니다.

> **구직자 ↔ 법률자문 사이에서만** 전환할 수 있습니다. 업소(구인자)·운영자 계정은 소속 업소·공고·권한이 얽혀 있어 전환할 수 없으며, 이런 계정이나 **탈퇴한 계정**을 선택하면 역할 수정 버튼 자체가 나타나지 않습니다. 두 명 이상을 선택했을 때도 마찬가지입니다(대신 일괄 제재 막대가 뜹니다).
>
> 아직 가입 절차를 마치지 않은 계정은 목록에 구직자로 보여 버튼이 뜨지만, 확정하면 "아직 온보딩을 마치지 않은 계정이라 역할을 지정할 수 없어요."라는 안내와 함께 적용되지 않습니다.

**지정하면 그 계정은 어떻게 되나요**

- `무료 법률 자문` 게시판의 잠긴 글을 **비밀번호 없이** 열람하고 답변할 수 있으며, 글쓴이가 남긴 연락처도 볼 수 있습니다.
- 수다방 입장 자체는 성별·광고 자격을 따지지 않고 열립니다(운영자 계정과 같습니다). 남성 계정에 지정해도 답변을 남길 수 있습니다.
- 대신 수다방의 **다른 게시판은 읽기·쓰기가 모두 막힙니다.** `무료 법률 자문`만 이용하게 되며, 여성 회원이라도 예외가 없습니다.
- **운영자 콘솔 권한은 전혀 생기지 않습니다.** 그 밖의 권한은 구직자와 같지만, 지정 중에는 공고에 채팅을 새로 걸 수 없고 채팅방·채팅 메시지 신고도 할 수 없습니다(지정 전에 만들어진 대화방은 그대로 남아 이어서 대화할 수 있습니다).
- 당사자 화면에서는 역할이 `법률자문가`로 표시됩니다. 자세한 이용 범위는 구직자 사용 설명서의 **법률자문가 계정** 절에 정리되어 있으니, 문의가 오면 그 절을 안내하세요.
- 해제하면 곧바로 구직자로 돌아가 열람 권한이 사라지고 나머지 기능도 복구됩니다. 지정 기간에 쓴 글과 답변 댓글은 그대로 남습니다.

**여러 명을 한 번에 처리하는 절차(일괄 처리)**

1. 목록에서 사용자 줄 왼쪽의 선택 칸으로 여러 명을 선택합니다. **한 번에 최대 50명까지** 처리할 수 있습니다.
2. 화면 아래 처리 막대에서 **경고** 또는 **정지**를 누릅니다.
3. **처리 사유**를 두 글자 이상 입력하고 **적용**을 누릅니다. 처리 후 성공·실패 건수와 실패한 계정 번호가 안내됩니다.
   - 가입 절차를 마치지 않은 계정이 섞여 있으면 그 건만 실패로 집계되고 나머지는 정상 적용됩니다.

**처리하면 무슨 일이 일어나나요**

- 경고를 보내면 사용자가 경고 상태가 되고 경고 횟수가 1 올라갑니다.
- 이용 정지를 적용하면 해당 계정은 공고 등록·지원·채팅 등 서비스 조작이 모두 막힙니다.
- 모든 제재는 사유와 함께 기록으로 남습니다.

### 3.4 채팅 관리

**언제 사용하나요**

문제가 생긴 대화방의 내용을 직접 확인하고, 필요하면 대화방을 삭제할 때 사용합니다.

**목록에 올라오는 대화방**

이 화면에는 **표시가 붙은 대화방만** 나타납니다. 아무 문제 없이 오가는 대화방은 목록에 뜨지 않습니다.

- **신고됨**: 대화방 또는 그 안의 메시지가 신고된 방
- **차단됨**: 운영자가 차단한 방
- **삭제됨**: 구직자 또는 구인자 한쪽이 방을 나간 경우

한 방에 여러 표시가 동시에 붙을 수 있습니다. 표에는 공고 제목, 구인자, 구직자, 상태, 최근 메시지 시각이 표시됩니다.

**채팅 내역 확인**

1. 줄 오른쪽의 처리 메뉴에서 **채팅 내역**을 누릅니다.
2. 창에 전체 대화가 시간순으로 표시됩니다. 발신자 배지와 시각이 함께 보이며, 연락처 요청 메시지에는 **연락처 요청** 배지가 붙습니다. 첨부 파일은 파일명만 표시됩니다.

처리 메뉴에서 **구직자 상세**·**구인자 상세**를 누르면 해당 계정의 사용자 상세 화면으로 바로 이동해 제재를 이어서 적용할 수 있습니다.

**대화방 차단 · 차단 해제**

1. 처리 메뉴에서 **차단**(이미 차단된 방이면 **차단 해제**)을 누릅니다.
2. 창에 사유를 두 글자 이상 입력하고 **차단 확정**(또는 **차단 해제**)을 누릅니다.

차단하면 양쪽 모두 새 메시지를 보낼 수 없고, 목록의 상태에 **차단됨** 배지가 붙습니다. 차단을 풀면 다시 대화할 수 있습니다. 같은 조치를 [3.5 신고 처리](#35-신고-처리)의 신고 검토 화면에서도 할 수 있습니다.

> **사용자끼리 건 개인 차단은 운영자가 풀지 않습니다.** 운영자가 다루는 것은 대화방 차단뿐이며, 구직자·구인자가 상대를 개인 차단한 기록은 본인만 해제할 수 있습니다.

**대화방 삭제**

1. 처리 메뉴에서 **삭제**를 누릅니다.
2. 창에 사유를 두 글자 이상 입력하고 **삭제 확정**을 누릅니다.

> ⚠ **대화방 삭제는 되돌릴 수 없습니다.** 메시지·첨부만 사라지는 것이 아니라, **그 대화방을 통해 작성된 후기, 사용자 간 차단 기록, 관련 알림까지 함께 사라집니다.** 후기 관련 신고를 함께 처리 중이라면 후기 쪽을 먼저 마무리하고 삭제하세요. 대화만 멈추면 되는 경우에는 삭제 대신 **차단**을 사용하세요.

### 3.5 신고 처리

**언제 사용하나요**

사용자가 접수한 신고를 검토하고 조치할 때 사용합니다. 신고 대상은 공고, 채팅방, 채팅 메시지, 후기, 사용자, 커뮤니티 글, 커뮤니티 댓글입니다.

**목록에서 보이는 정보**

- 아직 처리하지 않은 신고가 위쪽에, 이미 처리한 신고는 아래 **처리 완료** 구역에 흐리게 표시되며 **완료** 표시가 붙습니다.
- 각 줄에는 중요도 표시(심각/주의/참고), 신고 사유, 접수 시각, 신고 대상과 신고자, 신고 내용 요약이 보입니다.
- 신고자는 표시명(없으면 이메일)과 역할(구직자/구인자/운영자/법률자문)로, 피신고 대상은 유형에 맞는 이름과 역할로 표시됩니다. 사용자 대상은 표시명과 역할, 공고는 공고 제목과 "공고", 채팅방은 연결된 공고 제목과 "채팅방"으로 보입니다. 후기·채팅 메시지처럼 이름을 특정하기 어려운 대상은 대상 번호를 축약(예: `#a1b2c3d4`)해 표기하고 역할 자리에 유형(후기·채팅 메시지 등)을 표시합니다.
- **사용자 상세**에서 **신고 내역 보기**로 들어오면 "특정 사용자 대상 신고만 보는 중" 배지가 뜹니다. **필터 해제**를 누르면 전체 목록으로 돌아옵니다.

> 중요도는 사유와 처리 여부로 자동 계산됩니다. 미처리 상태에서 사유가 불법·금지 콘텐츠 / 강요·안전 위협 / 미성년 의심이면 **심각**, 그 밖의 미처리 신고는 **주의**, 처리 완료된 신고는 **참고**로 표시됩니다. 심각 표시부터 처리하세요.
> 이 화면은 한 번에 최근 50건까지 조회합니다.

**처리 절차**

1. 목록에서 신고 줄을 누르면 **신고 검토** 화면이 열립니다.
2. 상단의 두 상자에서 피신고 대상과 신고자를 확인합니다. 각 상자에는 이름(실명·표시명, 없으면 이메일이나 대상 번호 축약)과 역할이 함께 표시됩니다.
3. 신고 대상 유형에 맞춰 아래 정보를 확인합니다(유형별 안내는 다음 항목 참고).
4. 판단이 서면 아래 조치 중 하나를 선택합니다.
   - **기각**: 정책 위반으로 보기 어려운 경우 신고를 종료합니다.
   - **제재 적용**: 사용자가 대상인 신고에서 조치가 필요할 때 누릅니다. **제재 수단 선택** 창에서 경고 보내기 / 이용 정지 중 하나를 고르면, 이어서 **사유 작성 창**이 열립니다. 기본 문구가 미리 채워져 있으니 상황에 맞게 수정한 뒤(두 글자 이상) 확정합니다. 제재를 적용하면 **해당 신고도 함께 조치 완료로 마감**됩니다. (사유 작성 창에서 **취소**를 누르면 제재 수단 선택으로 돌아갑니다.)
   - **조치 완료**: 사용자가 아닌 대상(공고·후기·채팅 등) 신고는 사용자 제재 대신 **조치 완료**로 마무리합니다. 해당 대상의 사용자 제재가 필요하면 **사용자 관리** 화면에서 진행합니다.
5. 이미 처리된 신고를 열면 처리 완료 안내가 표시되고, 별도 조치 버튼은 나타나지 않습니다.

**신고 대상 유형별로 확인·조치할 수 있는 것**

- **공고 신고**: 신고된 공고의 제목, 업소명, 현재 상태, 공고 본문 일부, (반려된 공고라면) 반려 사유를 확인할 수 있습니다. 공고를 내리려면 **공고 관리**에서 숨김 처리합니다.
- **후기 신고**: 신고된 후기의 별점, 현재 상태, 본문을 확인할 수 있습니다. 후기를 내리려면 **후기 관리**에서 숨김 처리합니다.
- **사용자 신고**: 신고된 사용자의 표시명, 역할, 계정 상태, 전화 인증 여부(인증 완료/미인증)를 확인할 수 있습니다.
- **채팅방 신고**: 신고된 대화방의 연결 공고 제목과 현재 상태(정상/차단됨)를 확인하고, **최근 메시지**를 열람할 수 있습니다. 아래에서 사유를 두 글자 이상 입력한 뒤 **방 차단**(또는 이미 차단된 방이면 **차단 해제**)을 눌러 대화방을 차단하거나 해제할 수 있습니다. **대화방 차단·해제는 이 화면에서만 가능합니다.**
- **채팅 메시지 신고**: 신고된 메시지 내용과 첨부 정보를 대화 형태로 확인할 수 있습니다.
- **커뮤니티 글·댓글 신고**: 신고된 글·댓글의 게시판, 현재 상태, 본문 미리보기, 작성자를 확인할 수 있습니다. 잠긴 글(비밀글)이라도 이 화면에서는 본문 미리보기가 그대로 보입니다. **조치 사유**를 두 글자 이상 입력하면 아래 버튼이 활성화되며, 현재 상태에 따라 **숨기기 / 삭제 / 복구**를 적용할 수 있습니다. 삭제를 고르면 한 번 더 확인 창이 뜹니다.
  - 콘텐츠 조치와 신고 처리는 별개입니다. 글을 숨겼다고 신고가 자동으로 마감되지는 않으므로, 조치 후 **조치 완료**를 눌러 신고도 마무리하세요.
  - **비회원이 쓴 글·댓글이면 제재할 계정이 없습니다.** 콘텐츠 조치로 정리하고 **조치 완료**로 마감하세요. 또한 댓글의 작성자 표기는 회원 계정 이름 기준이라 **비회원 댓글은 "회원"으로만** 보입니다. 실제 작성자를 확인하려면 수다방에서 해당 글 상세를 열어 대조하세요.

**여러 건을 한 번에 처리하는 절차(일괄 처리)**

1. 목록에서 선택 칸으로 여러 건을 선택합니다. **한 번에 최대 50건까지** 처리할 수 있습니다.
2. 화면 아래 처리 막대에서 **기각** 또는 **해결**을 누릅니다.
3. **처리 사유**를 두 글자 이상 입력하고 **적용**을 누릅니다. 처리 후 성공·실패 건수가 안내됩니다.

**처리하면 무슨 일이 일어나나요**

- 기각·조치 완료한 신고는 처리 완료 구역으로 내려갑니다.
- 채팅방을 차단하면 해당 대화방이 차단됨 상태가 되고, 차단 해제 시 정상으로 돌아옵니다.
- 모든 조치는 사유와 함께 기록으로 남습니다.

### 3.6 업소 승인

**언제 사용하나요**

구인자가 제출한 **사업자 정보를 심사**할 때 사용합니다. 승인된 업소만 공고를 등록하고 조직·팀 설정을 변경할 수 있으므로, 제출된 정보를 확인해 승인 또는 반려합니다.

**화면 구성**

- 위쪽 탭으로 상태별로 걸러 볼 수 있습니다: 전체 / 대기 / 승인 / 반려 / 미제출. (처음 들어오면 **대기** 상태가 선택되어 있습니다.)
- 각 업소 카드에는 업소명, 현재 인증 상태 배지(미제출/승인 대기/승인 완료/반려), 담당자 이메일과 사업자등록번호, 대표자와 개업일자, 국세청 확인 결과, (반려된 적이 있으면) 반려 사유가 표시됩니다.
- **국세청 확인**은 구인자가 정보를 제출할 때 국세청에 조회한 결과입니다.
  - **국세청 확인 완료** — 사업자등록번호·대표자·개업일자가 국세청 등록 정보와 일치했다는 뜻이며, 옆에 사업자 상태와 확인한 시각이 함께 표시됩니다.
  - **국세청 미확인** — 조회를 하지 못한 채 접수된 제출입니다. 정보가 틀렸다는 뜻은 아니지만 대조가 안 된 상태이므로, **사업자등록증을 수동으로 확인**한 뒤 승인 여부를 정해 주세요.
  - 국세청 진위확인은 현재 준비 중이며, 서비스키가 설정되기 전까지는 **모든 제출이 국세청 미확인으로 접수**됩니다. 이 기간에는 예외 없이 사업자등록증 수동 대조가 필수입니다.
- 서류 카드의 휴지통 버튼으로 부적절한 서류(무관한 파일, 과도한 개인정보 노출본 등)를 삭제할 수 있습니다. 삭제해도 업소 인증 상태는 바뀌지 않으므로, 판정이 필요하면 반려를 사용하세요. 서류 열람·다운로드 링크는 로그인한 본인(제출자)과 운영자에게만 동작합니다.

> 이 화면은 한 번에 20건씩 보여 주며, 목록 아래의 **이전 / 다음**으로 페이지를 넘깁니다. 탭을 바꾸면 1페이지로 돌아갑니다. 마지막 페이지에서는 **다음**이 비활성화됩니다.

**처리 절차**

1. **대기** 탭에서 심사할 업소를 확인합니다.
2. 업소명·이메일·사업자등록번호·대표자·개업일자 등 제출 정보와 국세청 확인 결과를 검토합니다. **국세청 미확인**이면 사업자등록증을 직접 대조합니다.
3. 서류에 문제가 없으면 **승인**을 누릅니다. 업소 상태가 승인 완료로 바뀝니다.
4. 서류에 문제가 있으면, 카드 안의 사유 입력란에 반려 사유를 적은 뒤 **반려**를 누릅니다.
   - 반려 사유는 **두 글자 이상** 입력해야 **반려** 버튼이 활성화됩니다.
   - 입력한 반려 사유는 기록으로 남고, 해당 업소 카드에 반려 사유로 표시되어 구인자도 확인합니다.
5. 처리가 끝나면 "처리했어요." 안내가 표시되고 목록이 갱신됩니다. 그 업소 카드에 적어 둔 반려 사유 입력값도 함께 비워집니다.

> ⚠ **승인 버튼은 확인 창 없이 한 번에 적용됩니다.** 게다가 승인·반려한 업소를 다시 **승인 대기**로 되돌리는 방법은 없습니다. 잘못 승인했다면 반려로 처리하는 수밖에 없고, 그러면 반려 사유가 업소 카드에 표시됩니다. 승인은 서류 대조를 마친 뒤 눌러 주세요.

**승인하면 무슨 일이 일어나나요**

승인된 업소의 구인자에게 다음 기능이 열립니다.

| 기능 | 미승인 상태일 때 |
| --- | --- |
| 공고 등록 | "운영자 승인 후 공고를 등록할 수 있습니다." |
| 조직 설정 변경 | "운영자 승인 후 조직 설정을 변경할 수 있습니다." |
| 팀 관리(생성·수정·삭제·멤버) | "운영자 승인 후 팀을 관리할 수 있습니다." |
| 팀 설정 변경 | "운영자 승인 후 팀 설정을 변경할 수 있습니다." |

반려한 업소는 반려 상태가 되며, 구인자가 정보를 다시 제출하면 승인 대기로 돌아옵니다.

### 3.7 팀 합류 승인

**언제 사용하나요**

구인자가 자기 업소의 팀에 담당자를 초대했을 때, 그 합류를 승인하거나 반려할 때 사용합니다. 운영자가 승인해야 초대받은 사람이 실제 팀 구성원이 됩니다.

**화면 구성**

위쪽 탭으로 상태별로 나눠 봅니다: **대기 / 승인 / 반려**. (처음 들어오면 **대기**가 선택되어 있습니다.) 한 번에 20건씩 보여 주며, 목록 아래의 **이전 / 다음**으로 페이지를 넘깁니다. 탭을 바꾸면 1페이지로 돌아갑니다.

각 카드에는 다음이 표시됩니다.

- 업소명과 팀명 (팀을 지정하지 않은 초대는 "조직 전체")
- 현재 상태 배지(승인 대기 / 승인 완료 / 반려)
- 초대 대상의 이름·이메일·부여될 역할, 초대한 사람
- **초대 사유** — 구인자가 초대할 때 적은 사유입니다. 적지 않았으면 "초대 사유가 적혀 있지 않아요."로 표시됩니다.
- 반려된 건에는 반려 사유
- 초대 유효기간이 지난 건에는 **만료됨** 표시

승인·반려 버튼은 **대기** 탭에서만 나타납니다. 승인·반려 탭은 지난 처리 이력을 되짚어 보는 용도입니다.

**처리 절차**

1. 카드의 업소·팀·초대 대상 정보와 **초대 사유**를 확인합니다. 초대 대상 이메일이 그 업소의 실제 담당자가 맞는지가 핵심 확인 사항입니다.
2. 문제가 없으면 **승인**을 누릅니다.
3. 승인할 수 없으면 **반려 사유(반려 시 필수)** 칸에 사유를 적고 **반려**를 누릅니다. 입력한 사유는 초대 기록에 남습니다.

**처리하면 무슨 일이 일어나나요**

- 승인하면 초대 대상 계정이 곧바로 그 업소(및 팀)의 구성원이 됩니다.
- 반려하면 초대가 반려 상태로 마감되고, 구인자가 다시 초대해야 합니다.

**처리되지 않을 때 확인할 것**

| 상황 | 화면에 뜨는 안내 |
| --- | --- |
| 초대 대상이 아직 가입하지 않았거나 구직자로 가입함 | "초대 대상 구인자 계정을 찾을 수 없습니다." |
| 다른 운영자가 이미 처리함 | "이미 처리된 초대입니다." |
| 유효기간이 지남(승인 버튼이 비활성) | "만료된 초대입니다." |

만료된 초대는 승인할 수 없지만 반려로 정리할 수는 있습니다. 초대 대상이 아직 가입 전이라면 구인자에게 "대상자가 구인자로 가입한 뒤 다시 초대해 달라"고 안내하세요.

> ⚠ **승인한 합류를 운영자 화면에서 취소할 방법은 없습니다.** 잘못 승인해 구성원이 된 계정은 해당 업소의 구인자가 자기 팀 관리 화면에서 직접 빼야 합니다. 승인 전에 업소·대상자를 꼭 대조하세요.

### 3.8 출석 관리

**언제 사용하나요**

구직자·구인자 회원의 출석 현황을 확인하고, 필요할 때 **포인트를 지급하거나 차감**할 때 사용합니다. 최근에 활동이 끊긴 회원을 찾거나, 오늘 얼마나 들어왔는지 파악하는 용도로도 씁니다. 출석 자체를 대신 찍거나 지우는 조작은 없습니다(바꿀 수 있는 것은 포인트뿐입니다).

**들어가는 길**

- 데스크톱: 상단 **회원 관리** → **출석 관리**
- 모바일: **더보기** → **회원** → **출석 관리**

**화면 구성**

화면 위쪽에 요약 카드 두 개가 있습니다.

- **오늘 출석자**: 오늘(한국 시간 기준) 출석한 회원 수
- **출석 대상 회원**: 출석 기능을 쓸 수 있는 회원 수(구직자·구인자, 탈퇴 계정 제외)

> 두 숫자는 아래 목록과 **같은 검색·역할 조건**으로 계산됩니다. 조건을 걸면 요약 숫자도 그 범위로 좁혀지므로, 전체 현황을 보려면 검색어를 비우고 역할을 **전체**로 두세요.

그 아래에 조회 조건이 있습니다.

- **검색**: 닉네임 또는 아이디로 찾습니다. 입력을 멈추면 잠시 뒤 자동으로 조회됩니다.
- **역할**: `전체` / `구직자` / `구인자` 중에서 고릅니다. (운영자·법률자문은 출석 대상이 아니라 목록에 나오지 않습니다.)

**목록에서 보는 값**

| 열 | 의미 |
| --- | --- |
| 회원 | 닉네임과 아이디. 오늘 출석했으면 이름 옆에 **오늘 출석** 뱃지가 붙습니다. |
| 역할 | `구직자` / `구인자` |
| 총 출석 | 가입 이후 전체 출석일 수 |
| 이번 달 | 이번 달 1일부터 오늘까지의 출석일 수 |
| 마지막 출석 | 가장 최근 출석 날짜. 한 번도 출석하지 않았으면 **기록 없음** |
| 미출석 | 마지막 출석일로부터 며칠이 지났는지. 출석 기록이 없으면 **-** |
| 포인트 | 현재 포인트 잔액(예: `1,200P`). 출석 적립과 운영자 지급·차감을 모두 더한 값입니다 |
| 관리 | **지급·차감** 버튼 |

**정렬과 더 보기**

- **총 출석 · 이번 달 · 마지막 출석 · 미출석** 열 제목을 누르면 그 기준으로 정렬됩니다. 정렬 방향은 축마다 고정(큰 값·최근 순)이라 같은 제목을 다시 눌러도 방향이 바뀌지 않습니다. 기본 정렬은 **마지막 출석** 최신순입니다.
- 오래 활동이 없는 회원을 찾으려면 **미출석**으로 정렬하세요.
- **포인트 열로는 정렬할 수 없습니다.** 특정 회원의 잔액을 볼 때는 검색으로 찾으세요.
- 한 번에 20명씩 표시되며, 아래 **더 보기** 버튼으로 이어서 봅니다.

**포인트 지급·차감 절차**

이벤트 보상 지급이나 잘못 적립된 포인트 회수처럼, 회원의 포인트를 손으로 조정해야 할 때 씁니다.

1. 대상 회원 줄 오른쪽의 **지급·차감**을 누릅니다. **포인트 지급·차감** 창이 열리고, 위쪽에 "○○○ 회원의 현재 잔액은 1,200P예요. 조정 내역은 사유와 함께 기록됩니다."라고 표시됩니다.
2. **지급 / 차감** 중 하나를 고릅니다. 기본값은 **지급**입니다.
3. **포인트**에 조정할 양을 넣습니다. **항상 양수**로 넣고 방향은 2번 선택이 정합니다(차감에 음수를 넣지 마세요). **1 이상 100,000 이하의 정수**만 받습니다.
4. **사유**를 씁니다(필수, 최대 200자. 예: `이벤트 당첨 보상`). 사유는 포인트 내역에 **운영자 지급: 사유** / **운영자 차감: 사유** 형태로 함께 저장됩니다.
5. 입력이 유효하면 사유 칸 아래에 **조정 후 예상 잔액**이 미리 보입니다. 확인하고 **적용**을 누릅니다.
6. "포인트를 조정했어요. 현재 잔액 1,270P"처럼 조정 후 잔액이 안내되고, 목록의 포인트 열이 갱신됩니다.

조정되지 않는 경우

| 상황 | 안내 |
| --- | --- |
| 차감액이 현재 잔액보다 큼 | "잔액보다 많이 차감할 수 없습니다." |
| 대상 계정이 없거나 탈퇴함 | "대상 회원을 찾을 수 없습니다." |
| 구직자·업소 회원이 아님(운영자·법률자문) | "구직자·업소 회원에게만 포인트를 조정할 수 있습니다." |
| 0 포인트로 조정 시도 | "0 포인트는 조정할 수 없습니다." |

> ⚠ **확인 창 없이 바로 적용되고, 조정을 되돌리는 버튼은 없습니다.** 잘못 넣었다면 반대 방향으로 같은 양을 다시 조정해 바로잡아야 하며, 그 기록도 내역에 남습니다. 잔액을 음수로 만들 수는 없습니다.

> 출석은 회원이 직접 하루 한 번 누르는 기능이며, 1회당 10포인트가 적립됩니다. 출석 **여부·날짜**는 운영자가 바꿀 수 없고, 출석 여부는 어떤 제재·심사 판단의 근거도 아닙니다. 운영자가 손댈 수 있는 것은 **포인트 잔액**뿐입니다.

### 3.9 광고 상품 관리

**언제 사용하나요**

구인자가 공고를 홍보하는 데 쓰는 유료 광고 상품을 관리할 때 사용합니다. 광고가 노출되는 위치와, 그 위치에서 판매하는 상품·가격을 등록·수정하고 켜고 끌 수 있습니다. 공고 단위로 따로 파는 **끌어올리기 옵션**의 판매가·제공량도 이 화면에서 정합니다.

**화면 구성**

- 상단의 **위치 추가**로 새 노출 위치를 만듭니다. 각 위치 카드에는 위치 이름, 유형 배지(배너/리스팅), 노출 켜기/끄기 스위치, 수정·삭제 버튼이 있습니다.
- 그 아래 **끌어올리기 옵션** 카드에서 끌어올리기 옵션 3종의 판매가와 제공량을 설정합니다(바로 아래 참고).
- 위치 카드 안에는 그 위치에서 판매하는 광고 상품이 나열됩니다. 각 상품에는 상품명, 노출 켜기/끄기 스위치, 수정·삭제 버튼과 함께 이용 기간별 가격이 표시됩니다.
- **이 위치에 상품 추가**로 해당 위치에 새 상품을 등록합니다.
- 이 화면에서는 꺼 둔(비활성) 위치·상품도 모두 보입니다. 구인자 화면에는 켜 둔 것만 노출됩니다.
- 위치 카드와 상품 줄에 **위/아래 화살표 버튼**이 있습니다. 누르면 그 항목이 한 칸 올라가거나 내려가고, 바뀐 순서가 곧바로 저장됩니다. 목록 맨 위·맨 아래에서는 해당 방향 버튼이 비활성화됩니다. 이 순서가 구인자 광고 안내·구매 화면에 보이는 순서입니다.

**끌어올리기 옵션 판매 설정**

화면 위쪽 **끌어올리기 옵션** 카드에서 공고 단위로 파는 끌어올리기 옵션 3종의 판매 여부·가격·제공량을 정합니다. 광고 상품에 포함된 일일 끌어올리기와 달리, 이 옵션은 **무료 공고를 포함한 어떤 공고에도 따로 붙일 수 있습니다**(배너 광고 공고 제외).

- **끌어올리기** — 기간제. **판매가(원)**, **하루 끌어올리기 횟수**, **적용 일수**를 입력합니다.
- **끌어올리기 횟수권** — 횟수제. **판매가(원)**와 **충전 횟수**를 입력합니다.
- **자동 끌어올리기** — 기간제. **판매가(원)**, **하루 끌어올리기 횟수**, **적용 일수**를 입력합니다.

1. 값을 입력하고 각 줄의 **저장**을 누릅니다. 저장되면 "옵션을 저장했어요."라고 안내됩니다.
2. **판매가를 비우면 그 옵션은 미판매로 처리되어 구인자 화면에서 아예 숨겨집니다.** 판매를 멈출 때는 이렇게 가격을 비우세요.
3. 판매가를 넣었는데 제공량이 비어 있으면 저장이 거부됩니다 — 기간제는 "판매 중인 기간제 옵션은 하루 끌어올리기 횟수와 기간(일)을 1 이상으로 입력해야 합니다.", 횟수권은 "판매 중인 횟수권 옵션은 끌어올리기 횟수를 1 이상으로 입력해야 합니다."라고 표시됩니다.
4. 가격·제공량을 나중에 바꿔도 **이미 구매한 건에는 소급되지 않습니다.** 구매 시점의 가격과 제공량이 그대로 유지됩니다(광고 상품과 동일한 스냅샷 규칙).

> 구인자 화면에서는 **광고 상품 안내** 화면 아래쪽 안내 블록, **공고 등록·수정** 화면의 끌어올리기 옵션 체크박스, **광고 관리**의 옵션 구매 창에 판매 중인 옵션만 나타납니다. 세 옵션 모두 가격을 비워 두면 안내 블록 자체가 표시되지 않습니다.

**노출 영역(게시 위치) 고르기**

상품 등록/수정 화면의 **노출 영역**은 그 상품을 산 공고가 실제로 뜨는 자리입니다. 고른 값에 따라 바로 아래 안내 문구가 바뀌니 저장 전에 읽어 주세요.

> **선택지는 그 상품이 속한 위치의 유형에 맞는 것만 보입니다.** 위치 유형이 **배너 광고**면 프리미엄 광고(배너)만, **리스팅 노출**이면 스페셜·급구·추천 리스팅만 나옵니다. "노출 영역 없음(일반)"은 양쪽 모두에서 고를 수 있습니다. 다른 영역을 팔고 싶다면 상품이 아니라 **위치**를 그 유형으로 새로 만들어야 합니다.
>
> 예전에 유형과 어긋나게 저장된 상품을 수정할 때는, 현재 값이 선택지에 그대로 남아 값이 지워지지 않습니다. 대신 선택 칸 아래에 **위치 유형과 어긋난다는 경고**가 붉게 표시되니, 저장 전에 맞는 영역으로 바꿔 주세요.
>
> **사이트 설정에서 급구 섹션을 숨기면** 노출 영역 선택지에서 "급구 채용 리스팅"이 사라지고, 구인자 공고 등록/수정의 광고 상품 목록에서도 급구 상품이 빠집니다(이미 급구로 저장된 상품을 수정할 때는 값 유실 방지를 위해 그대로 남습니다). 숨김을 해제하면 즉시 원복됩니다.

- **프리미엄 광고(상단·좌/우 사이드 배너)** — 광고 배너 영역입니다. 구인자가 가로형·세로형 배너 이미지를 모두 등록해야 하고, 프리미엄 정원(10자리)을 차지합니다.
- **스페셜 / 급구 / 추천 채용 리스팅** — 리스팅 노출 영역입니다. 채용 목록 섹션의 카드로 뜨며 **광고 배너 이미지를 쓰지 않습니다.** 대신 끌어올리기(수동·자동) 횟수를 설정할 수 있습니다.
- **노출 영역 없음(일반)** — 일반 구인과 동일하게 취급됩니다.

> **게시 위치 미리보기** 이미지는 구인자 광고 안내 화면에서 "이 상품이 어디에 뜨는지"를 보여 주는 예시일 뿐입니다. 실제 광고 배너 이미지는 구인자가 공고를 등록할 때 올립니다.

**상품 등록·수정과 가격 옵션별 할인율**

상품 등록/수정 화면에서는 상품명·한 줄 소개·노출 영역·서비스 내용과 함께 **가격 옵션(이용기간 · 금액 · 할인율)**을 설정합니다.

1. 가격 옵션마다 이용 기간(일)·금액(원)·**할인율(%)**을 입력합니다. **가격 옵션 추가**로 기간별 옵션을 늘릴 수 있으며, 같은 이용 기간은 중복으로 등록할 수 없습니다. 가격 옵션은 최소 한 개가 필요합니다.
2. 할인율은 **0~100 사이 정수**입니다. 비워 두거나 0이면 할인 없이 원가만 노출됩니다.
3. 할인율을 넣으면 구인자 화면에서 해당 기간 옵션이 **원가 취소선 + 할인가 + "N% 할인"** 형태로 표시됩니다. 할인가는 10원 단위로 내림합니다.
4. 미리보기 이미지는 1.5MB 이하만 등록할 수 있습니다.
5. **상세이미지 디자인 제작 가격**을 입력하면 이 상품을 사는 구인자가 공고 등록 화면에서 디자인 제작 옵션을 함께 신청할 수 있습니다. **비워 두면 이 상품에는 옵션이 노출되지 않습니다.** 가격을 나중에 바꿔도 이미 신청된 공고의 금액에는 소급되지 않습니다(가격·기간 옵션과 동일한 스냅샷 규칙).

**노출 켜기/끄기와 삭제**

- **스위치를 끄면** 구인자 카탈로그에서 그 위치·상품이 사라집니다. 이미 그 상품을 구매한 공고의 노출은 그대로 유지되므로, 판매를 멈출 때는 **삭제보다 스위치 끄기를 먼저** 쓰세요.
- 가격·기간·할인율을 바꿔도 **이미 구매한 공고에는 소급되지 않습니다.** 구매 시점 조건이 그대로 유지됩니다.
- 다만 상품의 **노출 영역**을 리스팅형에서 배너형으로 바꾸면, 그 뒤 구매분부터 프리미엄 배너 정원을 차지하게 됩니다. 노출 영역 변경은 정원 계획과 함께 검토하세요.

> ⚠ **게재 위치를 삭제하면 그 위치의 하위 광고 상품이 전부 함께 삭제되고, 해당 상품을 구매한 공고에서 광고 상품 연결이 끊어집니다.** 상품 단독 삭제도 마찬가지로, 그 상품을 구매한 공고가 **결제 관리 목록에서 사라지고** 구인자의 "내 광고" 목록·끌어올리기 자격에서도 빠집니다(노출 자체는 종료일까지 계속됩니다). 삭제 전 사용 중 여부를 알려주는 경고가 없으므로, 판매 중단은 반드시 **스위치 끄기**로 처리하고 삭제는 한 번도 판매되지 않은 항목에만 사용하세요.

### 3.10 결제 관리

**언제 사용하나요**

유료 광고를 붙인 공고의 **입금 확인 결과를 반영**할 때 사용합니다. 무통장입금이 들어오면 이 화면에서 결제완료로 전환해야 공고가 실제로 노출됩니다. 화면 아래쪽 **끌어올리기 옵션 결제** 섹션에서는 공고에 따로 구매한 끌어올리기 옵션의 입금을 확인합니다.

**화면 구성**

- 위쪽 공고 목록에는 **유료 광고 상품이 붙은 공고**(검수 대기 또는 공개 상태)만 나타납니다. 무료 공고와 임시 저장 공고는 나오지 않습니다.
- 표에는 제목·업체·상태·노출 종류·결제 금액·**디자인 제작**·결제 상태·남은 기간·만료·등록일이 표시됩니다. **결제 금액은 광고 금액과 디자인 제작 옵션 금액을 합한 총액**이며, 옵션이 있으면 금액 아래에 "디자인 +N원"이 함께 표시됩니다. **대기열에 든 스페셜·추천 공고**는 **상태** 열에 **스페셜 #N · 추천 #N**(N은 대기 순번)이 표시됩니다.
- 오른쪽 위 **미결제만 보기** 스위치를 켜면 입금 대기 중인 건만, **디자인 제작 신청건만** 스위치를 켜면 디자인 제작을 신청한 건만 추립니다. 스위치를 바꾸면 선택이 해제됩니다.

> 이 화면은 한 번에 50건까지 조회합니다. 밀리지 않도록 입금 확인 주기를 짧게 가져가 주세요.

**처리 절차**

1. **미결제만 보기**를 켜고 입금 대기 목록을 확인합니다.
2. 실제 입금이 확인된 공고의 왼쪽 선택 칸을 체크합니다(머리글의 선택 칸으로 현재 목록 전체 선택도 가능합니다).
3. 위에 나타나는 "N개 선택됨" 막대에서 **결제완료 처리**를 누릅니다.
4. 처리 결과가 안내됩니다. 실패한 건이 있으면 첫 번째 실패 사유가 함께 표시됩니다.

입금 확인이 잘못됐다면 같은 방식으로 **미결제로 되돌리기**를 누릅니다.

**상세이미지 디자인 제작 처리**

디자인 제작을 신청한 공고는 **디자인 제작** 칸에 **제작 대기** 또는 **제작 완료** 배지가 뜨고, 배지 아래 **디자인 제작 관리** 버튼으로 작업 창을 엽니다. 신청하지 않은 공고는 이 칸이 "-"로 비어 있고 버튼도 나오지 않습니다.

1. **디자인 제작 신청건만** 스위치로 신청 건을 추립니다.
2. 입금이 확인되면 결제완료 처리를 먼저 진행하고, 구인자와 채팅으로 제작 요청 사항을 주고받습니다(앱에는 시안 교환 기능이 없습니다).
3. 완성본이 나오면 **디자인 제작 관리**를 열어 상세 이미지를 등록합니다. 상세 이미지는 **최대 5장**이며, 창에 보이는 이미지 목록이 저장 시 그대로 공고의 상세 이미지가 됩니다 — **목록에서 지운 기존 이미지는 저장과 함께 실제로 삭제됩니다.**
4. **상세 이미지 저장**을 누른 뒤 **제작 완료 처리**를 누르면 배지가 제작 완료로 바뀝니다. 잘못 눌렀다면 같은 창에서 **제작 대기로 되돌리기**를 누릅니다. 창을 그냥 닫으려면 **닫기**를 누릅니다.

> **제작 완료** 상태가 되면 구인자는 그 공고의 디자인 제작 옵션을 해제할 수 없습니다. 취소·환불이 필요하면 결제 상태를 되돌리는 것과 별개로 운영 재량으로 처리하세요(앱에 환불 흐름은 없습니다).
> 구인자가 옵션을 켜거나 끄면 결제 총액이 바뀌므로 그 공고의 결제 상태는 **미결제**로 되돌아갑니다. 총액을 다시 확인한 뒤 결제완료 처리하세요.

**끌어올리기 옵션 결제**

공고 목록 아래 **끌어올리기 옵션 결제** 섹션에서 구인자가 공고에 구매한 끌어올리기 옵션의 입금을 확인합니다. 화면 안내대로 **입금 확인 시 옵션이 바로 활성화**됩니다. (공고 자체의 결제·게시와는 별개입니다 — 무료 공고에 붙은 옵션이 미결제여도 공고는 그대로 게시됩니다.)

- 표에는 **공고 제목 · 업소 · 옵션 · 스펙 · 금액 · 결제수단 · 상태 · 구매일 · 관리**가 표시됩니다. **스펙**은 구매 시점에 고정된 제공량(예: "하루 2회 · 30일", "10회 충전")이며, 설정되지 않았으면 "-"로 나옵니다.
- 오른쪽 위 **미결제만 보기** 스위치로 입금 대기 건만 추립니다. 목록은 최신 구매순으로 한 번에 **50건**까지 조회합니다.

처리 절차

1. **미결제만 보기**를 켜고 입금 대기 목록을 확인합니다.
2. 실제 입금이 확인된 줄의 **입금 확인**을 누릅니다. "입금을 확인했어요."라고 안내되며, 그 순간 옵션이 활성화됩니다 — 기간제는 **처리한 시점부터 설정된 일수만큼** 사용 기간이 시작되고, 횟수권은 **충전 횟수만큼 잔여가 채워집니다.**
3. 구인자가 입금하지 않았거나 잘못 신청한 건은 **취소**를 눌러 구매 자체를 지웁니다. **입금 확인이 끝난 건은 취소할 수 없습니다**("입금 확인된 구매는 취소할 수 없습니다.").
4. 잘못 확인한 건은 **미결제로**를 눌러 되돌립니다. 활성화 시각·만료일·남은 횟수가 모두 지워집니다.

> ⚠ **미결제로 되돌리면 기간·잔여 횟수가 초기화됩니다.** 다시 입금 확인하면 그 시점부터 기간이 새로 시작되므로, 기간제 옵션은 되돌린 뒤 다시 확인할 때 사용 기간이 늘어납니다.
> **이미 한 번이라도 사용된 횟수권은 미결제로 되돌릴 수 없습니다**("이미 사용된 횟수권 구매는 미결제로 되돌릴 수 없습니다."). 사용분이 되살아나는 것을 막기 위한 제한이며, 환불이 필요하면 운영 재량으로 처리하세요(앱에 환불 흐름은 없습니다).
> 같은 상태를 다시 눌러도(예: 결제완료 건에 다시 결제완료) 아무 일도 일어나지 않습니다 — 횟수권 잔여가 초기화되지 않도록 같은 상태 재확정은 무시됩니다.

**프리미엄 배너 정원(10자리)**

프리미엄 배너·좌측 배너·우측 배너 광고는 **전체 10자리로 제한**됩니다.

- 화면 위쪽에 **"프리미엄 정원 사용 N / 10"** 배지와 남은 자리·결제 대기 건수가 표시됩니다. 자리가 없으면 배지가 빨갛게 바뀌고 "정원이 찼어요" 안내가 함께 뜹니다. 결제완료 처리 후에는 배지가 자동으로 갱신됩니다.
- 이미 10자리가 모두 노출 중이면 결제완료 처리가 거부되고 "프리미엄 광고 정원이 가득 차 승인할 수 없다"는 안내가 표시됩니다.
- 배너 여러 건을 한 번에 결제완료 처리하면 **정원 안에 드는 건만 성공**하고 나머지는 실패로 집계됩니다. 실패한 건은 앞선 광고가 만료돼 자리가 난 뒤 다시 처리하세요.
- 남은 자리보다 많은 배너 건을 선택하지 않도록, 배지의 남은 자리 수를 먼저 확인하고 **입금이 도착한 순서대로** 처리하세요.

> ⚠ **이미 결제완료인 공고를 다시 결제완료 처리하면 광고 종료일이 오늘 기준으로 다시 계산되어 기간이 늘어납니다.** 선택 칸을 체크할 때 결제 상태 열을 함께 확인하고, 되도록 **미결제만 보기**를 켠 상태에서 처리하세요.
> ⚠ **미결제로 되돌리면 광고 종료일이 지워집니다.** 다시 결제완료 처리하면 기간이 그 시점부터 새로 시작되어 원래 종료일이 사라집니다.

**한 번에 처리할 수 있는 건수**

일괄 처리는 한 번에 최대 50건입니다. 목록도 50건까지 로드되므로, 머리글 전체 선택을 쓰면 한계에 딱 맞습니다.

### 3.11 게시물 조치

**언제 사용하나요**

커뮤니티 글·댓글과 고객센터 문의를 **숨기거나 삭제·복구**할 때 사용합니다. 신고를 통하지 않고 직접 발견한 게시물을 조치하거나, 이미 숨김·삭제한 항목을 되살릴 때 이 화면을 씁니다. 게시판을 없애기 위해 커뮤니티 글을 **영구 삭제**해야 할 때도 이 화면에서 처리합니다.

**화면 구성**

- 탭 세 개로 대상을 고릅니다: **커뮤니티 글 / 커뮤니티 댓글 / 고객센터 문의**
- **커뮤니티 글** 탭에는 탭 아래에 **게시판** 선택 상자가 있습니다(기본값 **전체**). 고른 게시판의 글만 목록에 나옵니다. 댓글·문의 탭에는 게시판이라는 축이 없어 이 선택 상자가 나오지 않습니다.
- 표에는 내용(제목과 발췌), 작성자, 상태(게시중/숨김/삭제됨), 등록일이 표시됩니다. **커뮤니티 글** 탭에는 **게시판** 열이 하나 더 붙습니다.
- 줄 왼쪽에는 **선택 칸**이 있습니다(세 탭 모두). 여러 건을 골라 한 번에 처리할 때 씁니다 — 아래 "여러 건을 한 번에 처리하기"를 보세요.
- 목록의 제목·발췌는 짧게 잘려 보입니다. 줄 왼쪽의 화살표를 누르면 **전체 본문**이 펼쳐집니다.
- 한 페이지에 20건씩 표시되며, 아래 **이전 / 다음**으로 이동합니다.

> 상태로 걸러 보는 기능은 없습니다. 숨김·삭제한 항목을 다시 찾으려면 페이지를 넘겨 가며 찾아야 하므로, 조치할 때 **어떤 항목을 어느 페이지에서 처리했는지** 메모해 두면 복구가 수월합니다.
> 작성자 열 표시에 주의하세요. 커뮤니티 댓글 탭의 작성자는 **원글 작성자**로 표시되므로, 댓글 작성자를 제재하려면 본문을 펼쳐 확인한 뒤 커뮤니티 화면에서 대조하세요.
> 수집한 커뮤니티 글에 달린 댓글은 우리 원글이 없어 내용 열에 **수집 커뮤니티 글**, 작성자 열에 **밤문화이야기**로 표시됩니다. 숨김·삭제 조치는 다른 댓글과 똑같이 됩니다.

**처리 절차**

1. 탭에서 대상 유형을 고릅니다.
2. 화살표를 눌러 본문을 펼쳐 실제 내용을 확인합니다.
3. 줄 오른쪽의 점 세 개 버튼을 눌러 조치를 고릅니다. 현재 상태와 같은 항목은 메뉴에 나오지 않습니다.
   - **숨김**: 사용자 화면에서 보이지 않게 합니다.
   - **삭제**: 게시물을 삭제 처리합니다.
   - **복구**: 숨김·삭제한 항목을 다시 게시 상태로 되돌립니다.
4. 창에 **조치 사유**를 두 글자 이상 입력하고 **확인**을 누릅니다.

**커뮤니티 글 영구 삭제하기(되돌릴 수 없음)**

위의 **삭제**는 기록을 남기는 삭제라 글이 데이터베이스에 그대로 남습니다. 그래서 게시판의 글을 전부 삭제해도 [3.12 게시판 관리](#312-게시판-관리)에서 그 게시판을 지울 수 없습니다("글이 있는 게시판은 삭제할 수 없습니다."). 게시판을 정말 없애야 할 때만 쓰는 **마지막 단계**가 영구 삭제입니다.

1. **커뮤니티 글** 탭에서 게시판 선택 상자로 정리할 게시판을 고릅니다.
2. 남은 글을 먼저 **삭제**(위의 절차 또는 선택 삭제)해 상태를 **삭제됨**으로 만듭니다.
3. 상태가 **삭제됨**인 줄의 점 세 개 버튼을 누르면 메뉴 맨 아래에 **영구 삭제하기**가 보입니다(게시중·숨김 상태에는 나오지 않습니다).
4. 확인 창의 경고("되돌릴 수 없습니다…")를 읽고 **영구 삭제하기**를 누릅니다. "영구 삭제했어요."라고 안내되고 줄이 목록에서 사라집니다.
5. 그 게시판의 글이 0건이 되면 [3.12 게시판 관리](#312-게시판-관리)에서 게시판 **삭제**가 성공합니다.

> 글이 여러 건이면 3~4를 반복하지 말고 **선택 영구 삭제**를 쓰세요(아래 "여러 건을 한 번에 처리하기"). 머리글 선택 칸으로 페이지 전체를 고르면 한 페이지(20건)를 두 번에 비울 수 있습니다 — **선택 삭제**로 게시중·숨김 글을 삭제됨으로 만들고, 이어서 **선택 영구 삭제**를 누릅니다.

> ⚠ **영구 삭제는 복구 창구가 없습니다.** 글과 그 글에 달린 **댓글·추천이 함께 사라지고**, 사용자·운영자 어느 화면에서도 되살릴 수 없습니다. 사유는 따로 묻지 않습니다 — 앞 단계의 **삭제** 조치에 남긴 사유가 기록이며, 영구 삭제 자체도 제목·게시판·작성 표시명을 기록으로 남깁니다.
> 조치 순서를 지켜 주세요. **삭제 처리하지 않은 글**에 영구 삭제를 시도하면 "삭제 처리한 글만 영구 삭제할 수 있습니다. 먼저 삭제 조치를 해 주세요."로 거절됩니다.
> 영구 삭제는 **커뮤니티 글에만** 있습니다. 댓글·문의에는 영구 삭제가 없습니다(글을 영구 삭제하면 그 글의 댓글은 함께 사라집니다).

**여러 건을 한 번에 처리하기**

선택 칸은 **세 탭(글·댓글·문의) 모두** 있고, **상태와 무관하게** 어떤 줄이든 고를 수 있습니다(삭제됨인 글도 골라야 영구 삭제를 할 수 있기 때문입니다).

1. 처리할 줄의 선택 칸을 체크합니다. 머리글의 선택 칸으로 **현재 페이지 전체**를 선택할 수도 있습니다.
2. 표 위에 "N개 선택됨" 막대가 나타납니다. 막대의 버튼에는 **실제 대상 건수가 괄호로** 적혀 있습니다.
   - **선택 삭제 (N)**: 고른 것 중 **아직 삭제되지 않은** 항목만 삭제합니다(삭제됨인 줄은 세지 않습니다). 대상이 0건이면 버튼이 눌리지 않습니다. 세 탭 모두에서 쓸 수 있습니다.
   - **선택 영구 삭제 (N)**: 고른 것 중 **이미 삭제됨 상태인 커뮤니티 글**만 지웁니다. **커뮤니티 글 탭에서만** 보이고, 대상이 0건이면 눌리지 않습니다.
3. **선택 삭제**는 창에 **조치 사유**를 두 글자 이상 입력하고 **확인**을 누릅니다. 사유는 선택한 모든 항목에 같이 기록됩니다.
   **선택 영구 삭제**는 사유를 묻지 않고 확인 창("선택한 N건을 영구 삭제할까요?" / "되돌릴 수 없습니다…")만 거칩니다.
4. 처리 결과가 한 번에 안내됩니다("N건 조치했어요." / "N건 영구 삭제했어요."). 실패한 건이 있으면 성공·실패 건수가 함께 표시됩니다.

선택 삭제도 기록을 남기는 삭제라 한 건씩 **복구**할 수 있지만, **선택 영구 삭제는 되돌릴 수 없습니다**. 탭·페이지·게시판 필터를 옮기면 선택이 해제됩니다.

**수다방 글·댓글을 다룰 때 알아 둘 것**

- **로그인하지 않은 비회원이 쓴 글·댓글도 이 목록에 함께 나옵니다.** 비회원은 본인인증(성인·여성)만 거치고 `자유수다`·`밤문화 이야기`·`무료 법률 자문` 세 게시판에만 참여할 수 있습니다.
- 비회원에게는 계정이 없어 **사용자 관리에서 제재할 대상이 없습니다.** 문제 글은 이 화면의 숨김·삭제로 정리하고, 반복되는 표현은 [3.14 금칙어 관리](#314-금칙어-관리)에 등록해 재발을 막으세요.
- **작성자 열만 보고 회원·비회원을 구분할 수 없습니다.** 커뮤니티 글의 작성자는 글마다 직접 적어 넣는 표시명이고(비회원의 기본값은 `비회원`이지만 바꿔 쓸 수 있습니다), 커뮤니티 댓글 탭의 작성자는 위에 적은 대로 **원글 작성자**입니다. 작성자 유형을 확인해야 하면 수다방에서 해당 글 상세를 열어 대조하세요(수다방 화면에서는 비회원 댓글이 항상 `비회원`으로 표시됩니다).
- 비회원 글·댓글도 회원과 똑같이 금칙어 검사를 거치고, 글의 표시명에는 회원과 같은 이름 규칙이 적용됩니다. 도배 제한은 **글이 회원·비회원 모두 1분에 1건**이고, **댓글은 비회원만 1분에 5건**으로 묶여 있습니다(회원 댓글에는 제한이 없습니다).
- **커뮤니티 글 탭에서는 게시판 열과 게시판 필터로 특정 게시판 글만 모아 볼 수 있습니다.** 줄을 펼치면 본문 위에 게시판 이름 배지도 그대로 보입니다. 댓글·문의 탭에는 게시판 축이 없어 열도 필터도 나오지 않으므로, 특정 게시판의 댓글을 점검하려면 수다방에서 해당 글을 열어 대조하세요(신고를 통해 들어온 건은 신고 검토 화면에 게시판 배지가 표시됩니다).
- 배지에 보이는 게시판 이름은 [3.12 게시판 관리](#312-게시판-관리)에서 정한 이름을 따라갑니다. 운영자가 만든 게시판의 글도 같은 목록에 섞여 나오며, 조치 방법은 기본 게시판과 같습니다.
- **`무료 법률 자문` 게시판 글은 예외 없이 비밀글입니다.** 그래도 이 화면과 신고 검토 화면에서는 잠금과 관계없이 본문을 펼쳐 확인할 수 있고, 수다방 화면에서도 **운영자는 게시판을 가리지 않고 비밀글을 비밀번호 없이 열람**합니다(법률 자문 글에 적힌 연락처도 보입니다). 상담 글에는 민감한 개인 사정이 담기므로 조치에 필요한 범위에서만 열람하세요.
- 수다방 화면에서 운영자가 남의 글·댓글을 직접 삭제할 수도 있습니다. 그 삭제도 이 화면의 삭제와 같은 상태라 여기서 **복구**할 수 있습니다. 다만 사유가 남지 않으므로, 기록이 필요한 조치는 이 화면에서 처리하세요.
- `공지사항` 게시판에 글을 쓸 수 있는 것은 운영자 계정뿐입니다. 작성은 콘솔이 아니라 수다방 글쓰기 화면에서 합니다.

**처리하면 무슨 일이 일어나나요**

- 사용자 화면에는 **게시중** 상태만 노출됩니다. 숨김·삭제는 즉시 비노출되고, 복구하면 다시 보입니다.
- 이 화면의 **삭제**는 **기록을 남기는 삭제**라 언제든 복구할 수 있습니다. 데이터가 물리적으로 사라지지 않습니다. 데이터까지 지우는 것은 **영구 삭제하기**뿐이며, 그것만 복구되지 않습니다.
- 조치 사유는 기록으로 남습니다.

> 고객센터 문의를 **삭제** 처리하면 [3.13 고객센터 관리](#313-고객센터-관리)의 문의 목록에서 사라지고 그 화면에서는 열 수도 없습니다. 되돌리려면 이 화면에서 해당 문의를 찾아 **복구**해야 합니다.
> 문의에는 **진행 상태**(접수됨/답변완료/종료)와 이 화면의 **조치 상태**(게시중/숨김/삭제됨)가 따로 있습니다. 답변을 마친 문의도 조치 상태는 게시중일 수 있고, 그 반대도 가능합니다.

### 3.12 게시판 관리

**언제 사용하나요**

수다방 게시판을 **새로 만들거나**, 기존 게시판의 이름·설명·아이콘·노출 순서를 바꾸거나, 글쓰기를 잠그거나, 게시판을 감출 때 사용합니다. 잘못 만든 빈 게시판은 삭제할 수도 있습니다. 개발자에게 요청하지 않고 이 화면에서 바로 반영됩니다.

**화면 구성**

- 위쪽에 새 게시판을 만드는 입력줄이 있습니다: **이름 · 주소 · 아이콘 · 설명**과 **게시판 추가** 버튼.
- 아래 표에는 등록된 게시판이 순서대로 나옵니다(감춘 게시판도 함께 보입니다).

| 열 | 내용 |
| --- | --- |
| 아이콘 | 게시판 이름 앞에 붙는 아이콘. 지정하지 않았으면 **—** |
| 게시판 | 사용자에게 보이는 이름 |
| 주소 | 게시판 주소(`/seeker/community/주소`) |
| 설명 | 게시판 목록·상단에 보이는 한 줄 설명 |
| 순서 | 정렬 순서. **숫자가 작을수록 앞**에 놓입니다 |
| 글쓰기 | 켜면 글을 쓸 수 있고, 끄면 읽기 전용이 됩니다 |
| 노출 | 끄면 사용자 화면에서 게시판이 사라집니다 |
| 관리 | **수정** 버튼(이름·설명·아이콘·순서 변경)과, 기본 게시판이 아닌 경우 **삭제** 버튼 |

**게시판 추가 절차**

1. **이름**에 사용자에게 보일 이름을 넣습니다(최대 30자, 예: `뷰티 수다`).
2. **주소**에 주소로 쓸 값을 넣습니다(예: `beauty-talk`). 안내대로 **영소문자·숫자·하이픈·밑줄 2~30자**만 쓸 수 있습니다.
3. **아이콘**을 고릅니다(선택). 목록에서 실제 모양과 이름을 함께 보고 고르며, 기본값은 **없음**입니다.
4. **설명**은 선택입니다(최대 200자). 게시판 상단과 홈 미리보기 카드에 한 줄로 보입니다.
5. **게시판 추가**를 누릅니다. "게시판을 만들었어요."라고 안내되고 표 **맨 끝**에 추가됩니다(순서 값은 기존 최댓값 + 10). 앞으로 옮기려면 **수정**에서 순서를 낮추세요.

추가되지 않는 경우

| 상황 | 안내 |
| --- | --- |
| 주소에 대문자·한글·공백 등이 섞임, 또는 2자 미만·30자 초과 | "주소는 영소문자·숫자·하이픈·밑줄 2~30자로 입력해 주세요." |
| `best`·`crawled`·`write` 중 하나를 입력 | "이미 쓰이고 있는 주소입니다. 다른 주소를 입력해 주세요." |
| 이미 있는 게시판과 같은 주소 | "이미 등록된 게시판 주소입니다." |

> ⚠ **주소는 만든 뒤에 바꿀 수 없습니다.** 밖으로 나간 링크가 깨지고 이미 쓰인 글이 이 값을 참조하기 때문입니다. 추가 전에 오타를 확인하세요. `best`·`crawled`·`write`는 각각 베스트글·수집 글 상세·글쓰기 화면이 쓰는 주소라 게시판 이름으로 쓸 수 없습니다.

**아이콘 고르기**

- 아이콘은 미리 준비된 **12가지 중에서만** 고를 수 있습니다: 말풍선 · 서류가방 · 쇼핑백 · 저울 · 확성기 · 반짝임 · 커피 · 음표 · 하트 · 별 · 사람들 · 신문. 직접 그림을 올리거나 이모지를 넣는 방법은 없습니다.
- 고른 아이콘은 **수다방 홈·구직자 홈의 게시판 카드 제목 앞**과 **게시판 목록 화면 상단 제목 앞**에 코럴색으로 붙습니다.
- **없음**을 고르면 아이콘 없이 지금처럼 보입니다. 이때 `공지사항`만 예외로 확성기 아이콘이 그대로 유지되고, 나머지 게시판 카드는 기존의 색 막대 표시로 돌아갑니다.
- 기본 게시판 5종은 처음에 아이콘이 지정되어 있지 않으므로, 화면 모습은 예전과 같습니다. 필요하면 **수정**에서 아이콘을 붙일 수 있습니다.

**이름·설명·아이콘·순서 바꾸기**

1. 해당 줄의 **수정**을 누르면 **게시판 수정** 창이 열립니다.
2. **이름**, **설명**, **아이콘**, **정렬 순서**(0~10000)를 고치고 **저장**을 누릅니다. "게시판을 수정했어요."라고 안내됩니다.
3. 아이콘을 **없음**으로 바꾸고 저장하면 지정해 둔 아이콘이 지워집니다.
4. 창에는 주소가 함께 적혀 있고 바꿀 수 없습니다.

순서는 수다방 홈 미리보기와 게시판 목록에 함께 적용됩니다. 기본 게시판은 10 단위로 떨어져 있으니(공지사항 0 · 자유수다 20 · 밤문화 이야기 30 · 중고거래 40 · 무료 법률 자문 50), 사이에 끼우려면 그 사이 값을 넣으세요.

**글쓰기·노출 스위치**

표에서 스위치를 누르면 **확인 창 없이 즉시** 적용됩니다.

- **글쓰기 끄기**: 게시판은 그대로 보이지만 **글쓰기** 버튼이 사라지고, 글쓰기 주소로 직접 들어가도 열리지 않습니다. 이미 쓰인 글과 댓글은 그대로 읽힙니다. 공지처럼 한동안 글을 막아 둘 때 씁니다.
- **노출 끄기**: 게시판이 수다방 홈·게시판 목록에서 사라지고, 주소로 직접 들어가면 없는 페이지로 처리됩니다. **글은 지워지지 않으며**, 다시 켜면 그대로 돌아옵니다.

**게시판 삭제**

삭제는 **잘못 만든 빈 게시판을 되돌리는 용도**입니다. 이미 쓰이고 있는 게시판을 정리할 때는 삭제가 아니라 **노출 끄기**를 씁니다.

1. 해당 줄의 **삭제**를 누르면 "○○○ 게시판을 삭제할까요?" 확인 창이 열립니다.
2. **삭제**를 누르면 지워지고 "게시판을 삭제했어요."라고 안내됩니다. (**취소**로 되돌릴 수 있습니다.)

삭제되지 않는 경우

| 상황 | 안내 |
| --- | --- |
| 글이 한 건이라도 있는 게시판 | "글이 있는 게시판은 삭제할 수 없습니다. 노출을 끄는 방식을 사용해 주세요." — 숨김·삭제 처리한 글도 남아 있는 것으로 셉니다. 그래도 게시판을 없애야 한다면 [3.11 게시물 조치](#311-게시물-조치)의 **선택 삭제 → 선택 영구 삭제**(또는 줄 메뉴의 **영구 삭제하기**)로 그 게시판 글을 0건으로 만든 뒤 다시 삭제하세요. |
| 기본 게시판(`공지사항`·`자유수다`·`밤문화 이야기`·`중고거래`·`무료 법률 자문`) | "기본 게시판은 삭제할 수 없습니다." — 이 다섯 개에는 **삭제 버튼 자체가 보이지 않습니다** |
| 이미 지워졌거나 없는 게시판 | "게시판을 찾을 수 없습니다." |

> ⚠ **삭제는 되돌릴 수 없습니다.** 기본 게시판 5종은 화면 곳곳에서 특별 규칙(공지사항의 운영자 전용 글쓰기, 밤문화 이야기의 수집 글 합류, 무료 법률 자문의 자동 비밀글 등)에 쓰이므로 지울 수 없게 막혀 있습니다. 글이 쌓인 게시판은 지우면 그 글이 함께 사라지므로 아예 삭제가 거부됩니다 — **감출 때는 반드시 노출 스위치**를 내리세요(글은 그대로 남고 다시 켜면 복구됩니다). 게시판 자체를 없애기로 결정했다면 [3.11 게시물 조치](#311-게시물-조치)에서 그 게시판 글을 **선택 삭제 → 선택 영구 삭제**로 비운 뒤 삭제해야 합니다(영구 삭제한 글은 되살릴 수 없습니다).

**새로 만든 게시판은 어떻게 동작하나요**

- **회원이 읽고 쓰는 일반 게시판**입니다. 비밀글을 쓸 수 있고, 목록에 광고·업소·내 글 **필터**가 붙으며, 추천을 많이 받은 글은 `베스트글`에도 모입니다.
- **비회원(본인인증만 한 게스트)은 참여할 수 없습니다.** 읽기는 되지만 글·댓글·추천은 `자유수다`·`밤문화 이야기`·`무료 법률 자문`으로 고정입니다.
- **로그인 없이 보는 공개 게시판(`/board`)에는 나오지 않습니다.** 공개 영역은 `공지사항`·`자유수다`·`밤문화 이야기` 세 곳으로 고정입니다.
- 기존 게시판의 특별 규칙(공지사항의 운영자 전용 글쓰기, 무료 법률 자문의 자동 비밀글·연락처 칸, 밤문화 이야기의 외부 수집 글 합류)은 **그 게시판에만** 적용되며 새 게시판에는 따라붙지 않습니다.
- 수다방 홈에서 `공지사항`은 맨 위 전체 폭, `중고거래`와 `무료 법률 자문`은 한 칸을 나눠 쓰고, 새 게시판은 그 사이 2단 영역에 순서대로 놓입니다.

> 게시판을 추가·수정하면 사용자 화면에는 보통 곧바로 반영되지만, 이미 화면을 열어 둔 사용자에게는 **최대 5분 정도 늦게** 나타날 수 있습니다. "안 보인다"는 문의가 오면 새로고침을 안내하세요.

> 목록을 불러오지 못하면 "불러오기 실패 / 목록을 불러오지 못했어요. 잠시 후 다시 시도해 주세요."가 표시됩니다. 등록된 게시판이 하나도 없으면 "등록된 게시판이 없어요."로 표시됩니다.

### 3.13 고객센터 관리

**언제 사용하나요**

회원이 보낸 1:1 문의에 답변하고, 고객센터에 노출되는 FAQ를 관리할 때 사용합니다. 화면 위쪽 탭으로 **문의 답변**과 **FAQ 관리**를 오갑니다.

#### 문의 답변

**화면 구성**

- 최근 메시지가 오간 순서로 문의 카드가 나열됩니다.
- 각 카드에는 카테고리 배지(계정·로그인 / 공고·지원 / 결제·광고 / 신고·제재 / 디자인 제작 / 기타), 진행 상태 배지(접수됨 / 답변완료 / 종료), 최근 메시지 시각, 제목과 본문 일부가 표시됩니다.

> 문의 목록에는 페이지 이동과 상태 필터가 없습니다. **접수됨** 상태 문의를 그때그때 처리해 목록이 20건을 넘기지 않도록 유지하세요. 종료된 문의도 목록에 계속 남습니다.

**답변 절차**

1. 답변할 문의 카드에서 **대화 열기**를 누릅니다. (다시 누르면 접힙니다.)
2. 맨 위에 문의 **원문**이 그대로 보이고(회원이 첨부한 이미지·스크린샷도 함께 표시됩니다), 그 아래로 지금까지 오간 대화가 시간순으로 표시됩니다. 각 메시지에는 **운영자** 또는 **회원** 배지가 붙습니다.
3. 아래 입력칸에 답변을 쓰고 **답변 보내기**를 누릅니다.
4. "답변을 보냈어요." 안내가 뜨고, 문의 상태가 **답변완료**로 바뀌며 카드가 목록 맨 위로 올라옵니다. 회원이 다시 질문하면 상태가 **접수됨**으로 돌아옵니다.

> ⚠ **운영자 답변도 금칙어 검사를 받습니다.** 신고·제재 관련 문의에 답하면서 문제가 된 표현을 그대로 인용하면 "게시할 수 없는 단어가 포함되어 있습니다"라는 안내와 함께 전송이 막힙니다. 표현을 바꿔 쓰거나, 꼭 필요하면 [3.14 금칙어 관리](#314-금칙어-관리)에서 해당 단어의 사용 스위치를 잠시 끄고 답한 뒤 다시 켜세요.

**문의 종료**

답변이 끝나 상태가 **답변완료**가 되면 답변 입력칸 아래에 **문의 종료** 버튼이 나타납니다. 누르면 "문의를 종료했어요." 안내와 함께 상태가 **종료**로 바뀌고, 답변 입력칸 대신 "종료된 문의라 답변을 남길 수 없어요."가 표시됩니다.

- 아직 **접수됨** 상태(운영자 답변 전)인 문의에는 종료 버튼이 나타나지 않습니다. 먼저 답변을 보내 주세요.
- 회원 화면에는 종료 버튼이 없습니다. 종료는 운영자만 할 수 있습니다.

> ⚠ **확인 창 없이 바로 종료되고, 종료한 문의는 다시 열 수 없습니다.** 회원도 그 문의에 답장할 수 없으므로, 이어질 대화가 없다고 판단될 때만 누르세요. 다시 대화가 필요하면 회원이 새 문의를 등록해야 합니다.

부적절한 문의 내용을 감춰야 한다면 [3.11 게시물 조치](#311-게시물-조치)의 **고객센터 문의** 탭에서 숨김·삭제를 적용합니다.

#### FAQ 관리

**등록 절차**

1. **새 FAQ 등록** 카드에서 카테고리를 고릅니다(계정·로그인 / 공고·지원 / 결제·광고 / 신고·제재 / 디자인 제작 / 기타).
2. **질문**을 입력합니다(두 글자 이상, 최대 300자).
3. **답변**을 편집기에 작성합니다. 서식·이미지도 넣을 수 있습니다.
4. **FAQ 등록**을 누릅니다. 등록한 FAQ는 **곧바로 고객센터에 공개**되므로, 문구를 확정한 뒤 등록하세요.

**공개 전환·수정·삭제**

- 목록에서 질문을 누르면 답변이 펼쳐집니다. 아래 스위치로 **공개 중 / 숨김**을 전환할 수 있고, 비공개 항목에는 접힌 상태에서도 **비공개** 배지가 붙습니다.
- **수정** 버튼을 누르면 그 자리에서 편집 폼이 열립니다. 카테고리·질문·답변을 등록 때와 같은 방식으로 고친 뒤 **저장**을 누르면 "FAQ를 수정했어요." 안내와 함께 바로 반영되고, **취소**를 누르면 편집을 접습니다. (노출 순서는 편집 화면에 나오지 않으며 기존 값이 그대로 유지됩니다.)
- **삭제** 버튼으로 FAQ를 지울 수 있습니다.

> ⚠ **FAQ 삭제에는 확인 창이 없고, 삭제한 FAQ는 복구할 수 없습니다.** 누르는 즉시 사라집니다. 오타나 내용 변경이면 삭제하지 말고 **수정**으로 고치세요. 잠시 감추기만 하면 될 때는 스위치를 **숨김**으로 내리면 됩니다.

### 3.14 금칙어 관리

**언제 사용하나요**

커뮤니티 글·댓글과 고객센터 문의에서 **쓰지 못하게 막을 단어**를 등록·관리할 때 사용합니다.

**금칙어가 동작하는 방식**

- 등록된 단어가 제목·본문에 있으면 **커뮤니티 글·댓글, 1:1 문의(운영자 답변 포함)의 등록이 차단**됩니다.
- 비교할 때 **공백과 특수문자는 무시**하고 소문자로 맞춰 비교합니다. 그래서 `성매매`를 등록하면 `성 매매`, `성-매매`도 함께 걸립니다. 반대로 `Cash`와 `cash`는 같은 단어로 취급되어 둘 다 등록할 수 없습니다.
- 공고는 **차단되지 않습니다.** 금칙어가 들어간 공고는 저장은 되고 검수 큐에 감지 표시가 붙어 올라오므로, 운영자가 [3.1 검수 큐](#31-검수-큐)에서 판단합니다.
- 공백을 무시하는 특성상 **인접한 단어가 붙어 금칙어를 이루는 오탐**이 생길 수 있습니다(예: "…미성" + "년…"). 짧은 단어를 등록할 때는 오탐 가능성을 함께 검토하세요.

**등록 절차**

1. **추가할 금칙어** 입력칸에 단어를 넣고 **추가**를 누릅니다(최대 100자).
2. 표에 원문(**금칙어**)과 비교에 쓰이는 형태(**정규화형**)가 함께 표시됩니다.

등록되지 않는 경우

| 상황 | 안내 |
| --- | --- |
| 공백·특수문자만 입력 | "금칙어는 공백·특수문자만으로 등록할 수 없습니다." |
| 이미 같은 뜻으로 등록된 단어 | "이미 등록된 금칙어입니다." |

**CSV로 한꺼번에 추가**

1. **CSV로 추가**를 누르고 `.csv` 파일을 고릅니다. 줄바꿈이나 쉼표로 구분된 단어를 읽어 들입니다.
2. 처리 후 `추가 N건 · 제외 M건` 형태로 결과가 안내됩니다. 이미 등록된 단어나 빈 항목은 제외됩니다.
3. **첫 줄도 단어로 취급합니다.** 머리글(`term` 등)이 있는 파일은 미리 지우고 올려 주세요.
4. 한 번에 500개까지 올릴 수 있고, 100자를 넘는 항목이 하나라도 있으면 **파일 전체가 등록되지 않습니다.**

**검색·사용 전환·삭제**

- 검색칸에서 금칙어·정규화형을 찾을 수 있습니다. **검색어에는 공백 무시 규칙이 적용되지 않으므로**, `성 매매`로 검색하면 `성매매`가 걸리지 않습니다. 검색은 등록된 형태 그대로 입력하세요.
- 각 줄의 **사용** 스위치를 끄면 그 단어는 검사에서 제외됩니다. 목록에는 그대로 남으므로, 잠시 풀었다가 다시 적용할 때 편리합니다.
- 삭제는 줄 단위 **삭제**, **선택 N건 삭제**, **전체 삭제** 세 가지가 있습니다.

> ⚠ **줄 단위 삭제와 선택 삭제는 확인 창 없이 즉시 실행됩니다.** 잠시 풀어 둘 목적이라면 삭제 대신 **사용 스위치**를 내리세요.
> ⚠ **전체 삭제는 되돌릴 수 없습니다.** 등록된 단어가 모두 사라지고, 커뮤니티·고객센터의 금칙어 차단이 사실상 꺼집니다. 확인 창이 뜨지만 한 번 확정하면 복구 방법이 없으니 목록을 따로 내려받아 보관한 뒤 진행하세요.

> 금칙어를 추가·삭제하거나 사용 스위치를 바꾸면 보통 즉시 반영되지만, 서비스 상황에 따라 **최대 1분 정도 늦게 적용**될 수 있습니다. "추가했는데 아직 글이 써진다"면 1분 뒤 다시 확인해 주세요.

### 3.15 후기 관리

**언제 사용하나요**

작성된 후기를 점검해 **게시 상태를 조정**할 때 사용합니다. 부적절한 후기를 숨기거나, 숨겼던 후기를 다시 게시할 때 사용합니다.

**화면 구성**

- 위쪽 탭으로 상태별로 걸러 볼 수 있습니다: 전체 / 게시됨 / 검수 대기 / 숨김.
- 각 후기 카드에는 별점, 현재 상태 배지(게시됨/검수 대기/숨김), 작성 시각, 연결된 공고 제목, 업소명, 작성자(익명이면 "익명"), 후기 본문이 표시됩니다.

**검수 대기** 상태는 후기 작성 시 자동 점검에서 전화번호·외부 메신저·협박성 표현·개인정보 같은 위험 신호가 잡혔을 때 붙습니다. 어떤 신호가 잡혔는지는 화면에 표시되지 않으므로 본문을 직접 읽고 판단하세요.

> 이 화면은 한 번에 50건까지 조회하며 페이지 이동이 없습니다. **검수 대기** 탭을 자주 비워 두세요.

**처리 절차**

1. 상태 탭에서 점검할 후기를 찾습니다.
2. 후기 내용을 확인합니다.
3. 조치를 선택합니다.
   - 게시하려면(또는 숨겼던 후기를 되살리려면) **게시** 또는 **게시 복원**을 누릅니다.
   - 부적절하면 **숨김**을 누릅니다.
   - (이미 게시된 후기에는 숨김만, 이미 숨긴 후기에는 게시 복원만 표시됩니다.)
4. 조치를 누르면 카드 안에 **사유 입력란**이 나타납니다. 사유를 두 글자 이상 입력합니다.
5. **확정**을 누릅니다. "후기 상태를 변경했어요." 안내가 표시됩니다.
6. 잘못 눌렀다면 **취소**로 되돌릴 수 있습니다. 사유 입력란은 한 번에 하나만 열리므로, 다른 카드 버튼을 누르면 쓰던 내용이 사라집니다.

**처리하면 무슨 일이 일어나나요**

- 게시(복원)한 후기는 게시됨 상태가 되어 공고 상세에 노출됩니다.
- 숨긴 후기는 숨김 상태가 되어 노출되지 않습니다.
- 입력한 사유는 기록으로 남습니다.

> 한 번 **게시** 또는 **숨김**으로 처리한 후기를 다시 **검수 대기**로 되돌릴 방법은 없습니다. 판단이 서지 않으면 처리하지 말고 그대로 두세요.

### 3.16 크롤링

**언제 사용하나요**

외부 채용 사이트(현재는 **퀸알바** 한 곳)에서 공고와 커뮤니티 글을 자동으로 모아 오는 기능을 운영할 때 사용합니다. 수집 주기 설정, 즉시 수집, 수집한 항목의 노출 관리, 업종 분류 검토를 이 화면에서 합니다.

**외부 공고 수집 카드**

1. **수집 데이터**에서 **공고** 또는 **커뮤니티** 중 하나를 고릅니다. 한 번에 한 종류만 수집합니다. "(준비 중)"이 붙은 항목은 아직 수집기가 없어 실제로 돌지 않습니다.
2. **수집 스케줄러** 스위치로 자동 수집을 켜고 끕니다. 기본값은 꺼짐입니다.
3. **수집 주기(시간)** 에 정수를 입력합니다. 비워 두면 기본값(3시간)을 씁니다.
4. **저장**을 누릅니다.

> **스케줄러 스위치는 저장 버튼과 함께 동작합니다.** 스위치만 옮기고 화면을 떠나면 반영되지 않습니다. 아래 「수집 콘텐츠 노출」의 스위치는 반대로 즉시 저장되니 혼동하지 마세요.

**즉시 수집**

**즉시 수집**을 누르면 주기를 기다리지 않고 한 회차를 지금 시작합니다. 스케줄러가 꺼져 있어도 실행되며, 화면에서 고른 수집 데이터 종류로 돕니다(이 선택은 저장되지 않습니다).

> ⚠ **즉시 수집은 실제 외부 사이트에 접속해 여러 페이지를 훑는 조작입니다.** 한 회차에 몇 분이 걸리고, 회차가 정상 마무리되면 **오랫동안 확인되지 않은 수집 공고가 만료로 정리되고, 메인 목록에서 사라진 공고의 광고 배너 표시가 해제**됩니다. 즉 수집 배너 노출이 즉시 줄어들 수 있습니다. 필요할 때만, 그리고 진행 중인 회차가 없을 때만 눌러 주세요.
> 이미 진행 중인 회차가 있으면 "이미 수집이 진행 중이에요."라는 안내가 뜨고 실행되지 않습니다.

**수집 콘텐츠 노출 카드**

세 개의 스위치로 수집한 항목을 사용자 화면에 내보낼지 정합니다. 기본값은 모두 꺼짐입니다.

- **광고 배너 슬롯 노출**: 결제 광고가 채우지 못한 빈 배너 자리에만 수집 배너가 들어갑니다. 결제 광고를 밀어내지는 않습니다.
- **공고 목록 노출**: 수집 공고가 공고 목록에 섞입니다. 유료 섹션에는 들어가지 않고 검증 배지도 붙지 않습니다. **업종·지역·업소명이 모두 채워진 공고만** 목록에 나옵니다.
- **수집 커뮤니티 글 노출**: 수집한 게시글이 커뮤니티에 섞입니다. 목록·상세에 출처 표시는 붙지 않고, 회원·비회원이 우리 글과 같은 규칙으로 **댓글**을 남길 수 있습니다(글 자체의 추천·신고는 없습니다).

> ⚠ **이 스위치들은 확인 창 없이 토글하는 즉시 저장되고, 곧바로 사용자 화면에 반영됩니다.** 특히 커뮤니티 노출은 외부 사이트 게시글을 우리 게시판에 세우는 조작이므로, 켜기 전 내용을 먼저 확인하세요.
> 수집 커뮤니티 글의 **상세 보기**는 이 스위치가 켜져 있을 때만 열립니다. 본문을 확인하려면 스위치를 잠시 켜야 합니다.
> 여러 창에서 동시에 스위치를 만지면 나중에 저장된 값이 앞선 변경을 덮습니다. 한 창에서만 조작하세요.

**수집 상한 카드**

배너·스페셜·급구·추천 자리마다 수집 공고를 몇 개까지 넣을지(각 0~60), 커뮤니티 글을 한 회차에 몇 개까지 모을지(1~150) 정합니다. 비워 두면 기본값(8 / 12 / 12 / 12 / 150)을 씁니다. 우리 서비스 공고가 항상 먼저 나오고, 남은 자리에만 수집 공고가 붙습니다.

**수집 현황 카드**

수집됨 / 만료 / 업종 검토 대기 / 삭제됨 / 전환됨 건수를 보여 줍니다. "전환됨"은 현재 사용하지 않는 항목이라 항상 0으로 표시됩니다.

**업종 검토 대기 카드**

외부 사이트의 직종 표기가 우리 업종 분류에 자동으로 이어지지 않은 공고가 모입니다. 최근 30건까지 표시되며(전체 건수는 문단에 표기), 원본 업종 문구를 보고 오른쪽 선택 상자에서 업종을 고르면 됩니다.

> ⚠ **업종은 고르는 즉시 저장되고, 그 공고는 검토 대기에서 빠져 노출 대상이 됩니다.** 확인 창이 없고 검토 대기로 되돌릴 방법도 없습니다. 잘못 골랐다면 다른 업종으로 다시 고르는 것만 가능합니다.

**수집 공고 관리 / 수집 커뮤니티 글 관리 카드**

상태 필터(전체 / 수집됨 / 업종 검토 대기 / 만료 / 삭제됨)로 걸러 보고, 줄 오른쪽 메뉴에서 **상세 보기**·**이미지 편집**·**삭제**·**복구**를 적용합니다. **이미지 편집**은 수집됨 상태의 공고에만 표시됩니다. 이미지 편집을 저장하거나 취소하면 편집을 시작한 상태 필터와 페이지로 돌아옵니다.

제목 왼쪽 선택 칸으로 현재 페이지의 공고를 최대 10개까지 고를 수 있습니다. 머리글 선택 칸은 현재 페이지의 삭제 가능한 공고를 모두 선택하고, 하나 이상 고르면 상태 필터 오른쪽에 빨간 **선택 삭제 (N)** 버튼이 나타납니다. 한 번 확인하면 선택한 공고가 모두 **삭제됨**으로 이동하며, 뒤 공고가 있으면 같은 페이지를 다시 최대 10개로 채웁니다. 페이지나 상태 필터를 바꾸면 선택은 초기화됩니다. 이미 삭제된 행은 선택할 수 없고 **삭제됨** 필터에서는 선택 칸 없이 기존 복구 기능만 제공합니다.

**수집 공고 상세 이미지 편집**

1. 수집됨 공고 오른쪽 점 3개 메뉴에서 **이미지 편집**을 누릅니다.
2. 이미지를 클릭해 선택합니다. `Ctrl`/`Cmd`를 누른 채 클릭하면 여러 장을 선택하고, `Shift`를 누른 채 클릭하면 연속 범위를 선택합니다.
3. 네 모서리 손잡이, px 슬라이더 또는 숫자 입력으로 표시 크기를 조절합니다. 원본 비율은 고정되고 최소 너비는 50px입니다.
4. 이미지를 우클릭하면 **자르기 / 복사 / 붙여넣기 / 전체 선택 / 다른 이름으로 저장 / 삭제 / 실행 취소** 메뉴가 열립니다. 모바일은 이미지 오른쪽 위 점 3개 버튼을 사용합니다.
5. 이미지 사이의 가는 삽입 위치를 누른 뒤 붙여넣거나 **이미지 추가**를 누르면 그 자리에 들어갑니다. 한 번에 한 장의 JPEG·PNG·GIF·WebP 파일만 추가할 수 있습니다.
6. 순서는 드래그하거나 위·아래 이동 버튼으로 바꿉니다. GIF는 자르기를 지원하지 않습니다.
7. **원본으로 초기화**는 크롤링 원본을 다시 초안으로 불러옵니다. 저장 전에는 언제든 실행 취소하거나 취소할 수 있습니다.
8. **저장**을 눌러야 구직자 상세 화면에 반영됩니다. 이미지를 전부 삭제한 상태도 저장할 수 있고, 저장 성공 후에는 편집을 시작한 수집 공고 상태 필터와 페이지로 돌아갑니다.

> 편집 중인 내용은 저장 전까지 임시 상태입니다. 취소·새로고침·탭 닫기 때는 변경 폐기 여부를 확인합니다. 두 운영자가 같은 공고를 동시에 편집하면 먼저 저장한 사람만 성공하며, 뒤의 화면은 새로 불러온 뒤 다시 편집해야 합니다. 원본 Base64 이미지는 별도로 보존되며 편집본 저장이나 공고 삭제·복구로 사라지지 않습니다.

- **삭제**는 확인 창을 거치며, 지운 항목은 「삭제됨」으로 남습니다. 다음 회차가 같은 글을 다시 만나도 되살아나지 않으므로, 반복해서 올라오는 문제 공고를 막는 데 쓰면 됩니다.
- **복구**는 확인 창 없이 즉시 적용됩니다. 복구하면 업종이 지정된 공고는 수집됨으로, 지정되지 않은 공고는 업종 검토 대기로 돌아갑니다.

**최근 수집 회차 카드**

최근 20회차의 시작 시각·출처·상태·건수·오류 메모를 보여 줍니다. **새로고침**으로 진행 상황을 다시 불러올 수 있습니다.

| 상태 | 의미와 대응 |
| --- | --- |
| 진행 중 | 회차가 돌고 있습니다. 끝날 때까지 기다립니다. |
| 성공 | 정상 종료했습니다. |
| 실패 | 오류로 중단됐습니다. 메모에 원인이 표시됩니다. 인증 쿠키 만료·robots.txt 차단 등은 개발팀 조치가 필요합니다. |
| 수율 미달 중단 | 장애가 아니라 **외부 사이트의 화면 구조가 바뀌었다는 신호**입니다. 이 회차는 기존 데이터를 건드리지 않고 스스로 멈춥니다. 개발팀에 파서 점검을 요청하세요. |

> ⚠ **비우기**를 누르면 진행 중이 아닌 **모든 회차 기록이 물리적으로 삭제되며 복구할 수 없습니다.** 수집한 공고·커뮤니티 글은 남지만, 수집 성공률 추이가 사라져 화면 구조 파손 시점을 되짚을 수 없게 됩니다. 확인 창이 뜨더라도 한 번 더 필요성을 검토하세요.

**수집 대상 추가 요청**

새 사이트를 수집 대상에 넣는 것은 화면에서 할 수 없는 개발 작업입니다. 필요하면 개발팀에 요청하세요.

### 3.17 사이트 정보

**언제 사용하나요**

서비스 화면 맨 아래(푸터)에 노출되는 **사업자 정보**, 결제 안내의 **무통장입금 계좌**, 그리고 **회원 정책·최저시급 표기·광고 배너 로테이션** 같은 서비스 공통 설정을 관리할 때 사용합니다.

화면에는 카드 일곱 개가 세로로 나열되며, **카드마다 저장 버튼이 따로 있습니다.** 한 카드를 저장해도 다른 카드의 값은 건드리지 않으니, 고친 카드의 저장 버튼만 누르면 됩니다.

**① 푸터 사업자 정보**

서비스 소개 문구, 상호(운영 주체), 대표자, 사업자등록번호, 고객문의 이메일, 고객센터 전화, 광고 등록 문의 전화, 사업장 주소를 입력합니다.

1. 각 입력란에 값을 채웁니다. **비워 두면 회색 안내 문구로 표시된 기본값이 대신 노출**됩니다. 값을 지우면 해당 항목은 기본값으로 되돌아갑니다.
2. 고객문의 이메일은 이메일 형식을 검사합니다. 형식이 맞지 않으면 저장되지 않고 "올바른 이메일 형식이 아닙니다." 안내가 표시됩니다.
3. **저장**을 누르면 "사이트 정보를 저장했어요." 안내가 뜨고, 저장한 값이 곧바로 서비스 푸터에 반영됩니다. 광고 등록 문의 전화는 광고 배너 자리의 "광고 등록 문의"에 노출됩니다.

**② 개인정보 처리방침 연락처**

개인정보 처리방침 페이지에 노출되는 항목입니다.

1. **본인인증 대행사(수탁사명)**, **보호책임자 성명**, **관리부서 전화**, **관리부서 메일** 네 항목을 입력합니다. 비워 두면 회색 안내 문구로 표시된 기본값이 대신 노출됩니다.
2. 관리부서 메일은 이메일 형식을 검사합니다.
3. **저장**을 누르면 "개인정보 처리방침 연락처를 저장했어요." 안내가 뜨고, 처리방침 페이지에 반영됩니다.

**③ 무통장입금 계좌**

1. **계좌 추가**를 눌러 행을 추가하고 은행명·계좌번호·예금주를 입력합니다. 세 항목 모두 필수이며, 세 항목이 전부 비어 있는 행은 저장 시 자동으로 제외됩니다. 계좌는 최대 10개까지 등록할 수 있습니다.
2. 필요 없는 계좌는 해당 행의 **삭제**로 뺍니다.
3. **계좌 저장**을 누르면 "무통장입금 계좌를 저장했어요." 안내가 표시됩니다.

여기서 저장한 계좌는 **구인자의 공고 결제 화면과 광고 관리의 "입금 안내"에 그대로 노출**됩니다. 등록된 계좌가 없으면 결제 안내가 고객센터 문의 문구로 대체되므로, 계좌 정보를 항상 최신 상태로 유지하세요. 현재 신용카드 결제는 "준비중"으로 안내되어 유료 공고 결제는 무통장입금으로 이뤄지며, 입금 확인 뒤 처리는 [3.10 결제 관리](#310-결제-관리)에서 진행합니다.

**④ 회원 정책**

**탈퇴 개인정보 보존기간(일)** 을 정합니다(1~365 사이 정수, 비워 두면 기본값 30일). 이 값은 탈퇴 안내 문구와 개인정보 처리방침에 그대로 표시되고, 아래 파기 실행의 기준이 됩니다. 사용자 화면(회원 탈퇴 안내)에는 같은 값이 "N일 동안 보관한 뒤 파기"라는 **보관 기간**으로 안내되므로, 문의가 오면 같은 값을 가리키는 말이라고 안내하세요.

옆의 **파기 배치 실행 시각(0~23시)** 은 파기 배치가 매일 몇 시에 도는지를 정합니다(0~23 사이 정수, **한국 시간** 기준, 비워 두면 기본값 새벽 4시). 트래픽이 적은 시간대로 두는 것을 권장합니다. **저장**을 누르면 "회원 정책을 저장했어요." 안내가 표시되고, 다음 실행부터 새 시각·보존기간이 적용됩니다.

파기는 **서버가 매일 설정한 시각에 자동으로 1회 실행**합니다. 보존기간이 지난 탈퇴 계정의 잔여 식별값이 자동으로 지워지므로 평소에는 운영자가 따로 할 일이 없습니다. 서버는 **10분마다 "오늘 몫이 돌았는지"를 다시 확인**하므로 설정 시각이 지난 뒤 최대 10분 안에 실행되며, 서버를 껐다 켜도 그날 몫이 아직 안 돌았으면 이어서 실행합니다(마지막 실행 시각을 기록해 두기 때문입니다).

카드 아래쪽에는 **마지막 실행** 시각이 표시됩니다(한 번도 돌지 않았으면 "아직 없음"). 자동 실행과 수동 실행 모두 이 값을 갱신하며, **파기 대상이 0건이었거나 도중에 실패한 경우에도 갱신됩니다.** 그래서 실패한 날은 그날 다시 돌지 않고 다음 날 예약 실행이 이어받습니다. 급하면 **지금 파기 실행**으로 그 자리에서 다시 돌리세요.

그 옆의 **지금 파기 실행** 버튼은 **다음 자동 실행을 기다리지 않고 즉시 정리할 때** 쓰는 수동 트리거입니다(보존기간을 줄여 저장한 직후 등). 자동 실행과 완전히 같은 처리를 하며, 겹쳐 실행돼도 같은 계정이 두 번 처리되지는 않습니다.

- 그날 설정 시각이 **이미 지난 뒤에** 수동으로 실행하면 그날 예약분은 건너뜁니다(이미 정리됐으므로 결과는 같습니다).
- 아직 설정 시각 **전에** 눌렀다면 그 시각이 되었을 때 예정대로 한 번 더 돕니다. 남은 대상만 처리하므로 이미 정리된 계정이 다시 손상되지는 않습니다.

> **실행 시각을 바꿀 때 주의할 점** — 오늘 이미 파기가 돈 뒤에 실행 시각을 **더 늦은 시각으로** 바꾸면, 그 시각이 되었을 때 오늘 한 번 더 실행됩니다(마지막 실행이 새 시각보다 이르기 때문입니다). 반대로 **더 이른 시각으로** 바꾸면 오늘은 더 돌지 않고 다음 날부터 새 시각이 적용됩니다. 어느 쪽이든 이미 파기된 계정이 다시 처리되지는 않으니, 시각을 옮긴 날에는 **마지막 실행** 표시로 실제 실행 여부만 확인하면 됩니다.

> 회원이 탈퇴하는 순간에는 개인정보가 지워지지 않습니다. 탈퇴하면 로그인 세션이 끊기고 표시 이름이 '탈퇴한 회원'으로 바뀌며 프로필 사진과 조직·팀 소속이 정리되지만, 아이디·이메일·연락처는 보존기간 동안 그대로 남습니다(탈퇴한 계정의 재로그인 시도에 "탈퇴한 계정이에요"라고 안내하기 위해 필요합니다). 보존기간이 지나면 위 자동 실행이 이를 파기합니다.

> ⚠ **「지금 파기 실행」은 확인 창 없이 즉시 실행되며 되돌릴 수 없습니다.** 보존기간이 지난 탈퇴 계정의 로그인 정보·연락처·본인인증 식별값이 지워지고, 이메일과 이름이 대체 값으로 바뀝니다. 누르기 전에 **보존기간 설정이 의도한 값인지** 반드시 확인하세요(보존기간을 짧게 저장한 직후 실행하면 예상보다 많은 계정이 대상이 됩니다).
> 대상이 없으면 "보존기간이 지난 탈퇴 계정이 없어요."가 표시되고 아무 일도 일어나지 않습니다. 연속으로 눌러도 같은 계정이 두 번 처리되지는 않습니다.

**⑤ 최저시급 표기**

공고 상세의 급여 옆에 표시되는 **기준 연도**와 **시급(원)** 을 입력하고 **저장**합니다. 기본값은 2026년 10,320원입니다.

> 한쪽만 바꾸면 다른 쪽은 기본값이 표시되어 연도와 금액이 어긋납니다. **두 값을 항상 함께 갱신**하세요.

**⑥ 광고 배너 로테이션**

프리미엄 배너가 몇 분마다 한 칸씩 돌아갈지 정합니다(1~10080분, 비워 두면 기본값 60분). **저장**을 누르면 반영되며, 주기를 바꾼 직후에는 배너 위치가 한 번 건너뛸 수 있습니다.

> 프리미엄 배너 정원(10자리)은 이 화면에서 바꿀 수 없는 고정값입니다.

**⑦ 문의 채팅 공지**

문의자 위젯(우하단 플로팅 버튼)의 **홈 탭**에 노출되는 **공지 배너 문구**를 입력합니다(최대 300자). 점검 안내나 응대 지연 공지 등 문의자가 대화를 시작하기 전에 먼저 보여 줄 내용을 적으면 됩니다. **저장**을 누르면 홈 탭에 반영되고, **비워 두면 배너가 표시되지 않습니다.**

### 3.18 문의 채팅

**언제 사용하나요**

회원·비회원이 화면 오른쪽 아래 플로팅 버튼으로 남긴 **실시간 문의**에 답할 때 사용합니다. 내비게이션 **콘텐츠** 그룹의 **문의 채팅**(`/moderator/support-chats`)으로 들어갑니다. 앞의 [3.13 고객센터 관리](#313-고객센터-관리)의 1:1 문의와는 별개 창구로, 가벼운 실시간 대화용입니다.

**공용 큐입니다.** 모든 운영자가 같은 목록을 보고, 누가 먼저 답하든 같은 대화에 이어집니다. 다른 운영자가 이미 응대 중인 대화는 겹치지 않게 확인하세요. 한 문의자가 **여러 대화**를 가질 수 있습니다(종료된 대화 뒤에 새 대화를 시작하기 때문입니다). 목록·대화는 약 **5초마다 자동 갱신**됩니다.

**진행 중 · 종료 탭**

목록 위 **진행 중 / 종료** 탭으로 상태별 대화를 나눠 봅니다. **진행 중**은 열려 있는 대화, **종료**는 운영자가 종료했거나 마지막 메시지 이후 **7일 동안 오간 내용이 없어 자동 종료된** 대화입니다. 7일 무활동 자동 종료는 별도 배치 없이 이 기준으로 판정되므로, 오래된 대화는 상태를 바꾸지 않아도 자연히 **종료** 탭으로 넘어갑니다.

**화면 구성(데스크톱 3열)**

- **왼쪽 목록**: 최근 메시지 순으로 대화가 나열됩니다. 각 대화에는 **회원/비회원** 배지, 표시 이름(비회원은 식별용 임시 번호), 최근 메시지 미리보기, 시각이 보이고, 안 읽은 문의자 메시지가 있으면 **미읽음 개수 뱃지**가, 잠긴 문의자의 대화에는 **자물쇠 아이콘**이 붙습니다. 종료된 대화에는 **종료** 표시가, 한 문의자가 대화를 여럿 가진 경우 **대화 N개** 표시가 함께 보입니다. 대화가 많으면 아래 **이전/다음**으로 넘깁니다.
- **가운데 대화**: 대화를 고르면 내용이 열립니다. 말풍선은 **문의자 왼쪽 · 운영자 오른쪽**입니다(문의자 위젯과 반대 방향). 아래 입력칸에 답을 쓰고 전송(또는 Enter)하면 상대에게 전달되고, 대화를 열면 미읽음은 자동으로 읽음 처리됩니다.
- **오른쪽 문의자 정보**: 회원이면 이름·역할·성별·가입일·소속 업소(있을 때)가, 비회원이면 구분과 최초 문의 시각이 표시됩니다. 데스크톱 좁은 화면·모바일에서는 대화 위 **문의자 정보** 버튼으로 접었다 펼칩니다.

**대화 종료와 재개**

응대가 끝난 대화는 대화 상단의 **대화 종료** 버튼으로 닫습니다. 닫으면 문의자 쪽 입력창이 잠기고, 문의자는 필요할 때 새 대화를 시작하게 됩니다. **대화 재개** 버튼으로 다시 열 수 있습니다. 종료된 대화에서도 운영자 입력창은 막히지 않으며, **답변을 보내면 대화가 자동으로 다시 열립니다**(재개 버튼을 따로 누르지 않아도 됩니다). 실수로 닫았더라도 답변 한 번이면 이어집니다. 종료 방 컴포저 위에는 "종료된 대화예요. 답변을 보내면 다시 열려요."라는 안내가 표시됩니다.

**문의자 발신 잠금**

문의자 정보 패널의 **문의자 발신 잠금** 버튼은 **문의자 단위**로 적용됩니다. 잠그면 그 문의자의 **모든 대화**(앞으로 시작하는 새 대화 포함)에서 메시지를 보낼 수 없고 "문의 발신이 제한된 상태예요."라고 안내됩니다(운영자는 계속 답할 수 있습니다). **잠금 해제**를 누르면 다시 보낼 수 있습니다. 대화 단위가 아니라 문의자 단위라, 새 대화를 열어 잠금을 우회할 수 없습니다.

**홈 탭 공지 문구**

문의자 위젯 **홈 탭**에 노출되는 공지 배너 문구는 [3.17 사이트 정보](#317-사이트-정보)의 **⑦ 문의 채팅 공지** 카드에서 설정합니다. 비워 두면 배너가 표시되지 않습니다.

> 문의자가 새 메시지를 보내면 알림함으로 통지됩니다(공용 큐라 운영자 전체에게 갑니다). 회원 문의자는 운영자 답변을 알림함으로도 받고, 비회원은 위젯 버튼 뱃지로만 확인합니다.

### 3.19 포인트몰

**언제 사용하나요**

회원이 적립 포인트로 바꿔 갈 수 있는 아이템을 등록·관리하고, 접수된 주문을 이행할 때 사용합니다. 내비게이션 **광고·결제** 그룹의 **포인트몰**(`/moderator/point-shop`)로 들어가며, 화면은 **아이템 관리**·**주문 관리** 두 탭입니다.

**먼저 알아 둘 것**

- 회원이 구매를 누르는 순간 **포인트는 그 자리에서 차감**되고, 주문은 **처리 대기** 상태로 접수됩니다. 아이템 지급은 자동이 아니라 운영자가 손으로 합니다.
- 이행이 어려우면 **취소·환불**로 처리하세요. 차감했던 포인트가 즉시 회원 잔액으로 되돌아갑니다. 별도의 포인트 지급 조작(출석 관리의 지급·차감)을 따로 할 필요가 없습니다.
- **포인트몰 구매·환불은 회원 등급 계산에 반영되지 않습니다.** 등급 계산에서 빠지는 것은 포인트몰 구매·환불뿐이고, 출석·수다방 활동은 물론 운영자 수동 지급·차감(출석 관리)도 등급에 그대로 반영됩니다. 그래서 회원이 아이템을 사도 등급이 내려가지 않고 환불해도 올라가지 않습니다. 화면에 보이는 회원 포인트 **잔액**에는 구매·환불이 그대로 반영됩니다.
- 구매는 **구직자·업소 회원**만 할 수 있습니다(법률자문 계정은 구매할 수 없습니다).
- 회원 화면의 포인트몰(`/point-shop`) 목록은 **로그인하지 않아도 보입니다.** 구매만 로그인 회원으로 제한되므로, 등록한 아이템은 비회원에게도 그대로 노출된다고 생각하고 이름·설명을 적어 주세요.

**아이템 관리 탭**

목록 위 오른쪽 **아이템 추가** 버튼으로 새 아이템을 등록하고, 각 줄의 **수정**·**삭제**로 관리합니다. 목록에는 숨긴 아이템까지 모두 나옵니다(회원 화면에는 노출 중인 것만 보입니다).

| 열 | 의미 |
| --- | --- |
| 이미지 | 등록한 아이템 사진. 없으면 회색 자리표시 아이콘 |
| 아이템 | 아이템명과 설명(설명은 한 줄로 줄여 표시) |
| 가격 | 회원이 내야 하는 포인트(예: `5,000P`) |
| 노출 | **노출** / **숨김** |
| 정렬 | 목록 정렬값. 값이 **작을수록 앞**에 놓이고, 같으면 먼저 만든 아이템이 앞 |
| 관리 | **수정** · **삭제** |

아이템·가격·정렬 열 제목을 누르면 그 기준으로 정렬됩니다.

**아이템 추가·수정 폼**

| 항목 | 입력 안내 |
| --- | --- |
| 아이템명 | 필수, 최대 60자 |
| 설명 | 선택, 최대 500자. 구매 창에서 회원에게 보입니다(비워 두면 "운영자가 확인한 뒤 순서대로 지급해요."가 대신 표시됩니다) |
| 가격(포인트) | 1 이상 10,000,000 이하의 정수 |
| 정렬값 | 0 이상 100,000 이하의 정수. 작을수록 목록 앞 |
| 포인트몰에 노출 | 켜면 회원 목록에 보이고, 끄면 목록에서 사라지며 구매도 막힙니다 |
| 이미지 | JPG·PNG·WebP, 10MB 이하. 회원 화면 카드가 정사각형이라 정사각 이미지가 가장 깔끔합니다 |

- 파일을 고르면 바로 업로드되고 미리보기가 뜹니다. **이미지 제거**로 되돌릴 수 있으며, 이미지를 바꾸려면 파일을 다시 고르면 됩니다.
- 입력이 유효해야 **저장**이 활성화됩니다. **취소**를 누르면 저장하지 않고 창이 닫힙니다.
- 판매를 잠시 멈출 때는 삭제하지 말고 **노출 스위치를 끄세요.** 되돌리기 쉬운 조작입니다.

**아이템 삭제**

**삭제**를 누르면 확인 창이 뜨고, 확인하면 아이템이 사라집니다. **되돌릴 수 없습니다.** 다만 이미 접수된 주문은 구매 시점의 **아이템명·차감 포인트를 스냅샷으로 보존**하므로, 아이템을 지워도 회원의 구매 내역과 환불 근거는 그대로 남습니다.

**주문 관리 탭**

위쪽 필터에서 **처리 대기 / 지급 완료 / 취소·환불 / 전체**를 고릅니다. 기본값은 **처리 대기**라 들어오면 바로 밀린 주문부터 보입니다.

| 열 | 의미 |
| --- | --- |
| 주문일 | 주문이 접수된 일시. 처리된 주문은 아래에 **처리 (일시)**가 함께 표시 |
| 구매자 | 회원 닉네임과 이메일. 탈퇴한 계정이면 **탈퇴한 회원** |
| 아이템 | 구매 시점의 아이템명(이후 아이템을 수정·삭제해도 바뀌지 않음) |
| 차감 포인트 | 구매 시 차감된 포인트 |
| 상태 | **처리 대기** / **지급 완료** / **취소·환불** |
| 메모 | 운영자가 남긴 메모(주로 취소 사유). 없으면 `-` |
| 관리 | 처리 대기 주문에만 **지급 완료**·**취소·환불** 버튼. 이미 처리한 주문은 **처리 완료**로 표시 |

한 번에 20건씩 보이며, 표 아래에서 페이지를 넘깁니다.

**지급 완료 처리**

1. 아이템을 실제로 지급(기프티콘 발송 등)한 뒤, 해당 줄의 **지급 완료**를 누릅니다.
2. 확인 창에서 대상 회원과 아이템을 다시 확인하고 **지급 완료**를 누릅니다.
3. "지급 완료로 처리했어요."가 안내되고 상태가 바뀝니다. 차감된 포인트는 그대로 두고 상태만 바뀝니다.

**취소·환불 처리**

1. 품절·중복 주문 등으로 이행할 수 없으면 **취소·환불**을 누릅니다.
2. 확인 창에 돌려줄 포인트가 표시됩니다. **취소 사유**(최대 300자)를 적고 **취소·환불**을 누릅니다.
3. "주문을 취소하고 포인트를 돌려줬어요."가 안내되고, 차감했던 포인트가 즉시 회원 잔액에 다시 더해집니다.

> ⚠ **지급 완료·취소·환불은 한 번만 적용되고 되돌릴 수 없습니다.** 완료한 주문을 다시 취소하거나, 취소한 주문을 완료로 바꿀 수 없으며, 이미 처리된 주문에 다시 시도하면 "이미 처리된 주문입니다."라고 거부됩니다. 잘못 지급 완료했다면 주문 처리로는 되돌릴 수 없으니, [3.8 출석 관리](#38-출석-관리)의 포인트 **지급**으로 사유를 남겨 보정하세요.

> 취소 사유로 적은 메모는 **구매자의 "포인트 구매 내역" 화면에 그대로 보입니다.** 회원이 읽을 문장으로 적어 주세요.

> 주문 처리 결과는 회원에게 알림으로 통지되지 않습니다. 회원은 **내 정보 → 포인트 구매 내역**에서 직접 상태를 확인합니다. 급한 안내가 필요하면 문의 채팅이나 고객센터로 별도 연락해 주세요.

## 5. 처리 원칙과 주의사항

- **모든 조치에는 사유가 필요합니다.** 공고 일괄 처리, 신고 조치, 후기 상태 변경, 채팅방 차단·삭제, 게시물 조치, 사용자 제재(개별·일괄) 등에서 사유 입력이 요구되며, 사유는 **두 글자 이상** 입력해야 처리가 진행됩니다. 공백만 입력한 경우에는 처리되지 않습니다. (예외: 게시물 조치의 **영구 삭제하기**는 사유를 다시 묻지 않습니다 — 선행 **삭제** 조치의 사유가 그 기록입니다.)
- **모든 조치는 기록으로 남습니다.** 운영자가 누른 승인·반려·제재·차단 등은 사유와 함께 감사 기록으로 저장되며, 사용자 상세의 **제재 이력**에서 조회할 수 있습니다. 화면의 사유 입력란에도 "조치 사유는 감사 로그에 남아요"라고 안내됩니다.
- **일괄 처리는 한 번에 50건까지입니다.** 공고 검수, 사용자 제재, 신고 처리, 결제 전환 모두 같은 한도입니다. 처리 후 성공·실패 건수가 안내되니, 실패한 건이 있으면 개별적으로 다시 확인하세요.
- **처리 전 대상 정보를 충분히 확인하세요.** 특히 신고 처리와 사용자 제재는 대상에게 직접적인 영향을 주므로, 신고 상세와 대상 맥락(공고 본문, 최근 메시지, 계정 상태 등)을 확인한 뒤 조치합니다.
- **되돌릴 수 있는 조치를 먼저 쓰세요.** 노출만 막으면 되는 상황이라면 삭제 대신 숨김을, 판매를 멈출 뿐이라면 삭제 대신 스위치 끄기를, 단어를 잠시 풀 뿐이라면 삭제 대신 사용 스위치 끄기를 사용합니다.

## 6. 자주 묻는 질문

**Q. 검수 큐에 어떤 공고가 올라오나요?**
게시 전 검수를 기다리는 공고가 모두 올라옵니다. 인증된 업소의 공고도 예외 없이 검수를 거칩니다.

**Q. 승인했는데 공고가 노출되지 않습니다.**
유료 광고를 붙인 공고는 **게시 + 결제완료**가 모두 충족돼야 노출됩니다. 목록에서 상태가 **미공개**로 보인다면 [3.10 결제 관리](#310-결제-관리)에서 입금 확인 후 결제완료 처리하세요.

**Q. 검수 큐의 "높은 위험" 필터를 골랐는데 아무것도 안 나옵니다.**
정상입니다. 위험도는 감지 문구 유무로만 중간/낮음이 정해지므로 높은 위험 항목은 큐에 올라오지 않습니다. 우선 처리 대상은 **중간 위험**으로 추리세요.

**Q. 반려한 공고의 사유는 구인자에게 어떻게 보이나요?**
구인자 화면에는 공통 반려 안내 문구가 반려 사유로 표시됩니다. 어떤 표현이 문제였는지 구체적으로 알려야 한다면 고객센터 문의 답변 등 별도 경로로 안내해 주세요.

**Q. 이용 정지는 며칠 뒤에 자동으로 풀리나요?**
자동 해제는 없습니다. 운영자가 사용자 상세의 **계정 상태 복구**에서 **정상으로 복구**를 눌러야 풀립니다.

**Q. 경고 상태인 계정에도 "계정 상태 복구"가 보입니다. 맞나요?**
맞습니다. 정상이 아닌 계정(경고·정지 모두)에 표시됩니다. 경고를 지우는 것이 아니라 계정 상태를 정상으로 되돌리는 조작이며, 누적 경고 횟수는 그대로 남습니다.

**Q. 신고를 잘못 눌러 처리했습니다. 취소할 수 있나요?**
사유 입력 단계에서는 **취소**로 되돌릴 수 있지만, 확정한 조치는 기록으로 남습니다. 필요하면 반대 조치(숨김 → 게시 복원, 차단 → 차단 해제 등)로 상태를 되돌립니다.

**Q. 대화방을 차단하고 싶은데 채팅 관리 화면에 버튼이 없습니다.**
차단·차단 해제는 **신고 검토 화면**의 채팅방 신고에서만 할 수 있습니다. 채팅 관리 화면에서는 내역 열람과 삭제만 가능합니다.

**Q. 비회원이 쓴 글로 신고가 들어왔습니다. 작성자를 제재할 수 있나요?**
없습니다. 비회원은 계정 없이 본인인증만 거쳐 글을 쓰므로 사용자 관리에 대상 계정이 없습니다. [3.11 게시물 조치](#311-게시물-조치)나 신고 검토 화면에서 글·댓글을 숨김·삭제하고 신고는 **조치 완료**로 마감하세요. 반복되는 표현은 금칙어로 막는 것이 유일한 사전 차단입니다.

**Q. 무료 법률 자문 글은 비밀글이라던데 운영자가 볼 수 있나요?**
볼 수 있습니다. 운영자는 게시판을 가리지 않고 수다방 비밀글을 비밀번호 없이 열람하며, 콘솔의 게시물 조치·신고 검토 화면에서도 잠금과 관계없이 본문이 보입니다. 상담 글은 민감하므로 조치에 필요한 범위에서만 열어 주세요.

**Q. 법률자문으로 지정했더니 그 계정이 다른 게시판에 못 들어간다고 합니다.**
정상입니다. 법률자문 계정은 `무료 법률 자문` 게시판 전용이라 다른 게시판은 읽기·쓰기가 모두 막히고, 지정 중에는 채팅도 새로 걸 수 없습니다. 원래대로 돌리려면 사용자 목록에서 **법률자문 해제**를 적용하세요.

**Q. 파기 배치 실행 시각을 오늘 늦은 시간으로 바꿨더니 오늘 또 돌았습니다.**
정상입니다. "오늘 설정 시각 이후로 아직 안 돌았다"를 기준으로 판단하기 때문에, 이미 실행된 날 시각을 뒤로 옮기면 그 시각에 한 번 더 실행됩니다. 이미 파기된 계정이 다시 처리되지는 않습니다.

**Q. 숨김 처리한 커뮤니티 글을 다시 찾으려면?**
[3.11 게시물 조치](#311-게시물-조치)에서 해당 탭을 열고 페이지를 넘겨 찾습니다. 상태로 걸러 보는 기능이 없으므로, 조치할 때 어느 페이지의 어떤 글이었는지 메모해 두면 좋습니다. 커뮤니티 글이라면 **게시판 필터**로 범위를 좁히면 훨씬 빨리 찾습니다.

**Q. 게시판을 지우려는데 "글이 있는 게시판은 삭제할 수 없습니다"가 뜹니다. 글은 전부 삭제했는데요?**
게시물 조치의 **삭제**는 기록을 남기는 삭제라 글이 그대로 남아 있기 때문입니다. [3.11 게시물 조치](#311-게시물-조치)의 **커뮤니티 글** 탭에서 게시판 필터로 그 게시판을 고르고, 머리글 선택 칸으로 페이지 전체를 고른 뒤 **선택 삭제 → 선택 영구 삭제**(한 건씩이면 줄 메뉴의 **영구 삭제하기**)로 비우고 다시 게시판을 삭제하세요. 영구 삭제한 글은 되살릴 수 없으니, 보존이 필요하면 게시판 삭제 대신 **노출 끄기**를 쓰세요.

**Q. 고객센터 문의에 답하려는데 "게시할 수 없는 단어" 안내가 뜹니다.**
운영자 답변도 금칙어 검사를 받습니다. 표현을 바꿔 쓰거나, 꼭 필요하면 [3.14 금칙어 관리](#314-금칙어-관리)에서 해당 단어의 사용 스위치를 잠시 끈 뒤 답하고 다시 켜세요.

**Q. FAQ 오타를 고치고 싶습니다.**
FAQ 관리 목록에서 해당 질문을 펼치고 **수정** 버튼을 누르면 카테고리·질문·답변을 그 자리에서 고쳐 **저장**할 수 있습니다. 삭제 후 재등록할 필요가 없습니다.

**Q. 금칙어를 추가했는데 글이 그대로 써집니다.**
반영에 최대 1분 정도 걸릴 수 있습니다. 1분 뒤 다시 확인하고, 그래도 통과한다면 해당 단어의 **사용** 스위치가 꺼져 있지 않은지 확인하세요.

**Q. 게시판을 잘못 만들었습니다. 지울 수 있나요?**
**글이 하나도 없다면** 그 줄의 **삭제**로 지울 수 있습니다. 글이 한 건이라도 쌓였으면 "글이 있는 게시판은 삭제할 수 없습니다. 노출을 끄는 방식을 사용해 주세요."라고 거부되는데, 지우면 그 글이 함께 사라지기 때문입니다. 이때는 **노출** 스위치를 내리면 사용자 화면에서만 사라지고 글은 그대로 보존됩니다. 기본 게시판 5종은 아예 지울 수 없어 삭제 버튼이 보이지 않습니다. 이름·설명·아이콘·순서는 **수정**으로 고칠 수 있지만 **주소는 바꿀 수 없으니**, 주소를 잘못 넣었다면 (글이 없을 때는) 삭제하고, 글이 있으면 노출을 끈 뒤 올바른 주소로 새로 만드세요. 자세한 내용은 [3.12 게시판 관리](#312-게시판-관리)를 참고하세요.

**Q. 포인트몰 주문을 잘못 눌러 지급 완료로 처리했습니다. 되돌릴 수 있나요?**
주문 상태로는 되돌릴 수 없습니다. 처리 대기가 아닌 주문에 다시 조작하면 "이미 처리된 주문입니다."로 거부됩니다. 회원에게 포인트를 돌려줘야 한다면 [3.8 출석 관리](#38-출석-관리)에서 같은 양을 **지급**으로 넣고 사유를 남겨 주세요.

**Q. 아이템을 잠시만 안 팔고 싶습니다. 삭제해야 하나요?**
아니요. 아이템 수정 창의 **포인트몰에 노출** 스위치를 끄면 회원 목록에서 사라지고 구매도 막힙니다. 삭제는 되돌릴 수 없으니 정말 없앨 때만 쓰세요.

**Q. 회원이 포인트몰에서 아이템을 샀는데 등급이 그대로입니다.**
정상입니다. 포인트몰 구매·환불은 등급 계산에서 제외됩니다. 포인트 **잔액**만 줄고 등급 기준 점수는 그대로 유지됩니다.

**Q. 회원이 포인트몰을 못 찾겠다고 합니다.**
PC에서는 상단 메뉴 **수다방**과 **고객센터** 사이의 **포인트몰**입니다. 휴대폰 아래쪽 탭 바에는 포인트몰 항목이 없으므로, 주소 `/point-shop`으로 직접 들어가도록 안내해 주세요. 구매 내역은 휴대폰에서도 **내 정보 → 포인트 구매 내역**에서 볼 수 있습니다.

**Q. 사유를 입력했는데 처리 버튼이 눌리지 않습니다.**
사유는 두 글자 이상 입력해야 처리가 활성화됩니다. 공백만 입력한 경우에도 처리되지 않으니 실제 사유를 적어 주세요.

**Q. 요약 현황의 숫자는 어떻게 갱신되나요?**
검수·신고·제재를 처리하면 상단의 검수 대기·신고 대기·경고 사용자 숫자가 자동으로 반영됩니다. 별도로 새로고침할 필요는 없습니다.

**Q. 모바일에서 결제 관리·크롤링 화면은 어디 있나요?**
좁은 화면의 아래쪽 탭에는 검수·신고·사용자·후기·광고 상품만 표시됩니다. 나머지 화면은 오른쪽 끝 **더보기** 탭을 눌러 열리는 목록에서 이동하세요.
